## 七、异常与边界专项（白盒）

- **TC-069 / P0** 全局异常 — 任意接口抛未处理Exception → GlobalExceptionHandler:62 catch → 返回 `{code:500, message:"服务器内部错误，请稍后重试"}`

- **TC-072 / P1** 未认证 — 无Authorization头访问需认证接口 → SecurityFilterChain → 返回 401 / 跳转登录
- **TC-073 / P1** 权限不足 — employee角色访问 `/admin/**` → SecurityConfig:63 hasRole("SUPER_ADMIN")不通过 → 返回 403
- **TC-074 / P1** IM回调免鉴权 — 飞书webhook回调 `/im/feishu/callback` → SecurityConfig:57 permitAll → 不经过JwtAuthFilter → 直接进入ImController
