# 预检引擎设计

> 素材上传后的即时质量检测系统。纯规则引擎，零 AI 调用，延迟 < 50ms。

---

## 一、两层防护

```
素材上传
  │
  ├── Gate 1: 准入检查（硬性拒绝）
  │   不通过 → status="rejected"，不进入流水线
  │
  └── Gate 2: 质量预检（打分但不阻断）
      高分 🟢 / 中分 🟡 / 低分 🔴
```

---

## 二、Gate 1：准入检查

### 检查项

| 检查项 | 规则 | 拒绝代码 | 拒绝文案 |
|--------|------|---------|---------|
| 内容过短 | < 50 字符 | `TOO_SHORT` | "内容过短（仅 X 字），请上传 ≥50 字的完整对话或经验分享" |
| 非中文 | 中文占比 < 70% | `NOT_CHINESE` | "当前仅支持中文素材，检测到中文占比仅 X%" |
| 非销售领域 | 销售关键词密度 < 0.5% | `NOT_SALES_DOMAIN` | "未检测到足够的销售关键词，请上传包含报价、谈判等内容的销售素材" |
| 教科书内容 | 第一人称"我"占比 < 1% 且理论句式 > 30% | `TOO_THEORETICAL` | "内容偏理论性，需要真实销售经验而非通用建议" |
| 营销广告 | 营销信号词占比 > 15% | `MARKETING_CONTENT` | "检测到营销推广材料，请上传销售经验分享" |
| 高度重复 | 与已有颗粒 5-gram 相似度 > 90% | `DUPLICATE` | "与已上传素材高度重复" |

### 执行时机

- **文本类文件**：上传时同步检查（`uploadMaterial()`）
- **二进制文件**：解析后的 `clean()` 入口检查

## 三、Gate 2：质量预检

### 架构

```
MaterialPreChecker.evaluate(text, domain, spaceId)
  │
  ├── StructureAnalyzer.analyze(text, config)    — 结构维度
  │     ├── minLength       最小长度检查
  │     ├── dialogueTurns   对话轮次检测
  │     └── customerRatio   客户发言占比
  │
  ├── ContentAnalyzer.analyze(text, config)      — 内容维度
  │     ├── businessDensity 业务关键词密度
  │     ├── objectionSignals 异议信号检测
  │     └── topicVariety    话题多样性
  │
  ├── QualityAnalyzer.analyze(text, config)      — 质量维度
  │     ├── noiseRatio      噪音比（寒暄/闲聊/口头禅）
  │     ├── chineseRatio    中文占比
  │     └── duplicateCheck  重复检测（需 DB）
  │
  └── PredictiveScorer → PreCheckResult
        ├── overallScore     综合评分（结构40% + 内容35% + 质量25%）
        ├── grade            good(≥70) / warning(50-69) / poor(<50)
        ├── estimatedGrains  预估颗粒数（对话轮数 × 业务密度 × 0.3）
        └── detectedScenes   检测到的场景标签
```

### 反馈文案

| 检查项 | 通过示例 | 不通过示例 |
|--------|---------|-----------|
| 最小长度 | "内容长度 1250 字，非常充分" | "内容过短（仅 30 字），建议上传 ≥100 字的完整对话" |
| 对话轮数 | "检测到 12 轮对话，结构完整" | "仅检测到 1 轮对话，建议至少 3 轮" |
| 客户占比 | "客户发言占比 35%，结构均衡" | "客户发言仅占 3%，需客户真实反馈" |
| 业务密度 | "业务关键词密度 3.2%，内容丰富" | "业务关键词密度偏低（0.8%），建议补充实质业务内容" |
| 异议信号 | "检测到 4 个异议信号：价格异议、竞品威胁、拖延信号、信任顾虑" | "未检测到客户异议信号，建议补充客户质疑对话" |
| 话题多样性 | "覆盖 5 个话题领域：价格谈判、竞品对比..." | "仅覆盖 1 个话题领域，建议上传多阶段对话" |
| 噪音比 | "噪音占比 6%，内容质量良好" | "无效内容占比 58%，建议裁剪寒暄和无关闲聊" |
| 中文占比 | "中文占比 98%，语言正常" | "中文占比仅 45%，当前仅支持中文" |

## 四、数据模型

### API 响应

```json
// 上传接口返回
{
  "materialId": "xxx",
  "status": "uploaded",
  "acceptance": {
    "passed": true
  },
  "preCheck": {
    "overallScore": 78,
    "grade": "good",
    "estimatedGrainMin": 5,
    "estimatedGrainMax": 15,
    "detectedScenes": ["价格谈判", "竞品对比", "异议处理"],
    "checks": [
      {
        "dimension": "structure",
        "name": "dialogue_turns",
        "passed": true,
        "score": 90,
        "feedback": "检测到 12 轮客户-销售对话，结构完整"
      }
    ]
  }
}
```

### Java Record

```java
public record PreCheckResult(
    int overallScore,                    // 0-100
    String grade,                        // good | warning | poor
    int estimatedGrainMin,
    int estimatedGrainMax,
    List<String> detectedScenes,
    List<CheckItem> checks
) {}

public record CheckItem(
    String dimension,     // structure | content | quality
    String name,          // dialogue_turns | objection_signals | ...
    boolean passed,
    int score,            // 0-100
    String feedback,      // 人类可读
    String suggestion     // 改进建议，通过时为 null
) {}

public record AcceptanceResult(
    boolean passed,
    String rejectCode,    // TOO_SHORT | NOT_SALES_DOMAIN | ...
    String rejectReason,  // 人类可读
    Map<String, Object> details
) {}
```

## 五、代码文件

| 文件 | 职责 |
|------|------|
| `service/precheck/MaterialPreChecker.java` | 主引擎，编排分析器 + 综合评分 |
| `service/precheck/StructureAnalyzer.java` | 结构维度 3 项检查 |
| `service/precheck/ContentAnalyzer.java` | 内容维度 3 项检查 + 准入检查 |
| `service/precheck/QualityAnalyzer.java` | 质量维度 3 项检查 + 重复检测 |
| `service/precheck/PreCheckResult.java` | 预检结果 Record |
| `service/precheck/CheckItem.java` | 单项检查 Record |
| `service/precheck/AcceptanceResult.java` | 准入结果 Record |
| `config/DomainConfig.java` | YAML 配置映射（含 AcceptanceConfig / PreCheckConfig） |
| `config/DomainConfigLoader.java` | 配置加载 + 缓存 |
