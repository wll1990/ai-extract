## 5. 事件流协议

所有端统一协议（`sse.ts` 已兼容）：

| type | 含义 | 字段 | 发送时机 |
|------|------|------|---------|
| `heartbeat` | 连接确认 | status | 连接建立时 |
| `warning` | 画像不完整提醒 | message, action, skillId | 回答前 |
| `content` | AI 文本 chunk | content | 每个 LLM token |
| `meta` | 会话 ID | conversationId | 回答完成后 |
| `source` | 引用溯源 | reportId, grainIds, grainTags, avgScore | 回答完成后 |
| `done` | 流结束标记 | - | 延迟到所有chunk之后 |
| `error` | 异常 | message | 发生错误时 |
