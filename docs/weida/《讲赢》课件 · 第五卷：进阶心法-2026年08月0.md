# 📗 《讲赢》课件 · 第五卷：进阶心法

卷首语：技巧学了不少，但总觉得“差点意思“。差的那点意思，就是心法。

## 第1页：封面

标题：第五卷 · 进阶心法 两大体系：

• 讲赢四修——表达力的内在修炼

• 讲赢四阶——表达力成长路径 一句话定位：技巧决定下限，心法决定上限

讲师备注： 开场问：“你们有没有过这种感觉——方法都学了，道理都懂，但真到用的时候，就是用不出来？“等回答，然后说：“为什么？因为你缺的不是方法，是心法。方法是术，心法是道。术学得再多，道不够，也用不出来。”

## 第2页：学习目标

学完这一讲，你会带走四件事：

1. ✅ 理解“修心、修言、修场、修业“四修体系

2. ✅ 找到你的心力卡点，知道怎么补

3. ✅ 看清表达力成长的四个阶段，知道自己在哪

4. ✅ 有一张清晰的成长路线图，知道下一步练什么

讲师备注： “这一卷是’拔高’的。前面的都是方法，这一卷讲的是’人’。你的表达力能走多远，最终取决于你这个人能走多远。”

# 讲赢四修

## 第3页：为什么技巧学了不少，还是“差点意思“？

因为你只学了“术“，没修“道“。

• 学了很多话术，但一到关键时刻就紧张

• 学了很多方法，但就是不敢收钱

• 学了很多技巧，但总觉得“不是自己的“

表达力的瓶颈，从来不是表达本身，是你这个人的瓶颈。

讲师备注： “我见过很多人，学了一堆表达技巧，说话一套一套的。但你跟他聊两句就觉得——差点意思。差在哪？——差在内在。他的内在撑不起他说的话。话再漂亮，人没跟上，也是空的。”

## 第4页：四修体系总览

表达力的内在修炼，分四个层次：

修业（事业）       以表达赋能事业      ┌──────────┐      │ 修场（气场） │      │ 控场能力、气场修炼│      ├──────────┤      │ 修言（语言） │      │ 表达技术、语言打磨│      ├──────────┤      │ 修心（心力） │      │ 心力强度、内在力量│      └──────────┘

• 修心：内在力量——你的心有多强，你的表达就有多有力

• 修言：语言技术——你的话有多准，你的表达就有多高效

• 修场：控场气场——你的场有多大，你就能影响多少人

• 修业：事业赋能——表达最终要落到事业上，帮你拿到结果

讲师备注： “很多人一上来就修言——学话术、学技巧。没错，但不够。修言是基础，修心才是根本。心不够强，言再漂亮也没用。心够强了，言哪怕朴实，也有力量。”

## 第5页：修心——心力强度

心力，就是你内心的力量。

心力强的表现：

• 敢说、敢要、敢拒绝

• 遇到事不慌，能扛住

• 被拒绝了不玻璃心，再来就是

• 敢收钱、敢涨价、敢说“不“

心力弱的表现：

• 不敢开口、怕被拒绝

• 一到关键时刻就紧张、掉链子

• 客户一砍价就心软

• 不敢收钱，总觉得自己不值那个价

讲师备注： “心力这个东西，看不见摸不着，但它决定了你的一切。你有100分的能力，心力只有50分，你只能发挥出50分。你有80分的能力，心力有100分，你能发挥出120分。”

## 第6页：心力怎么练？

心力不是天生的，是练出来的。

三个练习方法：

方法一：做“不敢做的事“

• 不敢跟陌生人说话？——每天主动跟3个陌生人打招呼

• 不敢收钱？——明天就给客户涨一次价

• 不敢拒绝？——今天就拒绝一个你不想答应的事

• 原理：你越怕什么，越去做什么。做着做着，就不怕了

方法二：“我值得“练习

• 每天早上对着镜子说：“我值得最好的一切”

• 收钱的时候告诉自己：“我值这个价”

• 被拒绝的时候告诉自己：“不是我不行，是他没眼光”

• 原理：自我价值感，是心力的根基

方法三：复盘“成功时刻“

• 每天晚上，写下当天最有成就感的3件事

• 不用多大，哪怕是“今天勇敢地说了不“

• 原理：心力是靠一次次小成功积累起来的

讲师备注： “心力的修炼，没有捷径。就是一件事一件事地扛，一个坎一个坎地过。扛过去了，你的心力就强了一分。扛不过去，你就永远卡在那里。”

## 第7页：修言——语言打磨

你的语言，就是你的武器。

好的语言，三个标准：

1. 准：一句话说到位，不啰嗦

2. 狠：能扎到人，让人有感觉

3. 暖：让人舒服，愿意听下去

语言打磨的三个方法：

方法一：录音回听

• 把你讲课、谈客户的录音录下来

• 自己听一遍：哪里啰嗦了？哪里没说清？哪里可以更准？

• 每次改一个地方，慢慢迭代

方法二：金句积累

• 看到好句子、好表达，记下来

• 自己琢磨出好句子，也记下来

• 慢慢攒出你的“金句库“

方法三：跟高手学

• 找你觉得表达好的人，反复听他讲

• 学他的节奏、他的用词、他的结构

• 不是抄，是吸收，变成你自己的

讲师备注： “语言这个东西，是越磨越锋利的。你天天说、天天练、天天改，慢慢的，你的话就有力量了。别着急，这是个慢功夫，但慢功夫出细活。”

## 第8页：修场——控场能力与气场

气场是什么？

气场不是“装出来的牛逼“，是“由内而外的力量“。

• 你一进门，别人就注意到你

• 你一开口，别人就安静下来

• 你一站在台上，别人就被你吸引

气场的三个来源：

1. 底气：你真的有料，真的能帮到人

2. 定力：你不慌、不乱、不讨好

3. 能量：你状态好、精神足、有感染力

讲师备注： “很多人以为气场就是’装酷’‘摆架子’。错了。那样的气场，一戳就破。真正的气场，是内在力量的外显。你内在有多少，外在就显多少。装不出来，也藏不住。”

## 第9页：气场怎么练？

三个练习：

练习一：身体训练

• 站如松：抬头挺胸，肩膀打开，重心稳

• 坐如钟：不瘫、不抖、不晃

• 走路：步子稳、速度适中、有节奏感

• 原理：身体的状态，直接影响心理的状态

练习二：眼神训练

• 跟人说话，敢看着对方的眼睛

• 不躲闪、不游离、不凶狠

• 眼神要稳、要定、要有温度

• 原理：眼神是心灵的窗户，眼神稳的人，心就稳

练习三：呼吸训练

• 紧张的时候，做三次深呼吸

• 吸气4秒，屏息4秒，呼气6秒

• 呼吸稳了，心跳就稳了，人就稳了

• 原理：呼吸是你能直接控制的生理反应，控制了呼吸，就控制了状态

讲师备注： “气场的修炼，是从身体开始的。身体稳了，心就稳了。心稳了，场就出来了。别小看这些小动作——它们是你气场的根基。”

## 第10页：修业——以表达赋能事业

表达不是目的，事业才是目的。

表达力，最终要落到你的事业上，帮你拿到结果。

怎么用表达赋能事业？

1. 对外：用表达获客、成交、招商、建品牌

◦ 客户多了、收入高了、品牌响了

2. 对内：用表达带团队、做管理、传文化

◦ 团队强了、效率高了、文化稳了

3. 对自己：用表达梳理思路、倒逼成长、建立影响力

◦ 思路清了、成长快了、影响力大了

表达力，是你事业的“放大器“。

讲师备注： “很多人学表达，学着学着就跑偏了——为了表达而表达。参加演讲比赛、拿各种证书、追求’讲得好’。错了。表达是工具，不是目的。你的目的，是把事业做好、把日子过好。表达是为你的事业服务的。”

# 讲赢四阶

## 第12页：你现在在什么水平？

表达力的成长，不是一条直线，是四个阶段。

第四阶：塑IP —— 讲成品牌  ↑第三阶：出结果 —— 讲赢  ↑第二阶：建逻辑 —— 会讲  ↑第一阶：破恐惧 —— 敢讲

• 第一阶：破恐惧——敢开口、不紧张、能说清楚

• 第二阶：建逻辑——有结构、有条理、能说服人

• 第三阶：出结果——能控场、能成交、能拿结果

• 第四阶：塑IP——有风格、有品牌、有影响力

讲师备注： “很多人问我’郭老师，我表达不好，怎么办？’我说——你先告诉我，你卡在第几阶？每一阶的问题不一样，解法也不一样。找对了阶段，对症下药，才管用。”

## 第13页：第一阶：破恐惧——敢讲

这一阶的核心问题：不敢说、怕出错、怕被笑话。

表现：

• 一上台就紧张，心跳加速、脑子空白

• 跟陌生人说话不自在

• 有想法不敢说，怕说错

• 能打字就不打电话，能发语音就不见面

怎么破？

• 不是“克服紧张“，是“带着紧张上“

• 紧张是正常的，不紧张才不正常

• 你越怕，越去做。做着做着，就不怕了

通关标志：

• 敢开口、不逃避、能说清楚自己想说的

讲师备注： “很多人卡在第一阶，一辈子都没过去。为什么？——因为他们总想’等我不紧张了再上’。错了。你永远等不到那一天。紧张会一直陪着你，你要做的，是带着紧张，照样上。”

## 第14页：第二阶：建逻辑——会讲

这一阶的核心问题：想说的很多，但说不清楚。

表现：

• 说话没重点，东一句西一句

• 讲了半天，别人不知道你想说啥

• 心里明白，就是说不出来

• 写东西、做汇报，没有结构

怎么建？

• 学结构：总分总、递进、并列、对比……

• 学方法：结论先行、三点式、黄金圈……

• 多练习：每次说话前，先想清楚结构再说

通关标志：

• 说话有结构、有条理、别人一听就懂

讲师备注： “第二阶是’技术关’。这一阶没什么捷径，就是学方法、练结构。练多了，逻辑就出来了。大部分人，努力个三五个月，都能过这一关。”

## 第15页：第三阶：出结果——讲赢

这一阶的核心问题：说得挺好，但就是拿不到结果。

表现：

• 演讲掌声很多，但没人行动

• 跟客户聊得很好，但就是不成交

• 开会讲得很清楚，但员工就是不动

• 内容数据不错，但就是不变现

怎么破？

• 从“讲得好“转向“拿到结果“

• 每一次表达，都先想清楚：我要什么结果？

• 用结果倒推内容，而不是先有内容再想结果

通关标志：

• 说完之后，对方会按你说的做

• 表达能直接带来结果（成交、行动、改变）

讲师备注： “第三阶是’结果关’。很多人一辈子卡在第二阶——讲得挺好，但就是没用。为什么？——因为他们追求的是’讲得好’，不是’有结果’。目标错了，方法再对也没用。”

## 第16页：第四阶：塑IP——讲成品牌

这一阶的核心问题：有结果，但没有形成个人品牌。

表现：

• 你很厉害，但没多少人知道

• 你能成交，但都是靠一对一，效率低

• 你有影响力，但只在小圈子里

• 你离开了，业务就停了

怎么塑？

• 找到你的独特风格（别人抄不了的）

• 持续输出，建立你的内容资产

• 从“做事的人“变成“说事的人“

• 让你的名字，等于一个品类

通关标志：

• 别人提到某个领域，第一个想到你

• 你不用主动找客户，客户主动来找你

• 你的表达，能影响成千上万的人

讲师备注： “第四阶是’品牌关’。到了这一阶，你的表达力就不只是’技能’了，而是’资产’。这个资产，能帮你赚钱，能帮你做事，能帮你影响更多人。这是表达力的最高境界。”

## 第17页：你在哪一阶？下一步练什么？

快速自测：

| 问题 | 是/否 |
| --- | --- |
| 1. 你敢在公开场合说话吗？ | □ 是 □ 否 |
| 2. 你说话有结构、有条理吗？ | □ 是 □ 否 |
| 3. 你说完之后，对方会按你说的做吗？ | □ 是 □ 否 |
| 4. 很多人因为你的表达而认识你、信任你吗？ | □ 是 □ 否 |

判断：

• 1个“是“→ 第一阶（破恐惧）

• 2个“是“→ 第二阶（建逻辑）

• 3个“是“→ 第三阶（出结果）

• 4个“是“→ 第四阶（塑IP）

讲师备注： “找到你在哪一阶，就从那一阶开始练。别跳级。跳级的结果就是——基础不牢，地动山摇。一步一步来，稳扎稳打，才能走得远。”
