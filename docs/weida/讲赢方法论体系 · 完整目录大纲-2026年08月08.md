# 讲赢方法论体系 · 完整目录大纲

讲赢 · 小微企业的讲赢军师 千头万绪，一针变现 做事先识人，成事靠方法，落地靠表达

## 总序：关于讲赢

### 我们的使命

用表达，让创业者的才华配得上他们的努力。

### 我们的定位

国内唯一的「识人 + 判事 + 变现」三位一体商业表达体系—— 帮中小创始人在复杂的业务版图里，找到最快变现的那条路径，先活下来，再谈发展。

### 三大独家标签

1. 识人先行——先选对人，再做对事。市面上的商业课只教做事，我们还教选人。

2. 全部来自实战——每一个方法都有真实案例支撑，不是纸上谈兵，是20年一线经验攒出来的。

3. 当场出结果——课程结束，每个学员带走属于自己的变现方案，而不是一堆认知。

### 底层信念（三条）

1. 先活下来，再谈理想。

2. 人比模式重要。

3. 少即是多。

## 第一卷：顶层旗舰——一针变现法

卷首语：千头万绪，一针变现。别人教你“怎么把事做对“，我帮你“先找对那件事“。

### 前置篇：识人筛选

人选错了，方法再好也没用。

• 郭氏识人法：四力三问两观察

◦ 四力：专注力、执行力、学习力、抗压能力

◦ 三问：最牛的事？最大的坎？3年目标？

◦ 两观察：怎么对待身边人？怎么花钱和时间？

• 标杆案例：免疫力教授（正例）/ 空壳平台创始人（反例）

### 第一步：破局——欲望砍刀法

从“什么都想要“砍到“只干一件活命的事“。

• 【判】七步判生意法（简化版）

◦ 市场够不够大 / 痛点够不够痛 / 你有没有优势

◦ 变现够不够快 / 毛利够不够高 / 复制够不够易 / 风险够不够低

• 【识】破局识人三问

◦ 做这行多久了？最擅长什么？

◦ 去年赚了多少钱？主要靠什么赚的？

◦ 如果只能留一件事，你留哪件？

• 【表】一句话定位法

◦ 公式：我帮谁 + 解决什么问题 + 得到什么结果

• 经典破局提问（5个场景）

• 标杆案例×3：免疫力教授 / 枸杞项目 / 空壳平台创始人

### 第二步：找根——信任资产盘点法

不从零开始教育市场，从已经信你的人出发。

• 【判】客户价值分层法

◦ 高价值客户 vs 低价值客户（5个维度）

• 【识】种子用户识别法

◦ 行动力强 / 有感恩心 / 有影响力 / 价值观匹配

• 【表】存量激活话术（3套）

◦ 权威型 / 情感型 / 利益型

• 找根三问（标准问卷）

• 标杆案例×3：AI转型公司 / 枸杞项目 / 女性表达学院

### 第三步：穿线——闭环设计法

把单点生意变成自增长闭环，让每一笔成交都带来下一笔。

• 【判】商业模式健康度检测（7个维度）

◦ 入口够不够宽 / 转化够不够顺 / 价值够不够大

◦ 升单够不够自然 / 推荐够不够动力 / 交付够不够轻 / 利润够不够厚

• 【识】合伙人筛选法（四层）

◦ 体验层 / 推广层 / 经营层 / 战略层

• 【表】招商表达五步法

◦ 痛点开场 → 趋势铺垫 → 方案呈现 → 案例证明 → 行动号召

• 三层合伙人通用模板

• 标杆案例×3：女性表达学院 / 免疫力项目 / 枸杞项目

### 第四步：降维——主次重排法

让配角服务主角，让所有资源都为变现主线服务。

• 【判】资源ROI评估法

◦ 主线 / 放大器 / 门槛 / 入口 / 第二曲线

• 【识】创始人精力诊断

◦ 时间花在哪？最在乎什么？精力跟主线对齐吗？

• 【表】降维说服逻辑

◦ 先肯定 → 再重构 → 给希望

• 要素角色定位表

• 标杆案例×3：免疫力证书 / 创始人IP / AI工具

### 实战篇：一针诊断术

30分钟，给一个陌生项目做完整的商业诊断。

• 30分钟诊断标准流程

◦ 前5分钟：识人阶段

◦ 中间10分钟：破局+找根

◦ 后10分钟：穿线+降维

◦ 最后5分钟：总结行动

• 诊断输出物（标准四件套）

1. 一句话诊断结论

2. 变现主线

3. 起步动作

4. 降级建议

• 现场实战环节
