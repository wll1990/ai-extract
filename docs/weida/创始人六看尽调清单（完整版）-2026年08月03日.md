# 创始人六看尽调清单（完整版）

三道生死线（看人）：状态不行→死在半路；不笃定→死在困难里；人品差→死在人心上。

三道价值线（看事）：赛道小→做不大；无壁垒→守不住；账算不清→活不长。

人对 + 事对 = 值得投、值得合作、值得深交。

## 上篇：人三看（三道生死线）

### 第一看：状态（能不能撑到终点）

观察场景：见面30分钟内的整体状态、聊业务时的精神面貌、遇到质疑时的反应

#### 正向信号（打勾）

• [ ] 聊到自己的业务时，眼睛发亮、语速加快

• [ ] 遇到质疑，先停顿思考再回应，不急着辩解

• [ ] 说起困难，主动拆解成具体问题，不抱怨

• [ ] 面色红润、眼神清澈、说话有底气

• [ ] 身材管理良好，行动利落

• [ ] 坐姿端正，不频繁叹气、揉太阳穴

#### 负向信号（打叉）

• [ ] 脸色晦暗、眼神浑浊、有气无力

• [ ] 身材严重走形，明显缺乏自我管理

• [ ] 一坐下就叹气、揉太阳穴、频繁刷手机

• [ ] 遇到质疑立刻反驳、要面子不要结果

• [ ] 说起困难全是借口，都是别人的问题

• [ ] 全程焦虑感外溢，坐立不安

深度验证（防表演）：

• 凌晨两点回不回消息？（真实精力）

• 连续出差三周后说话还有没有条理？（耐力）

• 公司账上只剩三个月钱时，跟团队说话的语气变没变？（压力下的状态）

一句话判断：这个人，你信不信他能扛三年？

### 第二看：笃定（遇到挫折会不会放弃）

观察场景：聊业务细节、聊行业认知、被挑战核心逻辑时的反应

#### 真笃定（往里钻）

• [ ] 聊业务时主动说细节，越聊越深、越聊越兴奋

• [ ] 能说出具体用户画像、具体数据、具体痛点

• [ ] 被质疑时不回避，愿意深入讨论甚至承认不足

• [ ] 做这件事的理由是“我就是要做“，不是“风口来了“

• [ ] 对行业有自己的独立判断，不人云亦云

• [ ] 聊起产品/用户时，有“控制不住“的表达欲

#### 假笃定（往外飘）

• [ ] 全是宏大叙事、万亿市场，不说具体事

• [ ] 张口闭口“风口““赛道”“赋能”“闭环”

• [ ] 一被质疑就急、就跳脚——不是坚信，是心虚

• [ ] “行业第一”“三年上市”，就是不说现在怎么样

• [ ] 对竞品和市场格局说不清楚

• [ ] 回答问题绕圈子，不正面回应

深度验证（防偏执）：

• 举出一个他过去因为新证据而改变主意的例子（灵活度）

• 问“什么情况下你会放弃这件事？“——有明确底线的是真笃定，说“永不放弃“的可能是偏执

一句话判断：这件事，是不是已经长在他身上了？

### 第三看：对底层的态度（人品底色）

观察场景：和服务员/保洁/保安的互动、对下属犯错的反应、对供应商的姿态

#### 正向信号

• [ ] 对服务员说“谢谢““麻烦你”，自然不刻意

• [ ] 对保洁、保安点头致意，不视而不见

• [ ] 下属犯错时，对事不对人，一起找解决方案

• [ ] 对供应商平等沟通，不摆甲方架子

• [ ] 遇到地位低的人，姿态不变化

• [ ] 会主动关心身边普通人的处境

#### 负向信号

• [ ] 对服务员呼来喝去，一副大爷姿态

• [ ] 对保洁、保安完全无视，仿佛不存在

• [ ] 下属犯错时人身攻击、当众羞辱

• [ ] 对供应商趾高气扬，觉得有钱就是爷

• [ ] 对比自己强的人谄媚，对比自己弱的人傲慢

• [ ] 随口贬低服务行业人员、体力劳动者

深度验证（防教养≠人品）：

• 他怎么对待曾经帮过他、但现在已经没用了的人？（利益褪去后的本色）

• 他在钱上有没有过不清不楚的记录？（股权分配、报销、对合伙人的承诺）

• 跟他合作过的人，离开他之后怎么评价他？（长期口碑）

一句话判断：哪天你对他没用了，他会不会也这样对你？

## 下篇：事三看（三道价值线）

### 第四看：赛道（天花板有多高）

核心问题：这件事做成了，是个生意还是个事业？

#### 三步算清真实市场

1. 切细分：不说“大健康““教育“这种大词，切到最具体的人群和场景——“一线城市35-45岁女性的轻医美抗衰项目”

2. 算渗透率：这个细分里，现在有多少人已经在付费？每年增速多少？（增速比绝对规模重要）

3. 估份额：第一名通常能占30%-50%，他凭什么是那个第一名？

#### 红旗信号

• [ ] 张口就是“万亿市场““千亿赛道”，但说不出自己具体切哪一块

• [ ] 市场规模是靠“层层相乘“算出来的（总人口×渗透率×客单价=假大空）

• [ ] 增速全靠“未来趋势“撑着，没有当下真实数据

一句话判断：做成了，是赚点钱养家，还是能在行业里有名字？

### 第五看：壁垒（别人为什么抢不走）

核心问题：如果腾讯/阿里/字节明天也做这件事，他还活不活得下去？

#### 四种壁垒（从弱到强）

| 壁垒类型 | 说明 | 靠谱程度 |
| --- | --- | --- |
| 资源壁垒 | 独家渠道、人脉关系 | ★☆☆ 最弱，资源会流动 |
| 技术壁垒 | 别人做不出来的技术 | ★★☆ 有窗口期，会过期 |
| 规模壁垒 | 越大越便宜，正向循环 | ★★★ 后来者很难打 |
| 网络效应/心智壁垒 | 用户因为用户多而来；想到这件事第一个想到你 | ★★★★★ 最强壁垒 |

#### 红旗信号

• [ ] 把“先发优势“当壁垒——早做半年不算壁垒

• [ ] 把“团队厉害“当壁垒——人是会走的

• [ ] 把“创意好“当壁垒——创意最不值钱，谁都能抄

一句话判断：他的护城河，是真的河，还是画在地上的线？

### 第六看：算账（钱到底能不能赚到）

核心问题：如果明天没有融资了，这公司能不能活？

#### 三层账要算清

1. 单笔账：获客成本 vs 客单价×毛利率——一单做完，赚还是亏？

2. 生命周期账：一个用户能留多久？LTV（用户终身价值）> CAC（获客成本）吗？比值多少？（至少3倍以上才健康）

3. 规模账：做大了之后，单位成本会不会降？有没有规模效应？

#### 红旗信号

• [ ] “先做用户，以后再想怎么赚钱”——可能永远赚不到钱

• [ ] 毛利低于30%还在烧钱获客——越做越亏

• [ ] 获客成本逐月上升，没有下降趋势——增长不可持续

• [ ] 账上现金不够撑12个月——随时可能断气

一句话判断：这是一家靠输血活着的公司，还是靠自己造血活着的公司？

### 决策建议

• 8分以上：可以深交、可以合作、可以投资

• 6-8分：可以观察，小范围合作试水

• 6分以下：谨慎接触，项目再好也不碰

• 任一项低于4分：直接pass——有明显短板的创始人/项目，迟早栽在那个短板上

• 人三看总分高、事三看总分低：可以交朋友，但别投钱——人靠谱，但事做不大

• 事三看总分高、人三看总分低：事再好也别碰——人不行，再好的事也能做砸
