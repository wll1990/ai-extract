# 战略方法论：五看三定战略法

战略不是“我们要做什么“，是“我们不做什么“。 战略的本质是选择——选择做什么，更选择不做什么；选择怎么赢，更选择在哪里赢。

## 总框架

五看（看环境/看行业/看客户/看对手/看自己）        ↓三定（定方向/定目标/定打法）

## 五看：看清局势

### 第1看：看宏观环境——大环境怎么样？

宏观环境决定了“什么事能做，什么事不能做“。顺势而为，事半功倍；逆势而为，事倍功半。

### PEST分析框架

| 维度 | 看什么 | 例子 |
| --- | --- | --- |
| P（政治/政策） | 政策支持还是限制？监管严不严？ | 教培行业的政策变化、新能源的政策支持 |
| E（经济） | 经济增长还是下行？消费力怎么样？ | 经济下行期，性价比产品更受欢迎 |
| S（社会） | 人口结构、社会风气、消费习惯变化 | 老龄化、单身经济、Z世代的消费偏好 |
| T（技术） | 有没有新技术出现？会不会改变行业？ | AI、移动互联网、新能源技术 |

关键问题：

• 未来3-5年，大的趋势是什么？

• 哪些趋势对我们有利？哪些不利？

• 我们能抓住什么机会？要避开什么风险？

### 第2看：看行业——这个行业怎么样？

行业决定了你的天花板和赚钱难度。选对行业，猪都能飞；选错行业，再努力也白搭。

### 行业分析的五个维度

1. 市场规模和增速

• 市场有多大？增长快不快？

• 是增量市场还是存量市场？

2. 行业生命周期

• 萌芽期 / 成长期 / 成熟期 / 衰退期？

• 渗透率多少？

3. 竞争格局

• 行业前三名是谁？占多少份额？

• 是寡头垄断还是充分竞争？

• 进入门槛高不高？

4. 利润水平

• 行业平均毛利多少？净利多少？

• 钱被谁赚走了？（上游/下游/平台/品牌）

5. 关键成功要素

• 在这个行业里，什么最重要？

• 是技术？是品牌？是渠道？是成本？是关系？

用波特五力模型辅助判断：供应商议价能力、购买者议价能力、潜在进入者威胁、替代品威胁、现有竞争程度。

### 第3看：看客户——我们的客户是谁？

战略的起点，不是“我有什么“，是“客户需要什么“。

### 客户分析的三个问题

1. 我们的客户是谁？

• 不要说“所有人都是我们的客户“，那等于没有客户

• 客户画像越具体越好：年龄、性别、职业、收入、痛点、习惯

• 最好的客户画像，是你能说出“他叫什么名字，住在哪，每天干什么“

2. 客户的核心需求是什么？

• 他买的不是产品，是“问题的解决方案“

• 他最痛的点是什么？最想要的是什么？

• 需求是显性的还是隐性的？（很多时候客户自己都说不清楚）

3. 客户的决策路径是什么？

• 他怎么知道你？怎么了解你？怎么决定买不买？

• 决策的关键节点是什么？谁是决策者？谁是影响者？

客户转化的核心，是基于客户的“价值主张“分析——不同的客户，价值主张不一样，转化手段也不一样。

### 第4看：看对手——谁在跟我们抢饭吃？

不知道对手是谁，你就不知道怎么赢。

### 竞争对手分析的四个维度

1. 谁是我们的竞争对手？

• 直接竞争对手（做一样的事）

• 间接竞争对手（用不同方式满足同样的需求）

• 潜在竞争对手（现在不做，但随时可能进来）

2. 对手的优势和劣势是什么？

• 他什么做得好？什么做得不好？

• 他的核心竞争力是什么？

• 他的软肋在哪里？

3. 对手的战略是什么？

• 他在往哪个方向走？

• 他的重点是什么？

• 他会怎么对付我们？

4. 我们跟对手的区别是什么？

• 我们有什么不一样？

• 客户为什么选我们不选他？

• 我们的差异化在哪里？

关键提醒：不要只盯着直接竞争对手。打败你的，往往不是你以为的那个对手。比如打败康师傅的不是统一，是外卖。

### 第5看：看自己——我们有什么？

战略不是空想，是基于你有什么资源、什么能力，做最适合你的选择。

### 自我分析的四个维度

1. 我们有什么资源？

• 人：团队怎么样？核心成员厉害吗？

• 钱：有多少资金？能撑多久？融资能力怎么样？

• 关系：有什么人脉、渠道、合作伙伴？

• 品牌：有没有知名度？有没有口碑？

2. 我们有什么能力？

• 核心能力是什么？（产品？技术？营销？运营？销售？）

• 什么事我们做得比别人好？

• 什么事我们做不好？

3. 我们的优势和劣势是什么？

• 优势：我们擅长什么？我们有什么别人没有的？

• 劣势：我们缺什么？我们什么做不好？

4. 我们的愿景和使命是什么？

• 我们想成为什么样的公司？

• 我们为什么存在？

• 什么事我们就算不赚钱也想做？

用SWOT分析整理：

• S（优势）：内部的优势

• W（劣势）：内部的劣势

• O（机会）：外部的机会

• T（威胁）：外部的威胁

## 三定：做出选择

五看看完了，对局势有了清晰的认识，接下来就要做选择了——定方向、定目标、定打法。

### 一定：定方向——我们要去哪里？

战略方向，就是你选择“在哪里竞争“和“怎么竞争“。

### 三种基本战略（波特三大竞争战略）

| 战略类型 | 是什么 | 适合什么情况 |
| --- | --- | --- |
| 成本领先 | 我比别人都便宜 | 标准化产品、价格敏感的市场 |
| 差异化 | 我跟别人不一样，我有独特价值 | 客户愿意为独特价值付钱 |
| 聚焦 | 我只做一个细分市场，做到极致 | 大公司看不上的小市场 |

怎么选？

• 看你的优势是什么

• 看市场需要什么

• 看对手缺什么

关键：不要什么都想要。又想便宜又想高端又想全覆盖，最后什么都不是。

战略，不是要赢所有人，而是选择一个你能赢的战场。

### 二定：定目标——我们要做到什么程度？

方向定了，就要定具体的目标。没有目标，方向就是一句空话。

### 好目标的标准：SMART原则

• S（具体）：不能是“把业务做好“，要是“做到100万营收“

• M（可衡量）：能量化，能判断有没有达成

• A（可实现）：跳一跳够得着，不是遥不可及

• R（相关）：跟大方向相关，不是无关的目标

• T（有时限）：有截止时间，不是“以后再说“

### 目标的三个层次

• 愿景目标：3-5年，我们要成为什么样？

• 战略目标：1-2年，我们要做到什么程度？

• 年度目标：今年，具体要完成什么？

注意：目标不是越多越好。每年1-3个核心目标就够了。目标太多，等于没有重点。

### 三定：定打法——我们怎么赢？

方向和目标都有了，最后就是“怎么干“。

### 定打法的三个问题

1. 我们的核心策略是什么？

• 用什么方式达成目标？

• 关键的一招是什么？

• 什么事做对了，其他事都不重要？

2. 我们的路径是什么？

• 第一步做什么？第二步做什么？

• 先打哪里？后打哪里？

• 节奏怎么安排？

3. 我们的资源怎么配？

• 钱投在哪里？人放在哪里？

• 什么是优先级最高的？

• 什么事我们不做？

战略的核心，不是“做什么“，是“不做什么“。 什么都想做的公司，什么都做不好。战略就是取舍——取什么，舍什么。

## 附：战略的五个常见误区

误区1：战略就是目标

• “我们的战略是做到10亿”——这不是战略，这是目标。战略是“怎么做到10亿“。

误区2：战略就是想法

• 想法不值钱，谁都有想法。战略是经过系统分析、有资源支撑、有路径的选择。

误区3：战略一旦定了就不能变

• 战略是动态的，不是静态的。环境变了，战略就要调整。

• 定期复盘战略，至少每半年看一次。

误区4：战略是老板一个人的事

• 战略不是老板拍脑袋定的，是核心团队一起讨论出来的。

• 参与制定的人，执行起来才更有动力。

误区5：有战略就一定能成

• 战略只是第一步，执行才是关键。

• 好战略 + 差执行 = 0；差战略 + 好执行 > 0。

## 一句话总结

战略不是算命，是一套系统思考的方法。 先看清楚（五看），再想明白（三定），然后坚决干。 边干边调整，在战争中学习战争。
