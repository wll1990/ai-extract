## 二、课程体系：《观微识人罗盘》三天课

### 课程定位

给创业者、销售、管理者、HR——所有需要“跟人打交道“的人，一套从一线磨出来的识人成事方法论。

### 课程特色

• 不讲心法、不讲境界、不讲格局

• 只讲怎么看、怎么辨、怎么用、怎么成

• 从术出发，走到道去

• 一线磨出来的东西，才是真东西

### Day 1：看与辨——3分钟看透一个人

主题：从外表到内里，建立你的“人肉扫描仪“

#### 上午：第一层 · 3秒三看

| 模块 | 内容要点 | 练习 |
| --- | --- | --- |
| 开场导入 | 我是谁 + 为什么你会看走眼 + 课程地图（四层罗盘总览） | 破冰：每个人说一个“看人看走眼“的经历 |
| 第一看：穿着 | 看的不是贵不贵，是统不统一<br>从头到脚：头型→上衣→裤子→鞋<br>鞋是关键：底层细致程度的外露<br>三个误区：以品牌/价格/审美论人 | 案例：三张鞋的照片，判断三个人的性格 |
| 第二看：姿态 | 看的不是好不好看，是放不放松<br>身体僵硬程度 = 内心紧绷程度<br>三种姿态：紧绷型 / 放松型 / 夸张型 | 现场练习：两人一组，互看30秒，说出三个判断 |
| 第三看：眼神+微笑 | 看的不是热不热情，是真不真实<br>眼神：有光vs无神、坚定vs飘忽、直视vs躲闪<br>真笑vs假笑：眼睛先笑vs只有嘴动<br>“温暖的劲”：一个人对世界的善意 | 真假微笑练习：两人一组，互看微笑判断 |
| 第一层小结 | 3秒三看 = 做事靠不靠谱 + 做人舒不舒服 + 值不值得深交 | 3秒识人挑战：一人上台，全班观察判断 |

#### 下午：第二层 · 开口三辨

| 模块 | 内容要点 | 练习 |
| --- | --- | --- |
| 听话的两种方式 | 普通人听内容，高手听动机 |  |
| 第一辨：利己程度 | “我“字出现频率 = 焦虑程度<br>缺钱的人藏不住：三个信号<br>注意力在哪，语言就在哪 |  |
| 第二辨：客气真假 | 真客气vs假客气：有细节vs标准化<br>完美的客气 = 完美的距离<br>滴水不漏的人最危险 | 听音练习：两段对话录音，判断真假客气 |
| 第三辨：商业认知 | 懂的人：有数字、有逻辑、有对手<br>不懂的人：全是概念、全是愿景、全是别人的问题 |  |
| 第二层小结 | 开口三辨 = 生存状态 + 有没有戴面具 + 有没有真东西 |  |
| 综合演练 | 完整识人流程：3秒看 + 开口辨 | 角色扮演：A演客户，B做判断，C观察复盘 |

### Day 2：深与用——看透底色，因人成事

主题：从识人到用人，把判断力变成成交力

#### 上午：第三层 · 创始人三看

| 模块 | 内容要点 | 练习 |
| --- | --- | --- |
| 为什么先看人再看事 | 项目可以换，模式可以改，人的底色改不了 |  |
| 第一看：状态 | 创业拼到最后，拼的是体力和心力<br>身体状态：脸色、精神头、身材管理<br>精神状态：眼睛亮不亮、辩解vs思考、抱怨vs拆解<br>人性底色：创始人的人性 = 公司的天花板 |  |
| 第二看：笃定 | “信不信“比“好不好“重要一百倍<br>真笃定：往里钻、聊细节、不怕质疑、不追风口<br>假笃定：往外飘、全是概念、一质疑就急、什么热做什么<br>执念的力量：有执念的人，成是早晚的事 | 案例分析：两个创始人采访片段，判断谁真笃定 |
| 第三看：对底层的态度 | 人品的试金石<br>为什么看“下位者“：对上位者的好是演的<br>四个观察点：服务员、保洁保安、犯错下属、供应商<br>权力观：欺负人 / 做事 / 帮人 |  |
| 第三层小结 | 创始人三看 = 能不能撑到最后 + 会不会放弃 + 会不会死在人心上 |  |
| 案例分析 | 三个真实创始人案例，判断谁能成、谁会死 | 小组讨论 + 代表发言 |

#### 下午：第四层 · 成交三法

| 模块 | 内容要点 | 练习 |
| --- | --- | --- |
| 成交的真相 | 不是说服别人，是用对方的逻辑让他自己说服自己 |  |
| 筛选大于努力 | 成交率高的秘密：不行就撤，不消耗<br>把80%时间花在20%的人身上 | 自我盘点：你现在的时间花在了哪些人身上？ |
| 温暖型客户 | 特征：好说话、心软、怕拒绝人<br>怎么逼：直接逼单，别绕弯子<br>对好人，你要比他更干脆 | 话术示范 + 错误示范 |
| 犀利型客户 | 特征：理性、挑剔、有自己的判断<br>怎么逼：先解决核心需求再逼单<br>对聪明人，你要比他更专业 | 练习：怎么挖核心需求（连续问5个为什么） |
| 犹豫型客户 | 特征：纠结、拖延、怕犯错<br>怎么逼：先扎后拉，别算收益算损失<br>对纠结的人，你要比他更狠 | 话术示范：三个扎心反问句 |
| 第四层小结 | 成交三法 = 配，没有通用话术，只有匹配方法 |  |
| 逼单演练 | 三种类型客户，现场模拟 | 三人一组：客户、销售、观察员，轮换 |
| 常见错误 | ①一套话术打天下 ②该放弃的不放弃 ③逼单太急吓跑人 |  |

### Day 3：道与传——从术到道，独成一派

主题：把方法论变成你的内功，传给你的团队

#### 上午：从术到道

| 模块 | 内容要点 | 练习 |
| --- | --- | --- |
| 为什么有第五层 | 学会方法是“术“，变成自己的东西才是“道“ |  |
| 从术到道的三个阶段 | 会用 → 会说 → 会教<br>你现在在哪一层？ |  |
| 第一阶段：会用 | 把方法用在自己的工作里<br>用结果验证，不断修正 |  |
| 第二阶段：会说 | 把“感觉“说清楚<br>从隐性知识到显性方法 | 练习：用3分钟讲清楚“怎么看穿着“ |
| 第三阶段：会教 | 把方法教给团队<br>从“我厉害“到“我的团队厉害“ |  |
| 怎么复制给团队 | 三步法：①拆解成可操作的步骤 ②大量案例训练 ③实战复盘 |  |
| 你的识人体系 | 罗盘只是基础，你要加自己的东西<br>每个行业、每个岗位，重点不一样 |  |

#### 下午：场景应用 + 结业

| 模块 | 内容要点 | 练习 |
| --- | --- | --- |
| 场景应用：招聘 | 怎么用罗盘招员工？<br>不同岗位看什么？ | 小组共创：设计你们岗位的识人面试题 |
| 场景应用：合伙人 | 怎么判断一个人能不能合伙？<br>三个一票否决项 |  |
| 场景应用：投资人 | 怎么判断投资人靠不靠谱？<br>钱的背后是什么？ |  |
| 最后一课：术到极致即是道 | 你的经验，就是你最大的资产<br>不要羡慕别人的“道“，把自己的“术“磨到极致 |  |
| 行动清单 | 回去第一件事做什么？<br>三个行动：①明天见第一个人就用3秒三看 ②本周复盘三个客户 ③教给团队一个方法 |  |
| 结业仪式 | 颁发“观微阁“结业证书 + 合影 + 社群 |  |
