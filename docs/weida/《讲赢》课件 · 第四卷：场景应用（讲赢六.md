# 场景一：路演讲赢

## 第3页：站在舞台上，拿结果下台

路演的目的，不是讲完，是讲完有人行动。

• 不是“我讲得好不好“，是“投资人投不投“

• 不是“观众喜不喜欢“，是“客户买不买“

• 不是“掌声热不热烈“，是“会后有没有人找你“

路演的本质，是放大版的成交。

讲师备注： “很多人路演，追求的是’讲得好’。错了。路演追求的是’有结果’。掌声没用，赞美没用，掏钱才有用。”

## 第4页：八步成演法

① 开场 → ② 痛点 → ③ 趋势 → ④ 方案                        ↓⑧ 收尾 ← ⑦ 行动 ← ⑥ 案例 ← ⑤ 差异

1. 开场：30秒抓住注意力

2. 痛点：戳中听众的痛点

3. 趋势：为什么现在是最好的时机

4. 方案：你的解决方案是什么

5. 差异：你跟别人有什么不一样

6. 案例：谁用了，拿到了什么结果

7. 行动：你希望听众做什么

8. 收尾：一句话记住你

讲师备注： “八步成演法，是路演的标准结构。不管你讲5分钟还是50分钟，都是这个结构。短的话每步一句话，长的话每步展开讲。结构不变，内容可变。”

## 第5页：开场十法

30秒抓住注意力的十个开场方法：

1. 提问法：“你们有没有遇到过……？”

2. 数据法：“90%的创始人，都卡在了这件事上”

3. 故事法：“有个朋友，跟你们一样……”

4. 金句法：“千头万绪，一针变现。”

5. 反差法：“我今天不是来教你怎么成功的，是教你怎么少失败的”

6. 互动法：“有这个问题的举手我看看”

7. 悬念法：“你知道为什么90%的生意做不成吗？”

8. 自嘲法：“我以前是个特别不会说话的人……”

9. 权威法：“我做了20年企业服务，见过上万个创始人……”

10. 场景法：“想象一下，三个月后的今天……”

讲师备注： “开场30秒，决定了听众要不要听下去。别一上来就自我介绍、讲公司历史——没人关心。先抓住注意力，再讲别的。”

## 第6页：主体八法

路演主体部分，八个表达技巧：

1. 结论先行：每一段第一句就是结论

2. 数字说话：用数据代替形容词

3. 故事佐证：每个观点配一个小故事

4. 对比强化：用前后对比突出效果

5. 节奏变化：快慢结合，有张有弛

6. 互动参与：时不时抛个问题给听众

7. 画面感：用比喻、用场景、让听众有画面

8. 金句点缀：每5分钟一个金句，方便记忆和传播

讲师备注： “主体部分最怕什么？——平。从头到尾一个节奏，听众就睡着了。你要像过山车一样，有高有低、有快有慢、有紧张有放松。”

## 第7页：结尾三部曲

好的结尾，让听众立刻行动。

第一部：总结回顾

• “今天我讲了三件事：第一……第二……第三……”

• 帮听众梳理一遍，加深记忆

第二部：价值升华

• “所以，表达力不只是表达力，是变现力，是领导力，是你这辈子最重要的能力”

• 把价值往上拔一层

第三部：行动号召

• “如果你也想改变，现在就是最好的时机。会后找我聊聊。”

• 给出明确的行动指令

讲师备注： “很多人路演结尾说’谢谢大家’就完了。太浪费了。结尾是听众注意力最集中的时候，你要在这个时候，推他一把，让他行动。”

## 第9页：招商四讲

招商路演，比普通路演多了一层——要让别人愿意加入你。

招商四讲：

1. 讲趋势——这个行业正在发生什么变化？为什么现在是最好的时机？

2. 讲模式——我们的商业模式是什么？怎么赚钱？

3. 讲支持——加入我们，你能得到什么支持？（培训、流量、品牌、系统……）

4. 讲案例——谁加入了，拿到了什么结果？

招商的核心：让对方觉得“我也行“。

讲师备注： “招商不是画大饼，是给信心。你要让他相信——别人能做到，我也能做到。怎么给信心？——用真实的案例、用具体的支持、用清晰的路径。”

# 场景二：成交讲赢

## 第10页：不是你说服客户，是客户自己说服自己

成交的最高境界，是客户自己说服自己。

• 你说的，客户会怀疑

• 客户自己说的，他深信不疑

• 所以高手不是“会说“，是“会问“

用提问，引导客户自己得出结论。

讲师备注： “很多人以为成交就是’能说会道’，把客户说晕了就成交了。错了。客户越被你说，防备心越强。你要让他自己说——说着说着，他就把自己说服了。”

## 第11页：面对面成交七能力

① 亲和力 —— 让客户喜欢你  ↓② 提问力 —— 挖出真实需求  ↓③ 倾听力 —— 让客户觉得被理解  ↓④ 共情力 —— 建立情感连接  ↓⑤ 价值力 —— 让客户觉得值  ↓⑥ 异议处理力 —— 化解拒绝  ↓⑦ 临门一脚 —— 推动成交

讲师备注： “七个能力，一个比一个深。前面的能力是基础——客户不喜欢你，后面都白搭。后面的能力是关键——临门一脚踢不进去，前面都是白费。”

## 第12页：提问四步法（进阶版）

面对面成交的提问链条：

第一步：背景问题（建立连接）

• “你现在做什么业务？做多久了？”

• “团队有多少人？主要做哪块？”

第二步：痛点问题（挖出痛苦）

• “现在最大的困难是什么？”

• “这个问题多久了？给你造成了什么影响？”

第三步：需求问题（转向渴望）

• “如果能解决，你最想要什么结果？”

• “这个结果对你来说，意味着什么？”

第四步：成交问题（给出方案）

• “如果我有一个方法能帮你做到，你想了解一下吗？”

• “如果今天就能开始，你愿意试试吗？”

讲师备注： “提问四步法，核心是’引导’，不是’逼单’。你一步一步引导客户，让他自己说出’我需要’。他自己说出来的，比你说一百句都管用。”

## 第13页：异议处理三步法

客户说“不“的时候，怎么办？

三步法：认同 → 共情 → 引导

1. 认同：先同意他的说法，别反驳

◦ “你说得对，确实不便宜。”

2. 共情：说出他的感受，让他觉得被理解

◦ “我特别理解，换作是我，我也会犹豫。”

3. 引导：换个角度，重新定义问题

◦ “但你想想，如果这个问题不解决，你每个月损失多少？”

为什么管用？

• 你一反驳，客户就跟你对着干

• 你一认同，客户的防备心就放下了

• 防备心放下了，你说什么他才听得进去

讲师备注： “记住——客户的异议不是针对你，是针对风险。他不是拒绝你，他是在保护自己。你要做的，不是跟他辩论，是帮他消除风险感。”

## 第14页：临门一脚四类方法

怎么推动客户做决定？

| 类型 | 方法 | 话术示例 |
| --- | --- | --- |
| 假设成交法 | 假设他已经买了，问细节 | “那我们是从下周一开始，还是下周二？” |
| 二选一法 | 给两个选项，都是成交 | “你是先学三针变现法，还是直接上一针变现法？” |
| 稀缺法 | 制造稀缺感，推动决定 | “这个月还有2个名额，下个月就涨价了” |
| 风险逆转法 | 把风险揽过来，让他无后顾之忧 | “学完觉得不值，随时退给你” |

讲师备注： “临门一脚，不是’逼’，是’推’。逼的话，客户会跑。推的话，客户会往前走。力度要刚刚好——轻了推不动，重了会吓跑。”

## 第16页：算账成交法

怎么让客户觉得“太值了“？

方法：帮客户算一笔账。

算三笔账：

1. 损失账——不解决这个问题，你每年损失多少？

◦ “你现在每个月至少少赚2万，一年就是24万。”

2. 收益账——解决了这个问题，你能多赚多少？

◦ “学完之后，成交率提升20%，你一年多赚多少？至少50万吧？”

3. 投入账——跟收益比，投入算什么？

◦ “9800块钱，换一年多赚50万，这笔账，算得过来吧？”

讲师备注： “客户觉得贵，是因为他只看到了价格，没看到价值。你要帮他把价值算出来。价值算清楚了，价格就不是问题了。”

## 第17页：72小时转介绍机制

成交不是结束，是开始。

怎么让客户帮你转介绍？

72小时法则：成交后72小时内，启动转介绍。

具体动作：

1. 成交当天：发感谢信息 + 确认安排

2. 24小时内：发课前准备 + 学习建议

3. 48小时内：发一个额外的小礼物/干货（超出预期）

4. 72小时内：问一个问题——“你身边有没有跟你一样，也有表达变现卡点的朋友？”

为什么72小时内？

• 刚成交，客户满意度最高

• 超出预期的服务，让客户觉得“太值了“

• 这时候提转介绍，客户最愿意帮你

讲师备注： “转介绍不是’要’来的，是’换’来的。你先给客户超出预期的价值，客户自然愿意帮你介绍。你什么都没给，就想要转介绍，那叫索取。”

# 场景三：社交讲赢

## 第18页：高情商不是会说话，是让人舒服

社交的目的，不是“认识多少人“，是“认识对的人“。

• 加了100个微信，一个都没深度链接 = 白搭

• 认识3个同频的人，互相支持 = 赚大了

• 质量比数量重要100倍

社交的本质，是价值交换。

讲师备注： “很多人参加饭局，忙着发名片、加微信。一圈下来，加了几十个人，回头一个都记不住。为什么？——因为你没给别人留下印象，别人也没给你留下印象。无效社交，不如不去。”

## 第19页：识人三步法（社交版）

饭局上，怎么快速判断一个人值不值得深交？

第一步：观察（前10分钟）

• 他怎么跟服务员说话？

• 他坐什么位置？（主动坐主位还是靠边坐？）

• 他的眼神、语气、状态怎么样？

第二步：试探（聊几句）

• 问他是做什么的？（看他怎么介绍自己）

• 问他最近在忙什么？（看他的关注点）

• 说一个不同的观点，看他什么反应？（看他的包容度）

第三步：深聊（找机会）

• 找到共同话题，深入聊

• 用三问摸底，了解更深层的东西

• 判断：这个人，要不要继续交往？

讲师备注： “识人三步法，是社交场合的’快速筛选器’。10分钟判断一个人，比你跟他吃十顿饭都准。”

## 第20页：同频共情四步

怎么快速跟一个人拉近距离？

四步法：倾听 → 认同 → 共鸣 → 链接

1. 倾听：认真听他说，别打断，别着急说自己

2. 认同：“你说得太对了”“我特别理解”

3. 共鸣：“我也有过类似的经历……”（讲一个你的小故事）

4. 链接：“以后多交流，加个微信？”

核心：让他说，让他觉得被理解。

讲师备注： “很多人社交，忙着表现自己——我多厉害、我做了多大的事。结果呢？别人觉得你爱吹牛逼，不想跟你来往。真正的社交高手，是让对方说爽了，对方自然就喜欢你了。”

## 第21页：第一印象黄金30秒

30秒，决定了别人对你的第一印象。

三个关键：

1. 形象：穿着干净、得体、有精神

◦ 不用穿名牌，但一定要干净、合身

◦ 鞋子、头发、指甲，这些细节最容易暴露

2. 状态：微笑、眼神、声音

◦ 微笑是最好的名片

◦ 眼神要坚定，别躲闪

◦ 声音要有力，别太小声

3. 开场：第一句话说什么？

◦ 别说“你好，我是XX“（太干）

◦ 说“你好，我是XX，刚才听你说XX，特别有共鸣“（直接找连接点）

讲师备注： “第一印象一旦形成，很难改变。所以你要在30秒内，给对方留下一个好印象。怎么留？——形象+状态+开场，三件事做好了，第一印象差不了。”

## 第22页：饭局酒桌的说话艺术

饭局上，什么该说，什么不该说？

五说五不说：

| ✅ 该说的 | ❌ 不该说的 |
| --- | --- |
| 说别人的好话 | 说别人的坏话 |
| 说有趣的事 | 说抱怨的话 |
| 说对方关心的事 | 说自己多厉害 |
| 说共同话题 | 说别人听不懂的专业术语 |
| 说恰到好处的段子 | 说低俗的笑话 |

饭局上的三个角色：

• 主角：饭局的中心人物（通常是买单的或地位最高的）

• 配角：烘托气氛、帮主角搭话

• 听众：认真听、适时回应

找准你的角色，说对应的话。

讲师备注： “饭局不是演讲台，不是你表现自己的地方。饭局是社交场，是建立关系的地方。你越会让别人舒服，别人就越喜欢你。”

## 第23页：长期人脉经营之道

人脉不是“认识多少人“，是“多少人愿意帮你“。

怎么经营长期人脉？

1. 分层管理

◦ 核心圈（5-10人）：每周联系

◦ 重要圈（20-30人）：每月联系

◦ 普通圈（100-200人）：每季度联系

2. 持续给价值

◦ 看到好文章，转发给需要的人

◦ 听到好机会，介绍给合适的人

◦ 别人帮了你，一定要还，而且多还一点

3. 关键时刻出现

◦ 别人生日、节日，发个祝福

◦ 别人遇到困难，能帮就帮一把

◦ 别人有好事，真心祝福

人脉的本质：你先有用，别人才会对你有用。

讲师备注： “很多人经营人脉，就是加微信、发名片、点赞。没用。真正的人脉，是’关键时刻能用上的人’。怎么才能用上？——你先成为别人关键时刻能用上的人。”

# 场景四：管理讲赢

## 第24页：好领导，都是用嘴带团队的

管理的本质，是通过别人拿结果。

• 你自己能干，不算本事

• 你能让团队能干，才算本事

• 怎么让团队能干？——靠表达

管理表达力 = 团队执行力

讲师备注： “很多创始人，业务能力很强，但带团队不行。为什么？——因为他只会自己干，不会通过别人干。通过别人干，靠的是什么？——靠你的嘴。你说清楚了，团队才能干明白。”

## 第25页：高效会议讲话法

怎么开会，才不会“开会两小时，会后啥也没干“？

会议三段式：

会前：说清楚为什么开

• 这次会议的目的是什么？

• 要解决什么问题？

• 需要大家提前准备什么？

会中：控制节奏，聚焦结果

• 别跑题（跑题了及时拉回来）

• 每个人发言不超过3分钟

• 每个议题，必须有结论

会后：明确行动项

• 什么事？（What）

• 谁来干？（Who）

• 什么时候干完？（When）

• 怎么验收？（How）

会议结束，必须有“3W1H“。

讲师备注： “很多公司的会，开了跟没开一样。为什么？——因为没有行动项。大家聊得很嗨，散会了不知道干啥。记住：没有行动项的会，就是浪费时间。”

## 第26页：激励与批评的艺术

怎么激励，员工才会更努力？ 怎么批评，员工才会改而不抵触？

激励的三个原则：

1. 具体：别说“你真棒“，说“你这次把XX事做得特别好，尤其是XX细节“

2. 公开：表扬要公开，让所有人都知道

3. 及时：做得好立刻表扬，别等月底

批评的三个原则：

1. 具体：别说“你怎么总是犯错“，说“你这次在XX事上，犯了XX错误“

2. 私下：批评要私下，给员工留面子

3. 对事不对人：说事情，不说人品。“这件事没做好”，不是“你这个人不行“

讲师备注： “激励和批评，都是技术。不是你心好就行，你得会说。说对了，员工越干越起劲。说错了，员工越干越没劲。”

## 第27页：招人谈判技巧

怎么把优秀的人招进来？

招人不是“我要你“，是“你要来“。

招人四步：

1. 看人：用四力三问两观察，判断这个人靠不靠谱

2. 挖痛：他现在的工作，有什么不满意的？（钱？成长？空间？）

3. 给梦：来我们这，你能得到什么？（钱？成长？空间？）

4. 临门一脚：什么时候能来？

核心：不是你需要他，是他需要你。

讲师备注： “很多创始人招人，姿态放得很低——‘求求你来吧’。错了。你越求，他越不来。你要让他觉得——‘我想去，我必须去’。怎么让他这么想？——挖他的痛，给他的梦。”

## 第28页：组织表达与愿景传递

怎么让团队跟你一条心？

愿景不是挂在墙上的，是说进心里的。

愿景传递的三个层次：

1. 公司层面：我们要做什么？我们的使命是什么？

2. 团队层面：我们一起，能做成什么事？

3. 个人层面：你在这件事里，能得到什么？

最高级的愿景，是让每个人都看到自己的位置。

讲师备注： “很多创始人说’我们团队没有凝聚力’。为什么？——因为你只讲公司的愿景，没讲他的愿景。他为什么要跟你一条心？他得知道——这件事成了，他能得到什么。”

## 第29页：汇报三段式

怎么跟上级/投资人汇报，让他觉得你靠谱？

汇报三段式：结论 → 数据 → 行动

1. 结论先行：第一句就说结果

◦ “这个月业绩完成了120%，超额完成目标。”

2. 数据支撑：用数据说明情况

◦ “具体来看，新客户增长了30%，老客户复购增长了15%……”

3. 下一步行动：接下来要做什么

◦ “下个月我们计划……，预计能做到……”

别铺垫、别绕弯、别找借口。直接给结果。

讲师备注： “老板最烦什么？——员工汇报说了十分钟，还没说到重点。你要训练自己：第一句就说结论。结论说完了，再讲细节。老板想听细节，他会问的。”

# 场景五：内容讲赢

## 第30页：好内容不是写出来的，是“讲“出来的

为什么你写文案、拍视频，没人看？

因为你在“写作文“，不是在“说话“。

• 写作文：书面化、讲道理、有文采

• 说话：口语化、讲故事、有情绪

好内容的标准：像跟朋友聊天一样自然。

讲师备注： “很多人写文案，一上来就想’我要写得有文采’。错了。文案不是用来欣赏的，是用来行动的。客户看完你写的东西，愿意掏钱，才叫好文案。”

## 第31页：四步硬核内容公式

怎么写出/讲出有杀伤力的内容？

公式：观点 + 数据 + 案例 + 结果

1. 观点：你想说什么？（一句话说清）

2. 数据：用数据支撑观点（增加可信度）

3. 案例：用故事说明观点（增加代入感）

4. 结果：最后给行动指令（推动行动）

✅ 示例：

观点：小微企业主最大的问题，不是能力不够，是表达变现有卡点。 数据：我做了20年企业服务，见过上万个创始人，90%的人都卡在表达上。 案例：有个做免疫力的教授，产品很好，但就是卖不上价……（讲案例） 结果：如果你也有这个问题，评论区扣“1“，我发你一份表达力自测清单。

讲师备注： “这个公式，写文案、拍视频、做直播、发朋友圈，通用。记住四个词：观点要狠、数据要准、案例要真、结果要明。”

## 第32页：金句锻造法（6个公式）

怎么写出有传播力的金句？

| 公式 | 结构 | 示例 |
| --- | --- | --- |
| 对比式 | 不是A，是B | “商业表达不是艺术，是精准打击” |
| 因果式 | 因为A，所以B | “因为人对了，所以事早晚会对” |
| 递进式 | 不仅A，更要B | “不仅要会做事，更要会讲事” |
| 反转式 | 看起来A，其实B | “看起来是表达问题，其实是商业认知问题” |
| 数字式 | N个XX，N个XX | “千头万绪，一针变现” |
| 比喻式 | A就像B | “表达力就是变现力” |

讲师备注： “金句不是灵感迸发，是有公式的。你把这六个公式练熟了，随手就能写出金句。金句有什么用？——客户记住了你的金句，就记住了你这个人。”

## 第33页：朋友圈成交方法论

怎么发朋友圈，能成交？

朋友圈的五个内容类型：

1. 价值型：干货、方法、观点（建立专业形象）

2. 案例型：客户反馈、成交截图、成功故事（建立信任）

3. 生活型：你的日常、你的家人、你的爱好（建立真实感）

4. 观点型：你对事情的看法、你的价值观（建立人设）

5. 产品型：你的产品/服务是什么、怎么买（直接成交）

比例建议：30%价值 + 30%案例 + 20%生活 + 10%观点 + 10%产品

讲师备注： “朋友圈不是广告栏，是你的’信任阵地’。你天天发广告，别人就把你屏蔽了。你要发有价值的内容、有真实感的内容，让别人觉得’这个人靠谱’。信任建立了，成交是早晚的事。”

## 第34页：短视频表达与人设打造

怎么拍短视频，既涨粉又变现？

人设三环模型：

外环：专业标签       （你是做什么的）      ┌──────────┐      │ 中环：性格标签 │      │（你是什么样的人）│      ├──────────┤      │ 内环：价值观标签 │      │（你相信什么）│      └──────────┘

• 外环：让别人知道你是干嘛的（专业）

• 中环：让别人喜欢你这个人（性格）

• 内环：让别人认同你的理念（价值观）

三环都有，才是一个立体的人设。

讲师备注： “很多人做短视频，只做外环——天天讲专业知识。结果呢？粉丝挺多，就是不变现。为什么？——因为别人只知道你专业，不知道你是谁。没有情感连接，就没有成交。”

## 第35页：内容体系设计

怎么设计你的内容体系，让客户从“认识你“到“信任你“到“掏钱给你“？

内容金字塔：

顶层：成交内容（10%）       （直接卖产品/服务）      ┌──────────────┐      │ 中层：价值内容（30%） │      │（干货、方法、案例）│      ├──────────────┤      │ 底层：流量内容（60%） │      │（痛点、共鸣、话题）│      └──────────────┘

• 底层（60%）：抓流量，让更多人认识你

• 中层（30%）：建信任，让客户觉得你专业

• 顶层（10%）：做成交，让客户掏钱

讲师备注： “很多人做内容，要么全是流量内容（涨粉不变现），要么全是成交内容（没人看）。正确的比例是6:3:1——用流量内容拉人，用价值内容建信任，用成交内容变现。”

## 第36页：30天选题法

不知道拍什么/写什么？用这个方法，一次搞定30天选题。

三步法：

第一步：列出你的客户最常问的30个问题

• 客户问得最多的，就是最好的选题

• 从你的微信聊天记录里找、从客户咨询里找

第二步：把每个问题，变成一个内容标题

• “为什么客户总是砍价？” → “客户一砍价你就答应？教你三招守住价格”

• “怎么提升成交率？” → “成交率低的三个原因，第一个你就中了”

第三步：按内容金字塔分类

• 哪些是流量内容？（痛点、共鸣）

• 哪些是价值内容？（干货、方法）

• 哪些是成交内容？（产品、案例）

30个选题，排好表，按节奏发。

讲师备注： “选题不是靠灵感，是靠方法。你把客户的问题列出来，答案就是你的内容。客户关心什么，你就讲什么。这样的内容，没人看才怪。”

# 场景六：沙龙讲赢

## 第37页：一场沙龙，胜过一百次陌拜

为什么要做沙龙？

• 一对多成交，效率翻10倍

沙龙的本质：批量建立信任，批量成交。

讲师备注： “很多人觉得沙龙就是’分享分享’。错了。沙龙是你的’成交场’。一场好的沙龙，能顶你一个月的业绩
