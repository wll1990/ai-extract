# 团队搭建方法论：从0到1建团队的七步法

先找人，再定规矩，再拿结果，最后建文化。 团队不是招一堆人就完事了，是把一群人变成一个整体——有共同目标、有分工协作、有战斗力、有凝聚力。

## 总框架

第1步：定目标 → 第2步：定架构 → 第3步：找对人 → 第4步：立规矩                                                    ↓第7步：建文化 ← 第6步：拿结果 ← 第5步：给方法

## 第1步：定目标——我们要去哪里？

团队的起点，不是招人，是目标。没有目标，招再多的人也是乌合之众。

### 怎么定目标？

1. 目标要清晰

• 不能是“把业务做好“，要是“Q3做到100万营收，用户增长50%“

• 清晰的目标 = 具体数字 + 截止时间

2. 目标要拆解

• 大目标拆成小目标，小目标落实到每个人

• 每个人都知道“我要做什么，做到什么程度“

3. 目标要对齐

• 不是你一个人定了就完了，要跟团队对齐

• 对齐的过程，就是建立共识的过程

一句话：团队的目标，必须是“我们的目标“，不是“我的目标“。

## 第2步：定架构——谁干什么？

目标定了，再想需要什么样的人。不要先招人再想让他干什么，要先想清楚需要干什么，再招对应的人。

### 架构设计的三个原则

1. 因事设人，不是因人设事

• 先列出来“要做成这件事，需要哪几块工作“

• 再想“每块工作需要什么样的人“

• 最后才是“找谁来做“

2. 一个头原则

• 一件事只能有一个最终负责人

• 两个和尚抬水喝，三个和尚没水喝

• 责任不清，是团队最大的内耗

3. 管理幅度适中

• 一个人直接管7-8个人是比较合适的

• 管太少，浪费管理资源；管太多，管不过来

• 超过10个人，就要考虑分层了

### 早期团队的架构建议

0-10人的团队，不要搞复杂的架构，就三层：

• 创始人/负责人：定方向、找资源、扛结果

• 核心骨干：各管一块，独当一面

• 执行层：具体干活

越早期，架构越扁平。等团队大了，再慢慢加层级。

## 第3步：找对人——谁跟我们一起走？

人对了，事就成了一半。人不对，再努力也白搭。

### 招人看什么？

用四力模型判断：认知力、心力、格局力、匹配力。

早期团队招人，还有几个特别要注意的：

1. 看价值观合不合

• 早期团队人少，每个人的影响都很大

• 一个价值观不合的人，能把整个团队的味道搞坏

• 不认同组织价值观的人，绝对不能要

2. 看能不能打硬仗

• 早期团队变化快、压力大，需要能扛事的人

• 不要招“温室里的花朵“，要招“野地里的狼“

• 问他经历过最大的困难是什么，怎么走出来的

3. 看学习速度

• 早期团队什么都在变，需要快速学习的能力

• 经验重要，但学习能力更重要

• 经验是过去的，学习能力是未来的

4. 招比你厉害的人

• 很多创始人喜欢招比自己弱的人，因为好控制

• 但这样团队的天花板就是你的天花板

• 真正厉害的创始人，敢招比自己厉害的人

建设组织的思维是“求之于势，不责于人“——关键是整个环境对不对，土壤对不对。

## 第4步：立规矩——我们怎么一起干活？

没有规矩，不成方圆。团队小的时候靠感情，团队大了必须靠制度。

### 早期团队必须有的几个规矩

1. 目标和进度规矩

• 每周一开周会，定本周目标

• 每周五复盘，看完成情况

• 每天站会15分钟，同步进度

2. 沟通规矩

• 什么事用什么渠道沟通（紧急的打电话，不紧急的发消息，重要的写文档）

• 谁跟谁汇报，谁对谁负责

• 不要越级指挥，也不要越级汇报

3. 决策规矩

• 什么事谁来拍板（大事集体讨论，负责人拍板；小事自己定）

• 拍板了就执行，不许背后议论

• 可以有不同意见，但决策出来了，方向必须一致

4. 奖惩规矩

• 干好了怎么奖（钱、荣誉、机会）

• 干坏了怎么罚（批评、降薪、走人）

• 奖惩要及时，不要等年底再说

注意：规矩不是越多越好，早期团队规矩太多会束缚手脚。先有最基本的几条，慢慢加。

## 第5步：给方法——怎么帮大家干好？

人招来了，规矩立了，还不够。你还要教他们怎么干。

管理者的角色，不是监工，是教练。你要帮团队提升能力，让每个人都越来越厉害。

### 给方法的三个层次

1. 给工具

• 把你知道的好工具、好方法，教给团队

• 把经验沉淀成SOP，让新人来了就能上手

• 不要让每个人都从零开始摸索

2. 给反馈

• 干得好的，及时表扬

• 干得不好的，及时指出，告诉怎么改进

• 反馈要具体，不要“你做得不好“，要说“你在XX方面可以改进，比如……“

3. 给成长

• 给员工挑战的机会，让他做超出他当前能力一点的事

• 帮他规划成长路径，让他看到“我在这里能变成什么样“

• 员工成长了，团队自然就强了

## 第6步：拿结果——我们干得怎么样？

团队存在的意义，就是拿结果。没有结果的团队，再团结也没用。

### 拿结果的PDCA循环

P（计划）→ D（执行）→ C（检查）→ A（处理）     ↑                          ↓     └────────────────────────┘

P（计划）：定目标、定方案、定责任人、定时间 D（执行）：按计划干，遇到问题及时调整 C（检查）：定期检查进度，看有没有偏差 A（处理）：总结经验，固化成流程；找出问题，下个循环改进

### 拿结果的几个关键

1. 抓重点

• 不要什么都抓，什么都抓等于什么都没抓

• 每个阶段只有1-2个核心目标

• 把80%的精力放在最重要的20%的事上

2. 追过程

• 不要等到最后才看结果，中间要跟进

• 过程不对，结果肯定不对

• 早发现问题，早调整

3. 复盘

• 干完一件事，一定要复盘

• 不是为了追究责任，是为了下次做得更好

• 复盘的三个问题：什么做得好？什么做得不好？下次怎么改进？

## 第7步：建文化——我们是什么样的人？

文化是制度漏洞的终极补丁。制度管不到的地方，靠文化。

### 早期团队怎么建文化？

1. 创始人的样子，就是团队的样子

• 你勤奋，团队就勤奋；你偷懒，团队就偷懒

• 你真诚，团队就真诚；你虚伪，团队就虚伪

• 文化不是写在墙上的，是创始人活出来的

2. 反复讲，反复强化

• 我们是什么样的团队？我们相信什么？我们反对什么？

• 开会讲、聊天讲、招人的时候讲、发奖的时候讲

• 讲100遍，就变成文化了

3. 用行动强化

• 奖励符合文化的行为

• 惩罚违反文化的行为

• 特别是对核心成员，文化要求更高

4. 招对的人，淘汰错的人

• 文化不是靠教育出来的，是靠筛选出来的

• 招进来的人，首先要是“对的人“

• 不对的人，尽快淘汰，不要犹豫

## 附：团队搭建的五个坑

坑1：招人太快，没看清就招进来了 → 慢招人，快开人。招人慢一点，看清楚；不行的人，快点让他走。

坑2：什么人都自己带，不敢授权 → 你什么都自己干，团队永远长不大。该放的权要放，该踩的坑让他踩。

坑3：只看能力，不看人品 → 能力强但人品差的人，越厉害危害越大。人品是底线。

坑4：大锅饭，干好干坏一个样 → 必须拉开差距。优秀的人要给够，不行的人要淘汰。

坑5：只谈感情，不谈规矩 → 早期靠感情没问题，但团队大了必须有制度。感情是润滑剂，制度是骨架。
