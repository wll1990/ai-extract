# 判生意方法论：七步判生意法

判断一个生意能不能做，不是看“这个想法牛不牛“，是看“需求真不真、模式通不通、竞争赢不赢、验证过没过“。 七步走完，答案自然就出来了。

## 总框架：一句话记住

需求真假 → 天花板高低 → 模式通不通 → 竞争激不烈 → 阶段对不对 → 现金流健不健康 → 验证过没过

第1步：判需求 → 第2步：判天花板 → 第3步：判模式 → 第4步：判竞争                                                          ↓第7步：判验证 ← 第6步：判现金流 ← 第5步：判阶段

每一步都有：判断标准 + 关键问题 + 红灯信号。

## 第1步：判需求——这是不是一个真需求？

这是所有生意的起点。需求假的，后面全白搭。

### 判断标准：三个“够不够“

| 标准 | 怎么判断 | 通过的信号 |
| --- | --- | --- |
| 够痛 | 用户愿不愿意为解决这个问题付钱？ | 用户主动找解决方案，甚至自己凑合用 |
| 够频 | 这个问题多久出现一次？ | 高频（每天/每周）> 中频（每月）> 低频（每年/几年一次） |
| 够刚 | 不解决会怎么样？ | 不解决会严重影响生活/工作/心情 |

### 三个关键问题

1. “如果明天这个服务消失了，用户会难过吗？”——会难过=真需求，无所谓=伪需求

2. “用户是主动找过来，还是你硬推给他？”——主动找=真需求，推销半天才试试=伪需求

3. “用户用了之后，会不会推荐给别人？”——自发推荐=真需求，用完就忘=伪需求

### 红灯信号（出现一个就要警惕）

• 创始人说“等产品做出来了，用户就会喜欢“

• 全靠补贴拉用户，一停补贴用户就跑

• 用户说“挺好的“，但就是不掏钱

• 自己觉得“这个想法太牛了“，但没跟10个以上真实用户聊过

### 精益验证法（最快验证需求）

不要上来就做产品，先做需求探索：

1. 找10-20个目标用户深度访谈

2. 问：你最大的痛点是什么？你现在怎么解决？你愿意花多少钱解决？

3. 10个人里7个以上说“我愿意付钱“，再往下走

精益创业的核心：用最小的成本验证最大的假设。

## 第2步：判天花板——这个市场有多大？

市场体量决定了生意的上限。在小池塘里，再大的鱼也长不大。

### 三种估算方法

方法一：自上而下法（行业总量 × 你的份额）

• 优点：简单快

• 缺点：容易高估

方法二：自下而上法（用户数 × 客单价 × 复购 × 渗透率）

• 优点：更实在

• 缺点：需要的参数多

方法三：类比法（参考成熟市场/类似行业）

• 优点：有参照系

• 缺点：国情不同，不能直接照搬

### 三个关键问题

1. 这个市场现在有多大？未来三年能长多大？（增速>20%是高速增长）

2. 你能切到的那块市场有多大？（不是整个市场，是你真正能触达的部分）

3. 市场是在变大还是变小？（增长的市场水涨船高，萎缩的市场逆势而为太难）

### 红灯信号

• 张口就说“这是个万亿市场“，但说不清楚自己能切多少

• 市场很小，还在萎缩

• 市场很大，但全是巨头，根本挤不进去

## 第3步：判模式——商业模式能不能跑通？

商业模式就是“你怎么赚钱“。但不只是“卖什么赚差价“，是一整套利益相关者的交易结构。

### 工具：商业模式画布（9宫格）

┌──────────┬──────────┬──────────┐│ 重要伙伴  │ 关键业务  │ 价值主张  ││          │ 核心资源  │          │├──────────┼──────────┼──────────┤│ 客户关系  │ 渠道通路  │ 客户细分  │├──────────┼──────────┼──────────┤│ 成本结构  │          │ 收入来源  │└──────────┴──────────┴──────────┘

核心是中间的“价值主张“——你到底给用户提供了什么价值？其他8个模块都是围绕这个转的。

### 商业模式五问（快速版）

1. 你卖的是什么？（产品/服务/平台/数据/会员…）

2. 卖给谁？（目标客户画像越清晰越好）

3. 怎么卖？（获客渠道和成本）

4. 赚多少？（客单价、毛利率、复购率、LTV）

5. 凭什么是你赚？（护城河在哪里）

### 四类护城河（判断生意能不能长久）

| 护城河类型 | 是什么 | 例子 |
| --- | --- | --- |
| 无形资产 | 品牌、专利、技术、牌照 | 可口可乐的品牌、药企的专利 |
| 成本优势 | 规模效应、流程优势、独特资源 | 沃尔玛的规模采购、富士康的效率 |
| 网络效应 | 用户越多越有价值，越用越离不开 | 微信、滴滴、淘宝 |
| 迁移成本 | 用户走不了，换一个代价太大 | 苹果生态、企业SaaS软件 |

注意：好的产品本身不是护城河。你产品做得好，别人可以抄。只有当产品好到形成了品牌、网络效应或迁移成本，才是护城河。

### 红灯信号

• 说不清楚“怎么赚钱“，只说“先有流量再说“

• 毛利率低于20%，还很重运营

• 获客成本 > 客单价（永远赚不回来）

• 没有任何护城河，谁都能做

## 第4步：判竞争——竞争格局怎么样？

再大的市场，如果竞争太惨烈，你也赚不到钱。

### 工具：波特五力模型

潜在进入者的威胁                         ↑供应商议价能力 ← 现有竞争者的竞争程度 → 购买者议价能力                         ↓                    替代品的威胁

五力越强，行业越难做；五力越弱，行业越舒服。

### 快速判断竞争格局的三个问题

1. 行业前三名是谁？加起来占多少市场份额？（前三占70%以上=寡头垄断，新进入者很难）

2. 如果BAT/字节/美团也做这件事，你怎么办？（他们做了我就死了=没有护城河）

3. 这个行业的价格战打得凶不凶？（天天打价格战=同质化严重，赚不到钱）

### 红灯信号

• 行业已经有绝对巨头，你跟他做的一模一样

• 所有人都在打价格战，毛利越来越低

• 门槛极低，谁都能进来做

• 替代品很多，用户随时可以换

## 第5步：判阶段——行业处在什么位置？

同样的生意，在不同的阶段，玩法完全不一样。

### 用渗透率判断行业生命周期

| 阶段 | 渗透率 | 特点 | 适合做什么 |
| --- | --- | --- | --- |
| 萌芽期 | < 10% | 教育市场成本高，不确定性大 | 适合有技术、有耐心的玩家 |
| 快速增长期 | 10%-50% | 需求爆发，格局未定 | 最好的窗口期，冲就完了 |
| 成熟期 | 50%-80% | 格局基本定型，剩者为王 | 看效率和成本，拼运营 |
| 饱和期 | > 80% | 存量博弈，增长停滞 | 看整合和出海，找第二曲线 |

### 三个关键问题

1. 这个行业现在是在加速增长，还是已经放缓了？

2. 现在进场是早了还是晚了？（最好的时机是快速增长期的早期）

3. 未来三年，这个行业会变成什么样？（看趋势，不要只看现在）

### 红灯信号

• 所有人都在说“这是风口“，说明已经到风口后期了

• 行业增速明显下滑，还在往里挤

• 你进场的时机，既不是最早的，也不是最快的，还不是最有资源的

## 第6步：判现金流——生意能不能自己造血？

很多生意看起来很美好，但死在了现金流上。现金流是生意的血液。

### 现金流健康度的六个指标

| 指标 | 健康标准 | 危险信号 |
| --- | --- | --- |
| 收钱方式 | 先收钱后干活（预付费） | 先干活后收钱（应收账款） |
| 付费模式 | 订阅制/复购制（持续收钱） | 一锤子买卖（一次性） |
| 获客成本 | CAC < LTV的1/3 | CAC > LTV（永远赚不回来） |
| 毛利水平 | 毛利率 > 40% | 毛利率 < 20% |
| 增长方式 | 越做越赚钱（边际成本递减） | 越做越烧钱（边际成本递增） |
| 现金储备 | 能撑18个月以上 | 只能撑3个月以内 |

LTV/CAC > 3 是健康生意的基本标准。

### 三个关键问题

1. 不融资的话，你能活多久？（能活18个月以上=安全）

2. 每赚一块钱，需要投入多少钱？（投入少赚得多=好生意）

3. 收入是一次性的，还是持续的？（持续收入有积累，越做越轻松）

### 红灯信号

• 永远在融资，永远不赚钱

• 应收账款越来越多，回款越来越慢

• 增长全靠烧钱，一停烧就不增长

• 毛利越来越低，靠规模撑着

## 第7步：判验证——有没有跑通过？

前面六步都是分析和判断，但分析得再透彻，也不如真实世界的一次验证。

### 验证的两个核心假设

1. 价值假设：用户用了之后，真的觉得有价值吗？

• 验证标准：用户会不会主动回来用？会不会推荐给别人？

2. 增长假设：用户会自发带来新用户吗？

• 验证标准：自然增长率是多少？病毒系数K > 1吗？

### MVP验证三步法

第一步：需求探索 → 第二步：用户验证 → 第三步：推广放量（找10-20个用户聊）  （做MVP跑通闭环）   （加大投入规模化）

MVP不是“残缺版的产品“，是用最少的精力完成一次“开发—测量—认知“的反馈循环。

MVP可以是：一个视频、一个落地页、一个微信群、一次线下活动——只要能验证核心假设就行。

### 三个关键问题

1. 你验证过了吗？验证了什么？结果怎么样？（有真实数据=靠谱，全是“我觉得“=不靠谱）

2. 跑通最小闭环了吗？（从获客→转化→交付→复购，全链路跑通了吗？）

3. 单位经济模型算得过来吗？（单客LTV > 单客CAC + 单客服务成本）

### 一个直觉判断标准

成功到来时你总会感觉得到——媒体主动报道、投资者追着投钱、消费者主动推荐、销售增长超过扩招速度。如果你并没有这种感觉，那就说明你并没有取得突破性成功。

## 综合判断：七步评分表

每步10分，总分70分。

| 步骤 | 权重 | 评分（1-10） | 核心判断 |
| --- | --- | --- | --- |
| 1. 需求 | 20% |  | 真不真、痛不痛、刚不刚 |
| 2. 天花板 | 15% |  | 市场够不够大、增长够不够快 |
| 3. 模式 | 15% |  | 能不能赚钱、有没有护城河 |
| 4. 竞争 | 15% |  | 竞争激不激烈、有没有差异化 |
| 5. 阶段 | 10% |  | 时机对不对、是不是窗口期 |
| 6. 现金流 | 15% |  | 能不能自己造血、健不健康 |
| 7. 验证 | 10% |  | 有没有跑通过、数据怎么样 |

判断标准：

• 56分以上（80分制换算）：可以做，值得重仓投入

• 42-56分（60-80分）：可以做，但要想清楚差异化和切入点

• 42分以下（60分以下）：别做，或者再想想

三个一票否决项（命中一个就pass）：

1. 需求是假的——用户根本不买单

2. 算不过账——LTV < CAC，永远赚不回来

3. 没有任何差异化——跟别人一模一样，凭什么是你赢？

## 附：判断生意的“灵魂十问“

拿到任何一个生意，先问这十个问题，快速过一遍：

1. 这是谁的什么痛点？有多痛？

2. 用户愿意付钱吗？付多少？

3. 市场有多大？增速多少？

4. 你怎么赚钱？毛利多少？

5. 你的护城河是什么？

6. 竞争对手是谁？你跟他们的区别是什么？

7. 行业处在什么阶段？现在进场是早还是晚？

8. 获客成本多少？LTV多少？

9. 不融资能活多久？

10. 你验证过了吗？数据怎么样？

## 一句话总结

判断一个生意能不能做，不是看“这个想法牛不牛“，是看“需求真不真、模式通不通、竞争赢不赢、验证过没过“。 七步走完，答案自然就出来了。
