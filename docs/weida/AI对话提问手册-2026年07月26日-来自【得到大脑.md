# AI对话提问手册

核心心法：你问得越精确，AI答得越有用。AI是你的“思考外脑“，不是“答案机器“。会提问的人，AI是核武器；不会提问的人，AI是高级搜索。

## 第一阶：基础公式——四步写出高质量Prompt

目标：告别“帮我写个方案“这种废话提问，让AI一次就给你想要的东西。

### 四步公式

#### 1. 角色设定（你是谁）

“你是一个有10年经验的商业咨询师，专门帮中小企业做增长策略。” “你是一个资深的文案编辑，擅长写小红书爆款笔记。”

• 给AI一个身份，它的回答就会有“专业感“

• 身份越具体，回答越对味

• 别只说“你是一个专家“，要说“你是哪个领域、做了多少年、擅长什么的专家“

#### 2. 背景描述（什么情况）

“我有一个客户，做餐饮连锁的，目前有5家店，主要客群是25-35岁的白领。现在遇到的问题是……” “我要写一篇关于’创始人IP打造’的公众号文章，目标读者是中小企业创始人……”

• 背景越详细，AI越不会跑偏

• 把你知道的所有相关信息都告诉它

• 别怕啰嗦，信息越多，质量越高

#### 3. 任务要求（做什么）

“请你帮我设计一套3个月的增长方案。” “请你帮我写一个标题，10个备选。”

• 任务要具体，别模糊

• “帮我想想办法”= 没用

• “帮我设计一套3个月的增长方案，分阶段、有指标”= 有用

#### 4. 输出格式（怎么给我）

“请用表格形式呈现，分阶段、核心动作、预期效果、所需资源四列。” “请分三点回答，每点不超过100字。” “请用小红书风格，带emoji，开头有钩子，结尾有互动。”

• 格式定好了，你拿到就能用，不用再整理

• 你要什么格式，就说什么格式

• 表格、列表、分点、对话体、剧本……你说什么，AI就给什么

### 一个完整的例子

“你是一个有10年经验的商业咨询师，专门帮中小企业做增长策略。 我有一个客户，做餐饮连锁的，目前有5家店，主要客群是25-35岁的白领。现在遇到的问题是：新客越来越少，老客复购率低，外卖占比太高导致利润薄。 请你帮我设计一套3个月的增长方案。 请用表格形式呈现，分阶段、核心动作、预期效果、所需资源四列。”

## 第二阶：进阶用法——把AI从“工具“用成“搭档“

目标：不只是让AI“干活“，而是让AI“帮你想“。

### 六种高阶玩法

#### 1. 角色扮演法——让AI变成你想要的任何人

“请你扮演刘润，用他的风格和逻辑，帮我分析一下这个商业问题。” “请你扮演一个挑剔的投资人，对我的路演稿提10个最尖锐的问题。” “请你扮演我的客户，用最刁钻的角度反驳我的方案。”

• 让AI变成你的“ sparring partner（陪练）“

• 你想练什么，就让AI扮演什么

• 比你自己一个人想，效率高10倍

#### 2. 反向提问法——让AI帮你找问题

“请你帮我看看这个方案，有什么漏洞？” “如果这个方案失败了，最可能的原因是什么？” “站在竞争对手的角度，你会怎么攻击我这个方案？”

• 人最容易犯的错，就是看不到自己的盲区

• AI没有立场，它能帮你看到你看不到的东西

• 罗翔说：“认识到自己的有限性，是智慧的开始。”——AI就是帮你认识有限性的工具

#### 3. 头脑风暴法——让AI当你的创意合伙人

“围绕’个人IP打造’这个主题，帮我想20个选题方向，越奇葩越好。” “帮我想10个完全不同的商业模式，来做这件事。” “如果完全不考虑钱，这件事最疯狂的做法是什么？”

• 人的思维容易被经验框住，AI没有框

• 让它“越奇葩越好““越疯狂越好”，先发散，再收敛

• 20个想法里，只要有1个能用，就值了

#### 4. 苏格拉底式提问——让AI帮你想清楚

“我现在有一个困惑：要不要辞职创业。请你用苏格拉底式提问，一步步帮我梳理，不要直接给答案。”

• 苏格拉底式提问，就是不断追问“为什么““然后呢”“还有呢”

• 你不是要AI给你答案，你是要AI帮你把自己的思路理清楚

• 答案其实你心里有，只是你自己没看见

#### 5. 迭代优化法——一次不行，就多来几次

第一次：“帮我写一个朋友圈文案。” 第二次：“刚才的太官方了，再口语化一点，像聊天一样。” 第三次：“开头不够抓眼球，帮我换5个不同的开头。” 第四次：“把第三版和第五版的优点结合一下，再润色润色。”

• 别指望一次就完美

• AI的好处就是：你让它改，它就改，而且永远不烦

• 迭代3-5次，质量会有质的飞跃

#### 6. 知识萃取法——让AI帮你读书

“请你总结《沟通的方法》这本书的核心观点，用10个要点呈现。” “请你对比一下《影响力》和《先发影响力》的区别。” “请你用刘润的七层提问法，帮我设计一套客户诊断清单。”

• 你不用读每一本书，你让AI帮你读

• 但注意：AI可能会“幻觉“，重要的观点要核实

• 最好的用法是：你先读过，让AI帮你整理和串联

## 第三阶：场景实战——四个高频场景的Prompt模板

### 场景一：帮客户做诊断

“你是一个有10年经验的商业咨询师。 我的客户是做XX行业的，目前的情况是：XX（描述现状）。 请你帮我设计一套诊断提问清单，用来找出他的核心问题。 要求：

1. 按刘润的七层问题抽屉结构组织

2. 每个层级3-5个问题

3. 问题要具体、可落地，不能太泛

4. 用表格呈现：层级、问题、目的“

### 场景二：写营销文案

“你是一个资深的文案策划，擅长写能卖货的文案。 产品是：XX（产品介绍） 目标用户是：XX（用户画像） 核心卖点是：XX（3个以内） 发布平台是：小红书/朋友圈/公众号 请你写3个不同风格的版本：

1. 痛点型：开头戳痛点，中间给方案，结尾促行动

2. 故事型：用一个小故事引入，自然带出产品

3. 对比型：用前后对比凸显效果 每个版本不超过300字。“

### 场景三：做会议纪要

“以下是一段会议录音的文字稿： （粘贴文字稿） 请你帮我整理成会议纪要，要求：

1. 会议主题

2. 参会人员

3. 核心讨论点（分点列出）

4. 达成的共识

5. 待办事项（责任人+截止时间）

6. 下次会议时间 控制在500字以内。“

### 场景四：学一个新概念

“我想了解’第一性原理’这个概念。 请你用费曼学习法的方式给我讲解：

1. 先用大白话解释，让一个小学生也能听懂

2. 举3个不同领域的例子

3. 说清楚它的适用边界——什么时候有用，什么时候没用

4. 最后给我一个行动建议：我怎么在工作中用起来“

## AI提问的五个禁忌

1. 别太模糊：“帮我写个方案”= 垃圾输出。你自己都不知道要什么，AI怎么知道？

2. 别一次问太多：一个Prompt只做一件事，多件事就分多次问

3. 别全信：AI会“幻觉“，会一本正经地胡说八道。重要的事实、数据、引用，一定要核实

4. 别让AI替你做决定：AI可以给你分析、给你选项，但最终决定要你自己做

5. 别只用中文：有些问题用英文问，质量更高——尤其是技术类、学术类问题

## 一句话总结

AI时代，会提问的人，指挥AI；不会提问的人，被AI指挥。

你的提问质量，决定了AI的输出质量，也决定了你和AI的合作效率。
