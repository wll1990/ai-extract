## 第3页：底层逻辑——商业表达力三维模型

商业表达力 = 商业认知 × 表达技术 × 心力强度

商业认知       /      /     /____ 表达技术     |     |     心力强度

乘法关系：缺一个维度，整体就是零。

• 有认知、没技术 = 茶壶里煮饺子，倒不出来

• 有技术、没认知 = 花架子，说不到点子上

• 有认知、有技术、没心力 = 关键时刻掉链子

讲师备注： “很多人以为表达力就是’会说话’，错了。会说话只是表达技术。真正的商业表达力，是三个维度相乘的结果。你哪一维最弱，哪一维就是你的天花板。”

# 第一针：痛点针——一句话戳中客户心窝子

## 第5页：为什么客户没感觉？

因为你讲的都是“你关心的“，不是“他关心的“。

• 你讲产品功能，他关心的是“我能得到什么“

• 你讲专业术语，他关心的是“能不能解决我的问题“

• 你讲你有多厉害，他关心的是“跟我有什么关系“

客户不关心你是谁，他只关心你能不能解决他的问题。

讲师备注： “我见过太多人，一开口就是’我们公司怎么样’‘我们产品怎么样’。讲了五分钟，客户已经在玩手机了。为什么？——因为跟他没关系。”

## 第6页：痛点三层模型

痛点不是一个点，是三层。

深层痛点       （恐惧/渴望）      ┌──────────┐      │ 中层痛点  │      │（具体困难）│      ├──────────┤      │ 表层痛点  │      │（表面抱怨）│      └──────────┘

• 表层痛点：客户嘴上说的（“太贵了”“没时间”）

• 中层痛点：客户实际遇到的困难（“没人帮我做”“不知道怎么做”）

• 深层痛点：客户内心的恐惧或渴望（“怕失败”“想被认可”“想赚钱”）

高手直接扎深层，新手停在表层。

讲师备注： “客户说’太贵了’，真的是钱的问题吗？不一定。可能是他觉得不值——这是中层痛点。也可能是他怕买了没用、怕被人说乱花钱——这是深层痛点。你只在表层跟他砍价，永远谈不拢。”

## 第7页：痛点深挖五问法

怎么从表层挖到深层？问五个问题。

Q1：你现在遇到的最大问题是什么？（表层） → 客户会说一堆表面的抱怨

Q2：这个问题给你造成了什么具体的困难？（中层） → 客户开始说具体的影响

Q3：如果这个问题不解决，会怎么样？（往深层推） → 客户开始说后果

Q4：这个后果，你能承受吗？（再推一把） → 客户开始面对真实的恐惧

Q5：如果解决了这个问题，你最想得到什么？（转向渴望） → 客户说出内心真正的渴望

讲师备注： “五个问题问完，客户自己就把自己说服了。因为不是你告诉他’你有问题’，是他自己说出来的。人只会相信自己说的话，不会相信你说的话。”

## 第8页：一句话痛点公式

怎么用一句话，戳中客户的痛点？

公式：你是不是也遇到了XX问题？然后XX后果？

❌ 错误示范：

• “我们的产品很好用”（自嗨）

• “你需要提升表达力”（说教）

• “很多人都有这个问题”（太泛）

✅ 正确示范：

• “你是不是也遇到过这种情况——产品很好，但一谈价格客户就砍价？砍到最后，你都不想做了？”

• “你是不是也觉得，自己挺有才华的，但就是赚不到与之匹配的钱？心里特别憋屈？”

讲师备注： “痛点公式的关键——不是说’你有问题’，是说’你是不是也遇到了’。一个’也’字，瞬间拉近距离。他会觉得’对！就是这样！你懂我！’”

## 第9页：提问四步法

怎么用提问，把客户从痛点带到成交？

背景 → 痛点 → 需求 → 成交

1. 背景问题：了解基本情况（“你现在做什么业务？做多久了？”）

2. 痛点问题：挖出具体痛苦（“现在最大的困难是什么？”）

3. 需求问题：转向解决方案（“如果能解决，你最想要什么结果？”）

4. 成交问题：给出你的方案（“如果我有一个方法能帮你做到，你想了解一下吗？”）

讲师备注： “提问四步法，是面对面成交的黄金链条。一步一步，把客户从’我没事’带到’我需要’。别跳步，跳步就会被拒绝。”

## 第10页：不同场景的痛点打法

| 场景 | 痛点打法 | 示例 |
| --- | --- | --- |
| 短视频/文案 | 开头第一句就扎痛点 | “你是不是也……” |
| 面对面成交 | 用提问挖痛点 | “你现在最大的困难是什么？” |
| 路演/演讲 | 用场景描述痛点 | “想象一下，如果你……” |
| 朋友圈 | 用共鸣戳痛点 | “有没有人跟我一样……” |
| 沙龙/会销 | 用互动找痛点 | “有这个问题的举手” |

讲师备注： “不同场景，痛点的打法不一样。但核心是一样的——从客户的角度出发，说他关心的话，戳他真实的痛。”

## 第11页：落地工具 · 痛点清单

📋 你的产品/服务痛点清单

第一步：列出你的客户最常抱怨的10件事（表层痛点） 第二步：每件事往下挖三层——具体困难是什么？后果是什么？深层恐惧/渴望是什么？ 第三步：选出最痛的3个痛点 第四步：用一句话痛点公式，写出3个痛点话术 第五步：拿去测试——哪个反应最大，就用哪个

讲师备注： “痛点不是你想出来的，是客户说出来的。别坐在办公室里想，去跟客户聊。聊10个客户，你就知道真正的痛点是什么了。”

# 第二针：差异针——让客户立刻觉得你不一样

## 第12页：为什么客户选你不选别人？

因为你跟别人不一样。

• 如果你跟别人一样，客户凭什么选你？

• 如果你跟别人一样，客户凭什么给你高价？

• 如果你跟别人一样，你最后只能拼价格

没有差异化，就没有定价权。

讲师备注： “很多人说’我们产品质量好’‘我们服务好’。我说——别人也这么说。你说的跟别人一样，那就等于没说。”

## 第13页：差异化的三个维度

你可以从三个地方找差异化：

人的差异化       （你就是差异化）      /     /    /  方法的差异化   /  （你的方法不一样）  / /产品的差异化（产品本身不一样）

1. 产品差异化——功能、质量、价格、包装

2. 方法差异化——你的方法、流程、体系不一样

3. 人的差异化——你这个人就是差异化（你的经历、你的风格、你的价值观）

产品最容易被抄，方法其次，人最难抄。

讲师备注： “小微企业、个人品牌，最容易做的差异化是什么？——人的差异化。因为产品你干不过大公司，方法别人也能学。但你这个人，别人抄不了。你的经历、你的故事、你的风格，都是独一无二的。”

## 第14页：差异三找法

怎么找到你的差异化？三个方向。

找法一：反向找——别人都在说什么？你反着说。

• 别人都说“越多越好“，你说“少即是多“

• 别人都说“快速暴富“，你说“先活下来“

• 别人都说“技巧方法“，你说“心力修炼“

找法二：细分找——你在哪个细分领域最强？

• 不是“做营销的“，是“专门帮医美机构做私域的“

• 不是“做培训的“，是“专门教创始人商业表达的“

• 不是“做咨询的“，是“专门帮小微企业做变现诊断的“

找法三：组合找——把两个不相关的东西组合起来

• 识人 + 表达 = 讲赢

• 中医 + 心理学 = 身心疗愈

• 美食 + 教育 = 亲子厨房

讲师备注： “差异化不是’比别人好’，是’跟别人不一样’。好是主观的，不一样是客观的。你只要不一样，客户就会记住你。”

## 第15页：“不是…而是…“句式

怎么用一句话说出你的差异化？

公式：我们不是XX，而是XX。

❌ 错误示范：

• “我们跟别人不一样”（空泛）

• “我们更好”（自嗨）

• “我们更专业”（谁都这么说）

✅ 正确示范：

• “我们不是教你演讲技巧的，而是帮你用表达变现的。”

• “我们不是做普通营销的，而是专门帮医美机构做私域变现的。”

• “我们不是卖课程的，而是你的商业表达军师。”

讲师备注： “这个句式的威力在哪？——它先否定一个客户熟悉的东西，再给出一个新的定位。一推一拉之间，客户立刻就记住你了。”

## 第16页：一句话价值主张

怎么用一句话，说清你是谁、你能干嘛、你不一样在哪？

公式：我是XX，我帮XX人，用XX方法，解决XX问题，得到XX结果。

✅ 示例：

• “我是讲赢的郭老师，我帮小微企业主，用识人+判事+变现三位一体的方法，解决表达变现有卡点的问题，让他们的才华配得上他们的努力。”

拆解：

• 我是谁 → 讲赢的郭老师（身份）

• 帮谁 → 小微企业主（人群）

• 用什么方法 → 识人+判事+变现三位一体（方法差异化）

• 解决什么问题 → 表达变现有卡点（痛点）

• 得到什么结果 → 才华配得上努力（价值）

讲师备注： “这句话，你要练到脱口而出。别人问你’你是做什么的’，你一秒钟就能说出来。说不清楚，就是你自己没想清楚。”

## 第17页：差异符号设计

怎么让你的差异化，看得见、记得住？

• 名字符号：一针变现法、三针变现法、观微识人法（有画面感、有记忆点）

• 数字符号：四力三问两观察、七步判生意、三针合一（数字好记）

• 比喻符号：军师、一针、闭环（有画面感）

• 金句符号：千头万绪，一针变现；讲赢，就是赢（朗朗上口）

符号化的差异化，才是真正的差异化。

讲师备注： “为什么要做符号？因为人记不住复杂的东西，但记得住符号。你一说’三针’，客户立刻就知道是什么。你一说’一针变现’，客户立刻就有画面感。符号，就是你的记忆锚点。”

## 第18页：落地工具 · 差异化定位表

📋 差异化定位工作表

第一步：列出你的3个直接竞争对手 第二步：他们都在说什么？（找共同点） 第三步：用差异三找法，找出你的3个差异化方向 第四步：用“不是…而是…“句式，写出你的差异化表达 第五步：写出你的一句话价值主张 第六步：设计你的差异符号（名字/数字/比喻/金句） 第七步：拿去测试——客户听完能不能记住你？

讲师备注： “差异化不是一劳永逸的，是要不断打磨的。今天的差异化，明天可能就不是了。所以你要持续迭代，持续找新的差异点。”

# 第三针：信任针——不用吹牛逼，客户自动信你

## 第19页：为什么客户不信你？

因为你一开口就在吹牛逼。

• “我们是最好的”

• “我们的产品是顶级的”

• “我们服务了上千家客户”

客户的第一反应：你就吹吧。

讲师备注： “越吹，客户越不信。你越说自己厉害，客户越觉得你在忽悠。信任不是吹出来的，是建起来的。”

## 第20页：信任五层塔

信任是一层一层建起来的。

第五层：真实人设       （你是个真实的人，不是神）      ┌──────────────┐      │ 第四层：逻辑自洽 │      │（你说的话前后一致，有道理）│      ├──────────────┤      │ 第三层：客户证言 │      │（别人说你好，比你自己说管用）│      ├──────────────┤      │ 第二层：案例结果 │      │（具体的案例和数据）│      ├──────────────┤      │ 第一层：专业背书 │      │（头衔、证书、资历）│      └──────────────┘

从下往上建，一层比一层强。 最高级的信任，是真实人设。

讲师备注： “很多人一上来就想建第五层——我要做IP，我要有人设。错了。信任得从第一层开始建。先有专业背书，再有案例结果，再有客户证言，再有逻辑自洽，最后才是真实人设。顺序反了，就是空中楼阁。”

## 第21页：第一层：专业背书

怎么让客户觉得你专业？

• 头衔背书：XX创始人、XX专家、XX导师

• 证书背书：资格证、认证、奖项

• 资历背书：做了多少年、服务了多少客户、有多少经验

• 平台背书：上过什么节目、写过什么书、在什么平台开课

注意：背书是基础，不是全部。 只有背书没有案例，就是纸老虎。

讲师备注： “背书有用吗？有用。但别把背书当全部。客户最终看的，还是你能不能帮他解决问题。背书是敲门砖，案例是试金石。”

## 第22页：第二层：案例结果

怎么用案例建立信任？

案例三段式：困境 → 挣扎 → 突破 → 结果

1. 困境：客户之前遇到了什么问题？（让听众代入）

2. 挣扎：客户试过了哪些方法？都没用（放大痛点）

3. 突破：遇到你之后，发生了什么转变？（引入你的方法）

4. 结果：最后拿到了什么具体结果？（用数据说话）

✅ 示例：

“有个做免疫力的教授，之前同时做四件事，忙得要死还不赚钱（困境）。他也试过请运营团队、做投放，钱花了不少，效果都不好（挣扎）。后来用了一针变现法，砍掉三件事，只做培训（突破）。半年后收入翻了2.5倍，人还轻松了（结果）。”

讲师备注： “案例不是’客户用了我们的产品，效果很好’。那叫广告，不叫案例。好的案例，是有故事、有起伏、有数据的。客户听完，自己就会想’我也想变成那样’。”

## 第23页：第三层：客户证言

怎么让客户证言更有说服力？

三个原则：

1. 具体不空洞

◦ ❌ “郭老师讲得真好”

◦ ✅ “学完三针变现法，我用在客户身上，当周就多签了两单，多赚了3万块”

2. 有身份有名字

◦ ❌ “某客户”

◦ ✅ “XX公司创始人 张总”

3. 视频 > 音频 > 文字

◦ 视频最真实，文字最容易造假

◦ 有条件就拍视频，没条件就用语音条

讲师备注： “客户证言的核心——不是夸你好，是说他自己得到了什么。越具体、越有数据、越真实，说服力越强。”

## 第24页：第四层：逻辑自洽

怎么让客户觉得“你说的有道理“？

• 前后一致：你说的话不能前后矛盾

• 有因有果：因为A，所以B，所以C，逻辑链条清晰

• 符合常识：别讲反常识的东西，除非你有足够的证据

• 敢于承认：不是什么都能解决，有边界才可信

最高级的逻辑自洽——你说的话，客户自己能推出来。

讲师备注： “什么叫逻辑自洽？就是你不用吹牛逼，客户自己就能推导出’你应该很厉害’。怎么推导？——从你的方法、你的案例、你的思考方式里推导。”

## 第25页：第五层：真实人设

最高级的信任，是让客户觉得“你是个真实的人“。

怎么建立真实人设？

• 说真话：好的坏的都说，别只说好的

• 露弱点：你也有搞不定的事，你也有脆弱的时候

• 有温度：关心客户这个人，不只是关心他的钱

• 有立场：该拒绝的拒绝，该坚持的坚持

完美的人不可信，真实的人才可信。

讲师备注： “很多人做IP，想把自己塑造成完美的神。错了。神是用来拜的，不是用来信的。人是用来信的。你越真实，客户越信你。你越完美，客户越觉得你假。”

## 第26页：“反着说“的信任技巧

怎么用“自曝其短“建立信任？

方法：先讲自己的缺点，再讲优点。

✅ 示例：

“说实话，我们的课不便宜。9800块钱，对很多人来说不是小数目。但我敢说——你上完课，带回去的变现方案，至少值98000。如果觉得不值，你随时来找我。”

为什么管用？

• 你主动说缺点，客户会觉得你诚实

• 缺点说完了，优点就更有说服力

• 客户的防备心，一下就放下了

讲师备注： “这个技巧，用好了威力巨大。但有个前提——你说的缺点，不能是致命的。你不能说’我们的课质量不好’，那是找死。你说的缺点，得是’贵’‘严’’难’这种——侧面证明你有料。”

## 第27页：信任阶梯成交法

怎么一步一步建立信任，最后成交？

第五阶：真实人设 → 成为粉丝  ↑第四阶：逻辑自洽 → 认同理念  ↑第三阶：客户证言 → 放下防备  ↑第二阶：案例结果 → 看到希望  ↑第一阶：专业背书 → 初步认可

成交不是一步到位的，是一步一步往上爬的。 信任到了，成交是水到渠成的事。

讲师备注： “很多人犯的错——刚认识就想成交。信任还在第一阶，你就想收高价，可能吗？你得一步一步往上带。带到第五阶，客户不仅自己买，还帮你卖。”

# 三针合一：变现闭环

## 第29页：三针怎么组合？

不同场景，三针的顺序不一样。

| 场景 | 三针顺序 | 为什么 |
| --- | --- | --- |
| 短视频/文案 | 痛点→差异→信任 | 先抓注意力，再给理由，最后建信任 |
| 面对面成交 | 痛点→信任→差异 | 先建立信任，再说你不一样，最后成交 |
| 路演/演讲 | 差异→痛点→信任 | 先亮差异抓眼球，再讲痛点共鸣，最后用案例建信任 |
| 朋友圈 | 信任→痛点→差异 | 朋友圈是信任场，先建信任，再戳痛点，最后给方案 |
| 沙龙/会销 | 痛点→信任→差异 | 先集体戳痛点，再用案例建信任，最后给差异化方案 |

讲师备注： “三针不是固定顺序，是灵活组合的。你要根据场景、根据客户、根据你跟客户的关系，调整顺序。顺序对了，事半功倍。顺序错了，事倍功半。”

## 第30页：一针变现完整话术模板

面对面成交的完整话术（三针合一）：

第一步：痛点针（提问四步法）

• 背景：“你现在做什么业务？做多久了？”

• 痛点：“现在最大的困难是什么？”

• 需求：“如果能解决，你最想要什么结果？”

第二步：信任针（案例三段式）

• “之前有个客户，跟你情况差不多……（困境）”

• “他也试过很多方法，都没用……（挣扎）”

• “后来用了我们的方法……（突破）”

• “最后拿到了什么结果……（结果）”

第三步：差异针（不是…而是…）

• “我们跟别人不一样。我们不是XX，而是XX。”

• “所以我们能帮你做到XX结果。”

第四步：成交

• “如果我也能帮你做到这个结果，你想试试吗？”

讲师备注： “这套话术，你拿去就能用。但记住——话术是死的，人是活的。别硬背，要理解背后的逻辑。逻辑通了，你怎么说都对。”
