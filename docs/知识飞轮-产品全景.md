## 阶段一：素材上传 — 把专家的脑子"搬"进系统

### 做什么

企业提供销售专家的真实对话录音或文档 → 系统自动提取为结构化的"技能颗粒"。

### 一条素材能产出什么

一段 30 分钟的电话录音，经过 AI 处理后：

```
📄 原材料（销售对话文本）
     ↓
🔬 AI 自动拆解为 4 个维度的"技能颗粒"：

   ① 专家的思考："客户说贵，80% 不是真觉得贵，是在试探你的底线"
   ② 专家的原话："王总我理解，咱们换个角度看——您现在对比的是价格，
       还是三年总成本？"
   ③ 新手的常见错误："新人一听砍价就直接报折扣，没问客户对比的是哪个版本"
   ④ 什么时候有效："确认竞品是相同功能级别时，这个话术成功率最高"
```

### 为什么必须有这一步

没有这一步，AI 分身就是"空壳"——只能靠通用大模型胡编。有了这一步，AI 分身肚子里才有"真货"。

## 阶段二：分身使用 — 用户怎么从"不知道问什么"到"越问越上瘾"

### 三种使用场景

| 场景 | 用户心态 | 典型问题 | AI 怎么答 |
|------|---------|---------|-----------|
| **快问快答** | "马上要见客户了，急" | "客户说太贵了怎么回" | 直接给话术，分步骤，标注每句话的用意 |
| **深度请教** | "想学透这招" | "你是怎么判断客户是真想买还是比价的" | 拆判断逻辑 → 不同策略的选择依据 → 真实案例 |
| **实战对练** | "练练手，别到客户面前露怯" | 系统扮演客户，用户练习回应 | AI 扮客户刁难，练完打分点评，告诉你哪里没做好 |

### 用户可以感知到的质量信号

| 看到什么 | 意味着什么 |
|----------|-----------|
| 🟢 高匹配 | AI 的回答直接引用了这个场景下的真实经验，高度可信 |
| 🟡 参考 | AI 参考了相关场景的经验，有一定参考价值 |
| ⚪ 无匹配 | AI 实话实说"我不太了解"，并推荐你问其他问题 |
| 👍👎 打分 | 用户可以评价回答有没有用 |

## 阶段三：知识如何反馈 — 每一个用户行为都在"投喂"系统

### 用户不经意间贡献的数据

| 用户行为 | 系统学到什么 |
|----------|-------------|
| 问了一个新问题 | 系统记录："有人想知道 XXX"，如果多次出现 → 管理员应该补充这类知识 |
| 打了个 👍 | 这个颗粒确实有效 → 它的权重上升，未来更容易被检索到 |
| 打了个 👎 | 这个颗粒有问题 → 标记待审查，管理员会来检查和修改 |
| 点推荐问题继续聊 | 系统知道："这个推荐是有效的"，推荐算法更准 |
| 对练后看评价 | 系统记录用户薄弱点 → 下次推荐针对性练习 |

### 数据长什么样（管理员视角）

```
分身"张销售"本周数据:

📊 使用情况
  对话 247 次 ｜ 👍 满意率 87% ｜ 活跃用户 38 人

🔴 需要关注的
  5 条颗粒被踩了 ≥ 3 次 → 管理员该去看看了
  12 个用户问了但系统答不上来的问题 → 该补充了

📈 趋势
  满意率从上周的 82% 升到 87% —— 上周改的 3 条颗粒见效了
```

## 阶段四：反馈与优化 — 发现一个问题，消灭一类问题

### 可以调整的 5 个维度

管理员看到反馈数据后，可以在以下 5 个层面进行精准调整：

| 调整维度 | 什么时候调 | 怎么调 | 生效时间 |
|----------|-----------|--------|----------|
| **颗粒话术** | 用户 👎 说"话术太生硬" | 编辑 `standard_script` 字段，改成更自然的表达 | 下一次对话 |
| **颗粒逻辑** | 用户 👎 说"判断逻辑不对" | 编辑 `expert_thought` 字段，补充更准确的判断依据 | 下一次对话 |
| **颗粒覆盖** | 多人问同样的问题但系统答不上来 | 补充新颗粒（约专家再录一段，或从已有素材重新萃取） | 新颗粒上线后 |
| **画像人格** | AI 说话风格不像真人 | 调整 personality / speaking_style 参数 | 下一次对话 |
| **提示词** | 整体行为不符合预期（如回答太长/太短/结构不对） | 编辑 prompt 模板 → 发布新版本 | 下一次对话 |

### 优化实例

```
问题发现:
  6 个用户问了"怎么跟技术负责人打交道"，AI 的回答都是通用销售话术，
  用户 👎 率 40%

根因分析:
  颗粒库里缺少"技术决策者"这个细分场景的颗粒
  现有颗粒都是面向"经济决策者(老板/采购)"的

优化动作:
  ① 约销冠补录 15 分钟关于"如何影响技术负责人"的对话
  ② 上传 → AI 自动萃取 → 新增 8 条颗粒，场景标签"技术决策者"
  ③ 管理员审核通过 → 发布

效果验证:
  一周后，同类问题的 👍 率从 60% 提升到 89%
```

### 优化效率指标

| 维度 | 当前状态 | 优化后目标 |
|------|---------|-----------|
| 发现问题的周期 | 用户反馈但没人看 | 每周自动汇总 |
| 修复一个颗粒的时间 | — | 5 分钟（打开→编辑→保存） |
| 补充一个场景的时间 | — | 30 分钟（录对话→AI 萃取→审核发布） |
| 修复后验证 | — | 用"测试对话"功能立即验证 |

## 阶段五：最终效果 — 分身越来越聪明

### 进化曲线

```
满意度
 100% ┤
  90% ┤                                    ╭────── 第 3 个月
  85% ┤                           ╭────────╯
  80% ┤                  ╭────────╯
  75% ┤         ╭────────╯
  70% ┤────────╯
      └───────┼────────┼────────┼────────┼────────
            第1周    第2周    第1月    第2月    第3月

第 1 周: 上线，100 条初始颗粒，用户发现问题多
第 2 周: 第一轮优化，修复低分颗粒，补充高频缺口 → 满意度攀升
第 1 月: 第二轮优化，覆盖了 80% 的常见场景 → 满意度稳定在 85%
第 3 月: 长尾问题持续收敛，行业模板开始沉淀 → 满意度趋近 90%
```

### 跨客户的网络效应

```
客户 A（制造业）上线 3 个月 → 积累 500 条颗粒，满意度 88%
  │
  ├─ 制造业行业模板沉淀："报价策略""供应链谈判""技术选型" 等场景
  │
  ▼
客户 B（制造业）新上线 → 直接用行业模板冷启动
  │  初始颗粒 150 条（是 A 的 1.5 倍）
  │  初始满意度 80%（比 A 上线时高 10%）
  │
  ▼
客户 B 补充了自己独特的场景 → 模板进一步丰富
  │
  ▼
客户 C 上线 → 初始颗粒 200 条 → 初始满意度 83% → ...
```

**每多一个客户，行业模板就多一份数据；每个新客户的上线体验都比上一个好。**

### 商业化价值

| 阶段 | 客户看到的价值 | 我们的壁垒 |
|------|--------------|-----------|
| 上线第 1 周 | "AI 好像还不太行" | 行业模板降低冷启动成本 |
| 上线第 1 月 | "越来越准了，有点像真人了" | 飞轮开始转动，满意度上升 |
| 上线第 3 月 | "新销售培训就靠它了" | 颗粒质量 = 数据壁垒 |
| 上线第 6 月 | "换不了别的平台了" | 切换成本极高 |

### 一句话总结

**用户用得多 → 反馈就多 → 优化就快 → 分身就更准 → 用户就更愿意用。这就是飞轮。**
