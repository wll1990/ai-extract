## 3. 实机发现的 DDL 缺陷（五个角色都没看出来）

**`training_assignment.status varchar(20)` 装不下 `pending_certification`（21 字符）。**

触发条件：最后一个必修任务通过 → `markPendingCertification` 写 21 字状态 → `value too long for type character varying(20)` → 500，认证链路整条断掉。
T1–T4 的实机从未走到「必修全过」，所以一直没暴露；T5 复核通过后第一次触发。

修复：DDL 与实体列宽改 32，并在脚本注释里写明原因；开发库已 `ALTER COLUMN` 并重启清缓存计划。
证据：修复后复核通过 → 分配进入 `pending_certification`，计数 `completed 1 / passed 1 / requiredPassed 1`（补考不重复计完成）。
