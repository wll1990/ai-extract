## 一、统一命名规范（2026-07-22 审定）

| 维度 | API 字段 | 用户可见名 | 副标题 |
|------|---------|-----------|--------|

## 二、代码流程图

### 2.1 QA / Talk 模式（共用 ChatStreamService.chat()）

```
用户输入 / 点击推荐问题
    │
    ▼  POST /skills/{skillId}/chat { mode: "qa"|"talk", message: "..." }
    │
    ▼
┌─ ChatStreamService.chat() ───────────────────────────────────────────┐
│                                                                       │
│  Phase 1: Setup (同步)                                                │
│  ├─ skillRepository.findById()         ← 校验分身存在/可聊天          │
│  ├─ interceptGuest()                   ← C端游客限流(速率+日配额)     │
│  ├─ profileRepository.findBySkillId()  ← 画像完整性检查              │
│  ├─ resolveMode(mode, message)         ← qa→quick/discuss, talk→talk │
│  ├─ convPersistence.upsertConversation() ← 会话查找/创建+保存用户消息 │
│  ├─ ragPipelineService.buildRagHistory()    ← DB最近12条历史          │
│  ├─ ragPipelineService.rewriteQuery()       ← LLM查询改写(≤30字)     │
│  └─ ragPipelineService.retrieveGrainsWithScores() ← pgvector topK=5  │
│                                                                       │
│  Phase 2: Stream (异步, SSE, 120s超时)                                │
│  ├─ promptAssembly.buildSkillSystemPrompt()                           │
│  │   ├─ 模板: skill_qa_chat.md (QA) / skill_talk.md (Talk)           │
│  │   ├─ 注入画像 + 经验上下文(tier标记) + 模式指令 + 边界规则         │
│  │   └─ Talk额外: 社交规则(闲聊/话题切换/感谢收尾)                   │
│  ├─ promptAssembly.buildChatMessages() ← system+最近20条+当前消息     │
│  ├─ chatStreamAdapter.chatStream()     ← DeepSeek LLM 流式调用        │
│  └─ convPersistence.saveAiMessage()    ← 保存AI回复+grainId+reportId  │
│                                                                       │
│  Phase 3: Post-stream (Flux.concat)                                   │
│  ├─ ChatChunk.meta(convId)              ← conversationId              │
│  ├─ buildSourceChunkFlux()              ← 溯源 source event           │
│  │   └─ reportId + grainIds + grainTags + avgScore + avgSimilarity   │
│  ├─ RAG无匹配? → SSE suggested 事件     ← 推荐回退问题               │
│  └─ conversationStatsRepository.save()  ← 统计埋点(doFinally)        │
└──────────────────────────────────────────────────────────────────────┘
    │ SSE: content → source → suggested → meta → done
    ▼
┌─ 前端渲染 ───────────────────────────────────────────────────────────┐
│  SkillChatView / ChatActive / MobileChatShell                         │
│  ├─ 逐 chunk 渲染 AI 回复文本                                          │
│  ├─ onSource → MessageBubble 展示匹配度标签                            │
│  │   ├─ sim≥50% → 🏅 精准匹配 (绿)                                    │
│  │   ├─ sim≥30% → 📎 关联匹配 (蓝)                                    │
│  │   └─ sim<30%  → ✦ 综合画像生成                                     │
│  ├─ 溯源按钮(非综合) → TraceabilityDrawer 抽屉                        │
│  └─ onSuggested → 展示推荐问题                                        │
└──────────────────────────────────────────────────────────────────────┘
```

## 四、各模式分端详解

### 4.1 QA 模式（经验请教）

#### 主前端 (`/skill/[skillId]`)

```
切换到 💬 经验请教
  │
  ├─ 开场: PortraitCard + TrustBadge + openingMessage
  ├─ SceneTagBar: 横向滚动 pill（场景名 + 颗粒数），点击加载专属话题
  ├─ 场景上下文导航: ← 上一场景 | 当前场景 ✕ | 下一场景 →
  ├─ 对话: SkillChatView → MessageBubble (匹配度标签 + 溯源按钮)
  ├─ 反馈: 每条 AI 回复底部 👍👎
  └─ 历史: HistorySidebar (右侧滑入 overlay)
```

#### 企业端 (`/chat/[skillId]`)

```
切换到 🔍 经验请教
  │
  ├─ ChatEntry: 头像 + openingMessage + 场景 pill + 精选话题
  ├─ 对话: ChatActive → MessageBubble (企业主题)
  ├─ 匹配度: 绿色/黄色徽章 + 溯源展开
  └─ 历史: HistorySidebar (左侧固定280px)
```

#### H5 分享页 (`/s/[shareCode]`)

```
打开分享链接 → 默认 QA
  │
  ├─ 名片卡片: 头像 + 价值主张 + TrustBadge
  ├─ 场景标签: 水平可滚动按钮(第一个"推荐"徽章)
  ├─ 对话: 蓝色渐变用户气泡 + 白色 AI 气泡
  ├─ 溯源: <details> 原生展开/折叠
  ├─ 限制: isLimitReached → 输入禁用 + "注册解锁"按钮
  └─ 历史: HistoryDrawer (左侧抽屉85%)
```

### 4.2 Talk 模式（轻松交流）

#### 主前端（默认入口）

```
进入页面 → 默认 ☕ 轻松交流
  │
  ├─ 开场白 (t=0ms, fadeIn)
  ├─ 欢迎引导语 (t=300ms): "在开始之前，我想先了解你..."
  ├─ 精选话题 (t=600ms): RecommendedQuestions 按钮列表
  ├─ 对话: placeholder="聊聊你的想法..."
  └─ 边界: AI 域外→礼貌拒绝+引回 / 闲聊→自然回应1-3轮
```

#### 企业端（默认入口）

```
进入页面 → 默认 💬 轻松交流
  │
  ├─ ChatEntry: mode='talk' 时不展示场景标签
  ├─ 精选话题: 竖向按钮列表
  └─ placeholder: "聊聊你的想法..."
```

#### H5 分享页

```
底部 [聊天] tab
  │
  ├─ 引导语: "随便聊聊，就像老同事一样。"
  ├─ 推荐问题: 竖向列表(💬图标+>箭头)，优先 talkQuestions，回退到3个硬编码
  ├─ 提示: "也可以直接在下面打字说你想聊的 ↓"
  └─ 对话: 同 QA 消息渲染
```

### 4.3 Practice 模式（实战演练）

#### 主前端

```
点击 🎯对练
  │
  ├─ Phase select: 场景网格 → 用户选一个
  ├─ Phase active: AI 客户先说话 → 用户回应
  │   ├─ 实时教练卡片 (hits/misses/technique)
  │   └─ 消息>3条 → "结束对练" 出现
  ├─ Phase evaluate: 四维评分 + 优点/改进 + demoScript + 趋势图
  └─ 返回: 底部 "↩ 返回对话" → 回到 Talk
```

#### 企业端（独立实现，739行）

```
点击 🎯对练
  │
  ├─ Phase select: 场景卡片网格(6个+加载更多)
  ├─ Phase active: roleLabel="我（销冠）" vs "客户"
  │   └─ 无教练卡片（无 hits/misses/technique）
  ├─ Phase evaluating→result: 仅流式文本，无四维分数卡片，无趋势图
  └─ 返回: onBack → chat.reset() + setMode('talk')
```

#### H5 分享页

```
底部 [对练] tab
  │
  ├─ 场景选择: "选择一个场景开始对练" + 标签+颗粒数+›
  ├─ 对练中: 复用 PracticeChatSection
  ├─ 游客限制: 对练轮次计入免费消息，超额→RegisterSheet
  └─ 评价: 同主前端（复用 PracticeChatSection）
```

### 4.4 管理后台

```
管理后台不提供独立的三种对话模式入口。
对练预览仅在审核页通过 PracticeScenarioModal 测试单个颗粒的对练效果。

/admin/skills/[id]/audit — 四步审核向导:
  Step 1 (explicit): 知识外化 → 解析清洗
  Step 2 (skill):    经验→技能 → AI提取验证
  Step 3 (scene):    技能→场景 → PracticeScenarioModal 单颗粒测试
  Step 4 (product):  场景→产品 → 报告/画像/发布

ProductDemoModal — 四种验证模式:
  - practice (角色扮演) / qa (问答) / demo (自动演示) / debug (全量验收)

发布条件: 活跃颗粒≥10 + 场景覆盖≥3 + 画像完整
```

## 八、商业化分析（供产品和运营讨论）

### 8.1 当前转化漏斗

```
c_guest (游客, H5分享页)
  → 5条/天免费消息
  → 超额 → "注册解锁"弹窗
  → 注册 → c_user
  → 可以继续聊天 + 可以做访谈（最多3次免费萃取）

gap: 注册后没有付费入口，3次访谈用完=死胡同
```

### 8.2 数据飞轮

```
用户提问 → RAG检索 → AI回答 → 用户反馈(👍👎)
    │                      │              │
    ▼                      ▼              ▼
knowledge_gap          grain_retrieve   feedback_log
(知识缺口)             _log (匹配度)    (满意度)
    │                      │              │
    └──────────────────────┴──────────────┘
                          │
                          ▼
                  conversation_stats
                  (每次AI回复的质量、耗时、RAG分层)
```

### 8.3 对练的商业价值

- **用户侧**：看到四维评分趋势 → "练习→评价→改进→再练"的行为闭环
- **企业侧**：量化销售培训 ROI，发现短板场景
- **当前差距**：企业端无四维评分展示，体验不完整

### 8.4 建议优先级

1. **企业端 Practice 迁移到 shared-ui** — 减少维护成本，统一体验
2. **企业端加四维评分卡片 + 趋势图** — 补齐对练闭环
3. **C 端付费入口** — 访客→注册已有，缺注册→付费
