## 流程① 萃取师技能

```
输入                        处理                         输出
──────────────────────────────────────────────────────────────────
萃取师信息                   上传到 expert_skill 表        expert_skill 记录
· 姓名                       status=pending               · id
· 风格标签（银行、B2B等）                                  · name / styleTags
· 行业标签（金融、制造等）                                  · status: pending→extracting→active
· 资历描述
                                                          expert_document 记录
文件（可选）                  Python parse-file            · id / expertId
· .docx / .pdf / .md         提取纯文本                     · fileName
                                                          · parsedContent（纯文本）
                              ExpertAnalysisScheduler
                              每30秒扫描 pending 任务
                              乐观锁抢任务
                              UPDATE WHERE locked_by IS NULL
                              
                              analyzeMaterials()
                              ┌─ 步骤1: 解析文件为纯文本
                              └─ 步骤2: promptLoader.format(
                                   "expert_document_extraction.md")
                                 → AI 分析 → 七章 JSON 报告
                                 → report 表 content_json
                              
                              structureExpertReport()
                              调 AI 重新格式化为六章 JSON
                              
                              extractGrains()
                              ┌─ 优先: extractGrainsFromReportContent()
                              │   promptLoader.format(
                              │   "expert_grain_extraction.md")
                              │   → AI 拆解为 expert_grain[]
                              └─ 降级: generateDefaultExpertGrains()
                                  硬编码3条基础法则

                              POST /admin/experts/{id}/activate    expert_grain 记录（N条）
                              → expert_grain.status=active         · expertId
                              → expert_skill.status=active         · category（7类之一）
                              → regenerateComposite()              · knowledgeContent
                                合并所有萃取师法则                  · applicationRule
                                (共识/独家/矛盾)                   · priority（1-5）
                                                                  · status: under_review→active

注入访谈                      创建访谈时选 [综合/指定/无]
                              → loadExpertKnowledge(expertSkillId)
                              → 查 active expert_grain
                              → 按 category 分组
                              → 拼入 interview_system.md
                                的 {expert_knowledge} 占位符
                              → AI 学会用萃取师方法论追问
```

## 流程② 销冠访谈

```
输入                        处理                         输出
──────────────────────────────────────────────────────────────────
创建访谈                      POST /interviews              interview_session 记录
· spaceId                     InterviewService              · id (sessionId)
· topic（主题）                .createSession()             · spaceId
· expertSkillId（可选）        ┌─ 解析萃取师风格            · topic
· interviewType               ├─ 生成温暖开场语            · status: created
  (sales/expert)               │   promptLoader.format(     · currentPhase: opening
                              │   "interview_opening.md")  · expertSkillId
                              ├─ 保存 session              · 6个collect字段（全false）
                              └─ 保存开场AI消息             
                                                            interview_message 记录
                                                           · 开场AI引导消息（温暖版）

对话消息                      POST /interviews/{id}/chat    interview_message 记录（持续追加）
· message（用户输入）          InterviewService              · role: user/ai/system
                              .processMessageToWriter()     · content
                              ┌─ 保存用户消息               · phase（所属阶段）
                              ├─ loadInterviewSystemPrompt  · depth（追问深度）
                              │   注入萃取师经验

                              ├─ 调 AI (SSE流式)
                              │   → chunk 逐字返回
                              │   → phase_change 阶段切换
                              │   → collect_update 采集更新
                              └─ 前端接收 → 更新消息列表
                                 → 更新采集面板
                                 → 更新进度条

                              采集状态变更                  interview_session 更新
                              6个模块实时标记               · collectCaseStory → true
                              · 案例故事(storytelling)      · collectSteps → true
                              · 核心步骤(modeling)          · collectDecision → true
                              · 关键决策(modeling)          · collectMindset → true
                              · 专家心法(modeling)          · collectBoundary → true
                              · 适用边界(closing)           · collectChecklist → true
                              · 行动清单(closing)

阶段推进                      用户点击推进按钮              interview_session 更新
                              POST /interviews/{id}         · currentPhase 推进
                              /mark-phase-complete          interview_message 记录
                              ┌─ 内容预检（最少消息数）      · 阶段分隔消息
                              ├─ 标记当前阶段采集字段        · AI过渡/致谢消息
                              ├─ AI 生成阶段小结/过渡       前端更新
                              ├─ SSE: phase_change          · 进度条节点变化
                              │        collect_update       · 采集面板状态变化
                              └─ closing 完成时：           · 引导卡样式（新阶段）

                                 AI 温暖致谢

完成后                        checkAndCompleteSession()     report 记录
                              6模块全true + phase=closing   · id (reportId)
                              → ReportGenerationService     · spaceId / sessionId
                                 .generateReport()          · title / subtitle
                              ┌─ 调 Python AI                · contentJson（六章JSON）
                              │  /internal/report/generate  · wordUrl / pptUrl
                              └─ generateFilesAsync()
                                 ├─ 生成 Word（HTML→.doc）  experience_grain 记录（N条）
                                 ├─ 生成 PPT（POI）         · spaceId / reportId
                                 └─ extractExperienceGrains  · sceneTag（破冰/异议处理...）
                                    promptLoader.format(    · sceneDescription

                                    → AI 拆解锦囊[]         · standardScript
                                    → 降价: 基础法则         · commonMistakes
                                                            · applicableCondition
                              激活 Skill                   skill 记录
                              → skill.status = "active"     · status: generating→active
                                                            · spaceId

```
输入                        处理                         输出

· mode (quick/discuss)       ┌─ 查 skill 状态              ├─ source: reportId+报告名

                               │  grainRepository

                               │  promptLoader.format(
                               │  "skill_qa_system.md")
                               │  · {owner_name} = 周铭
                               │  · {owner_title} = 华东区销冠
                               │  · {experience_context} = 
                               │    按场景分组的颗粒全文
                               │  · {mode_instruction} = 
                               │    快问快答/深度探讨
                               ├─ 注入对话历史（最近12条）
                               └─ 调 AI (SSE 流式)

                              或 grain.unhelpfulCount++

## 流程④ 分身对练

```
输入                        处理                         输出
──────────────────────────────────────────────────────────────────
选择场景                      GET /skills/{id}             前端场景列表
· skillId                     /practice-scenes             · label / title / setting
                              SkillService                  / customerLine / grainCount
                              .getPracticeScenes()
                              从 experience_grain
                              按 scene_tag 分组
                              → 每组建一个场景

开始对练                      POST /skills/{id}            practiceId
· scene / customScene          /practice/start             场景信息
                              SkillService.startPractice() · scene.title / setting
                              → 返回场景设定+客户开场白      / customerLine

对练回应                      POST /skills/{id}            前端 SSE 流式
· practiceId                   /practice/respond           ┌─ chunk: 客户回应逐字
· message（员工回应）          SkillService                 └─ done: 完成
· sceneContext（场景上下文）    .respondPracticeToWriter()
· history（对话历史）          ┌─ promptLoader.format(
                              │  "skill_practice_customer.md")
                              │  · {scene_context}
                              │  · {history}
                              │  · {last_message}
                              │  → AI 扮演客户回应
                              └─ SSE 流式返回

结束对练                      POST /skills/{id}            前端综合评价卡片
· conversation（完整对话）      /practice/evaluate          · score（AI打分，1-100）
· scene（场景描述）            SkillService                 · strengths[]（做得好的点）
                              .evaluatePracticeToWriter()  · improvements[]（需改进的点）
                              ┌─ promptLoader.format(      · demo_script（销冠示范话术）
                              │  "skill_practice_evaluate.md") · next_advice（下次建议）
                              │  · {owner_name}
                              │  · {conversation}
                              │  · {scene}
                              │  → AI 以销冠视角复盘
                              └─ SSE 流式返回 JSON
```

## 汇总

```
┌──────────────────────────────────────────────────────────────────────┐
│                         四流程输入 → 输出                             │
│                                                                      │
│  流程①                         流程②                                │
│  萃取师 → expert_grain         销冠 → experience_grain               │
│  输入: 人物信息+文件            输入: 主题+对话消息                   │
│  输出: 7类萃取法则              输出: 六章报告+N条场景锦囊            │
│                                                                      │
│  流程③                         流程④                                │
│  experience_grain → 回答       experience_grain → 场景              │
│  输入: 问题+对话历史            输入: 对练回应+对话历史               │
│  输出: 销冠人格化回答           输出: 客户回应+综合评价               │
│                                                                      │
│  核心数据流:                                                         │
│  ① expert_grain ──注入──→ ② 访谈 ──产出──→ experience_grain          │
│                                   └────加载──→ ③ 问答               │
│                                   └────加载──→ ④ 对练               │
│                                                                      │
│  数据飞轮:                                                           │
│  更多① → 更好② → 更丰富锦囊 → 更精准③④ → 更多使用 → 更多访谈       │
└──────────────────────────────────────────────────────────────────────┘
```
