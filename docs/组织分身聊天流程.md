```java
Skill skill = skillRepository.findById(skillId).orElse(null);
```

## 2. chatOrganization() 三阶段管线

**ChatStreamService.chatOrganization()** — [ChatStreamService.java:318-438](backend/src/main/java/com/aiextract/service/ChatStreamService.java#L318-L438)

### Phase 0：前置校验

```
① 状态检查 → 必须是 "published"（无 admin/owner 豁免）
② 游客拦截 → 频率限流 + 每日免费额度
③ 成员解析 → resolveMemberSpaceIds() → 取所有已发布成员的 spaceId 列表
④ 空成员保护 → spaceIds 为空 → 返回错误 "组织分身尚未关联任何已发布成员分身"
```

### Phase 1：Setup（同步）

```
⑤ upsertConversation() → 创建/获取会话记录
⑥ ragPipelineService.rewriteQuery() → Query 改写（指代消解）
⑦ ragPipelineService.retrieveGrainsWithScores(query, spaceIds, topK, domain)
     → 多空间并行 pgvector 检索（CompletableFuture 并行）
     → tier 分层（high ≥0.50 / ref ≥0.30）
     → min-similarity 硬拦截
⑧ promptAssembly.buildOrgSkillSystemPrompt() → 构建 System Prompt（见 §3）
⑨ promptAssembly.buildChatMessages() → [system] + [最近20条历史] + [当前消息]
```

### Phase 2：Stream（SSE 流式）

```
⑩ chatStreamAdapter.chatStream(messages, context)
     → Flux<ChatChunk> 逐 token 推送 type="content" 事件
     → append aiContent StringBuilder
```

### Phase 3：Post-stream（AI 回复完成后）

```
⑪ ChatChunk.meta(conversationId)        → type="meta"
⑫ buildMultiSpaceSourceChunkFlux()       → type="source"（见 §6）
```

### doFinally：统计写入

```
⑬ ConversationStats 写入
     - skillType = "organization"
     - ragHighCount / ragRefCount / ragNoneCount
     - ragAvgSimilarity
     - totalDurationMs / llmDurationMs
     - isTest（管理员测试标记）
```

## 3. System Prompt 构建

**PromptAssemblyService.buildOrgSkillSystemPrompt()** — [PromptAssemblyService.java:388-470](backend/src/main/java/com/aiextract/service/PromptAssemblyService.java#L388-L470)

### 步骤 1：成员名解析（批量，2 次 DB 查询）

```
RAG 返回的 grains → distinct spaceIds
  ① skillRepository.findBySpaceIdIn(spaceIds) → ownerName
  ② 未命中 → spaceRepository + userRepository → user.name
  → Map<spaceId, ownerName>
```

### 步骤 2：经验上下文拼接（按成员分组）

```markdown
## 张经理 🟢 · 85%
- 场景：价格谈判
  思考：先确认客户预算区间...
  话术："这个价格我们确实..."
  避坑：不要一开始就降价...

## 李总监 🟡 · 62%
- 场景：客户异议
  思考：...
```

分组键是 `spaceId`（不是 sceneTag），每个成员一条 `##` 标题 + 匹配度颜色标注。

### 步骤 3：模板选择

| mode | 模板 | Prompt 定位 |
|------|------|-----------|
| `qa` | `org_skill_qa.md` | "团队知识库"，标注来源成员 |
| `talk` | `org_skill_talk.md` | "部门前辈们"，自然对话 |
| `practice` | `org_skill_practice_customer.md` | AI 扮演客户 |

### 步骤 4：变量注入

```
{org_name}        = skill.displayName（部门名）
{background}      = skill.description（部门描述）
{experience_context} = 上面的 Markdown
```

**关键**：组织分身没有 `SkillProfile`，不注入 personality/speakingStyle/background 等个人画像字段。AI 角色是"团队"而不是"个人"。

## 4. 成员解析

**OrganizationSkillService.resolveMembers()** — [OrganizationSkillService.java:208-213](backend/src/main/java/com/aiextract/service/OrganizationSkillService.java#L208-L213)

```
skill.member_skill_ids（JSONB: ["uuid1","uuid2",...]）
  → JsonUtil.parseList() → List<UUID>
  → skillRepository.findAllById(ids) → 一次批量查询
  → filter(status == "published")   → 只取已发布成员
  → resolveMemberSpaceIds()         → map(Skill::getSpaceId).distinct()
```

**设计要点**：
- `member_skill_ids` 是 JSONB 数组，无外键约束
- `findAllById` 一次查询，不 N+1
- `published` 过滤是安全网——已废弃成员自动排除
- `distinct()` 防止同一 space 被多次检索

## 5. 多空间 RAG 检索

**RagPipelineService.retrieveGrainsWithScores(List<UUID> spaceIds)** — [RagPipelineService.java:310-408](backend/src/main/java/com/aiextract/service/RagPipelineService.java#L310-L408)

```
每个 spaceId → CompletableFuture.runAsync 并行
  → grainRetriever.retrieveWithScores(query, spaceId, topK)
  → 结果合并到 ConcurrentHashMap + synchronizedList
  → 统一 min-similarity 硬拦截
  → tier 分层 + sceneTag 关键词加权
  → 写 GrainRetrieveLog（每条命中颗粒一行）
  → 无结果时写 KnowledgeGap

返回: GrainResult(grains, tiers, similarities)
```

与个体分身的区别：多空间并行检索 + 全局去重排序，其余一致。

## 7. 对话持久化

组织分身对话写入同一张 `skill_conversation` 和 `skill_message` 表，与个体分身共用。区分方式：

| 维度 | 识别方式 |
|------|---------|
| `skill_conversation.skill_id` | 组织分身的 skill UUID |
| `conversation_stats.skill_type` | `"organization"` |
| AI 消息 `role` | `"assistant"`（相同） |

## 8. 组件依赖链

```
SkillController
  → ChatStreamService
    → OrganizationSkillService (resolveMembers, resolveMemberSpaceIds)
    → RagPipelineService (retrieveGrainsWithScores 多空间)
      → GrainRetriever (pgvector HNSW 每空间)
    → PromptAssemblyService (buildOrgSkillSystemPrompt)
    → ConversationPersistenceService (upsertConversation, saveAiMessage)
    → ConversationStatsRepository (统计写入)
```

循环依赖已消除：`ShareService → SkillService → OrganizationSkillService`（单向 DAG）。

---

## 9. 与个体分身聊天的关键差异

| 维度 | 个体分身 | 组织分身 |
|------|---------|---------|
| spaceId | 必有值，一个 space | 多个成员的 spaceId 列表 |
| RAG | 单空间检索 | 多空间并行检索 |
| System Prompt 角色 | "我是{name}"，第一人称 | "我们是{部门}"，团队口吻 |
| SkillProfile | 注入 personality/speakingStyle | 无，用部门描述替代 |
| Source 事件 grainTags | 场景名 | 成员名+场景名 |
| 推荐问题 | 无匹配时生成 suggestedQuestions | 不生成 |
| 画像不完整警告 | 可能注入 profileWarning | 不注入 |
| 权限 | admin/owner 可聊审核中的 | 仅 published 可聊 |
