# 创始人分身 · 输入文档标准与编辑要求

> **上传前必读。** 这份文档定义：什么素材能进创始人分身、怎么整理、怎么提交。
> 输入质量直接决定分身质量——系统要做的，是把老板散落在各处的判断逻辑"挖"出来，你给的素材越能体现"判断"，分身就越像老板。

---

## 一、创始人分身到底需要什么

创始人分身能回答四类问题，对应需要四类素材：

| 分身能力 | 需要什么素材 | 判断标准 |
|---------|-------------|---------|
| **决策参考** | 老板的判断逻辑 | 有判断立场 + 判断依据（"因为 A 所以 B"） |
| **销售判断** | 老板的销售/客户经验 | 有经验判断 + 场景 |
| **内容代笔** | 老板的表达口吻 | 老板的原话、口头禅、风格素材 |
| **公司百科** | 制度、流程、静态信息 | 客观事实，无需判断 |

**其中决策参考和销售判断，是本分身的核心，也是萃取难度最高的**——它们要的不是"老板说过什么"，而是"**老板面对一个局面会怎么判断**"。

**判断一个素材该不该提交，问一句：这份素材里，有没有老板的判断逻辑，或是可被员工查询的客观事实？**

- 有（"我认为 / 应该 / 不该 / 为什么 / 决定"）→ 判断类素材，值得提交
- 有（制度、流程、参数等客观信息）→ 百科类素材，值得提交
- 都没有（只是空泛的描述）→ 不必提交

## 二、我们接收什么（按价值分级）

价值等级决定萃取优先级和深度。S 级先萃取、深萃取；D 级只用于学习表达风格，不作为事实来源。

| 等级 | 素材类型 | 典型内容 | 萃取目标 |
|------|---------|---------|---------|
| **S** | 战略判断 | 年度战略规划、战略复盘、重大决策思考记录（为什么做/不做）、董事会汇报建议 | 决策原则、判断框架 |
| **A** | 价值观与管理哲学 | 全员信、内部讲话、文化纲领、管理手记、组织调整说明 | 核心价值观、红线 |
| **B** | 议题立场 | 对某业务方向的态度、对某组织问题的判断、对外部事件的评论 | 具体立场 |
| **C** | 经历与故事 | 创业历程、关键转折点复盘、失败教训、成功经验、对外访谈 | 案例证据、判断的形成过程 |
| **D** | 风格素材 | 演讲转写、社交媒体发言、日常表达片段 | 仅学习表达风格，不作事实 |
| **百科** | 制度文档 | 报销流程、人事制度、合伙人分工、产品参数等客观信息 | 公司百科 FAQ（事实检索，非判断） |

> **说明**：前五类（S/A/B/C/D）是"判断类素材"，用价值等级衡量萃取优先级；"百科"是"事实类素材"，不分级，直接入库供检索。两者对应分身不同的能力——判断类支撑决策参考/销售判断，事实类支撑公司百科。

### 每一级的判断信号与示例

| 等级 | 判断信号 | 示例（老板的原话） |
|------|---------|------------------|
| S | "我们决定 / 我认为应该 / 不该做，因为" | "我决定暂不进入 AI 硬件，因为我们没有芯片供应链优势，进去只能做组装。" |
| A | "我最看重 / 底线是 / 绝不允许" | "我判断一个人靠不靠谱，就看他是不是把承诺当回事。" |
| B | "对 XX，我的态度是 / 支不支持" | "关于海外扩张，我目前是谨慎支持——先试点，不大规模铺开。" |
| C | "当时经历了 / 怎么走过来的 / 踩过什么坑" | "2019 年差点发不出工资，那次让我明白现金流比增长重要。" |
| D | 老板平时的说法、口头禅 | "别跟我讲虚的，直接说数据。" |

## 三、我们不接收什么（拒绝清单）

每条都说明原因，方便你判断。

| 类型 | 为什么不收 | 反例 |
|------|-----------|------|
| **纯信息罗列** | 没有判断立场，萃取不出原则 | "本月营收 1.2 亿，团队 480 人，开了 6 场会。" |
| **他人转述** | 非一手素材，可能失真 | "我听张总说，老板好像不太赞成这个方向。" |
| **未经老板确认的会议纪要** | 可能混入记录者自己的理解 | 纪要里写"老板认为要收缩"，但老板原话是"先观察"。 |
| **纯英文素材** | 当前萃取链路仅支持中文 | 全英文的对外演讲稿件。 |
| **AI 生成或虚构内容** | 非真人真实判断，无萃取价值 | AI 生成的"老板语录"。 |

## 四、文件格式与大小

| 分级 | 格式 | 处理方式 |
|------|------|---------|
| 即时处理 | `.txt` `.md` `.csv` | 上传后直接进清洗 |
| AI 解析 | `.pdf` `.docx` `.doc` | 异步解析后进清洗 |
| 需人工补充 | `.mp3` `.wav` `.m4a`（音频转写） | 解析后需人工校对转写文本 |
| 需人工补充 | `.png` `.jpg`（图片文字） | 需人工录入图中文字 |

- 单个文件 ≤ 100MB
- 不支持的格式：`.exe` `.zip` `.rar` 等二进制/压缩文件

## 五、质量要求

这里分两类：**系统能自动判断的**，和**需要人判断的**。

### 5.1 系统自动判断（不满足会被拒绝）

| 要求 | 标准 |
|------|------|
| **文件格式** | 只支持 `.txt` `.md` `.csv` `.pdf` `.docx` `.doc` `.mp3` `.wav` `.m4a` `.png` `.jpg` |
| **有效内容** | ≥ 100 字符 |
| **中文占比** | ≥ 70% |
| **原创性** | 不与已上传素材高度重复（重复率 > 90% 拒绝） |

这四项系统能 100% 判定，不满足会直接告诉你原因。

### 5.2 需要人判断（系统只做预检提示，不自动拒绝）

| 要求 | 标准 | 为什么 |
|------|------|--------|
| **有判断立场** | 含"我认为 / 应该 / 不该 / 为什么 / 决定"类判断 | 系统只能萃取"判断"，纯描述文字没有可萃取的东西 |
| **有判断依据** | 立场背后有理由（"因为 A，所以 B"） | 只有结论没有逻辑，分身学不到"怎么想"，只会鹦鹉学舌 |

系统会对这两项做**预检提示**（标记"这段疑似无判断"），但最终判断还是你来做——因为"有没有判断"AI 只能粗判，会误判。

**一句话记住**：格式、长度、重复、语言——系统把关；判断、依据——你把关。

## 六、编辑要求（提交前必做）

老板的判断往往散落在长文档里，提交前需要做整理，否则萃取准确率会明显下降。

### 6.1 命名规范

文件名要携带三个维度，方便系统归类和日后回溯：

```
[类型]-[主题]-[时间].扩展名
```

示例：

- `战略-是否进入AI硬件赛道-2024Q3.docx`
- `全员信-关于组织扁平化的判断-2023.md`
- `立场-对海外扩张的态度-2024.pdf`

### 6.2 摘录而非整篇

一份 30 页的战略规划，真正有判断价值的部分可能只有 3 页（决策结论 + 理由 + 边界）。**优先摘录"有判断"的段落**，而不是整篇丢进去。

**判断摘录的标准**：这段话是不是在回答"老板为什么这么决定"？
- 是 → 保留
- 否（纯数据、纯背景、纯流程）→ 可略

### 6.3 标注时间与背景（强烈建议）

判断是有时效和语境的。同一个判断，在 2023 年和 2025 年的含义可能完全不同。摘录时用**三段式结构**标注：

```
【背景】当时的处境是什么
【判断】老板怎么决定的、为什么
【边界】什么情况下会改变
```

完整示例：

> 【背景】2023 年，行业都在裁员过冬，公司账上现金还能撑 18 个月。
> 【判断】我决定逆势扩招核心研发。因为寒冬是抢人的最好时机，别人收缩时我扩张，能拿到平时拿不到的人。
> 【边界】前提是现金能撑过 24 个月，否则不扩。

这三段是系统萃取的**黄金结构**，建议尽量标注。**不标注也能萃取，但会丢失"什么情况下不适用"这个边界信息**——而边界恰恰是分身不机械套用原则的关键。

### 6.4 音频/图片素材

- **音频**：系统自动转写，但提交后**必须校对转写文本**（语音识别在专业术语上容易出错）
- **图片**：截图里的文字需手动录入，确保清晰可辨

### 6.5 敏感信息说明（宽进严出）

**录入端不设障碍**：素材含薪酬、具体人事、未公开交易、法律风险等内容，**照常上传，不需要手动打标签或删减**。

系统会在**输出端**自动拦截这些敏感内容——员工问到时，分身会回答"建议直接问老板本人"。所以：

- ✅ 你：照常上传，不用顾虑敏感词
- 🔒 系统：自动识别，输出时拦截

## 七、提交示例（好 vs 坏）

### ❌ 坏示例（无判断，无法萃取）

> "2024 年 Q4，公司营收 1.2 亿，同比增长 30%，团队 480 人，办公地点 3 个。"

**问题**：这是信息罗列，没有立场、没有判断，系统萃取不出任何原则。

### ❌ 坏示例（有结论但无依据）

> "我觉得应该收缩业务线。"

**问题**：只有结论，没有理由和背景，系统学不到"老板是怎么想出来的"。

### ✅ 好示例（有背景、有判断、有边界）

> 【背景】2023 年，行业都在裁员过冬，公司账上现金还能撑 18 个月。
> 【判断】我决定逆势扩招核心研发。因为寒冬是抢人的最好时机，别人收缩时我扩张，能拿到平时拿不到的人。
> 【边界】前提是现金能撑过 24 个月，否则不扩。

**为什么好**：这是一个"反共识"的判断——别人都在收缩，他逆势扩张。有背景、有立场、有理由、有边界，系统能直接萃取出"寒冬是抢人窗口期、以现金安全为前提做逆周期投入"的判断原则。这种稀缺判断，才是创始人分身真正值钱的地方。

## 八、上传后会发生什么

```
你上传素材
    │
    ├── 即时检查（秒级）—— 格式、长度、重复、是否有判断
    │   ├── ✅ 通过 → 进入清洗
    │   └── ❌ 不通过 → 告诉你具体原因
    │
    ├── 清洗与萃取（AI 自动）
    │   系统从素材中提取"候选判断原则"，推送到审核台
    │
    ├── 人工审核（老板/有权限的人）
    │   逐条 ✅确认 / ✏️修改 / ❌删除
    │
    └── 入原则库 → 发布到分身
```

## 九、常见问题

**Q: 老板没有写下来的东西，但有判断，怎么办？**
A: 这是常态。优先提交能体现判断的**现有文档**（全员信、会议纪要、访谈），系统会从中提取。对于完全没写下来的隐性判断，后续可以通过"引导式提问"环节补充。

**Q: 一份素材同时有多个判断，怎么提交？**
A: 不用拆。系统会从一份素材里提取出多条候选原则。你只需要保证这份素材本身是"有判断"的。

**Q: 会议纪要没有老板原话，只有记录者的总结，能提交吗？**
A: 不建议。除非老板本人确认过这份纪要，否则可能混入记录者的理解，影响分身准确性。

**Q: 敏感素材真的不用删减吗？**
A: 不用。宽进严出——录入不打标签，系统在输出端自动拦截。你删减反而可能误删有价值的判断。

**Q: 一次提交多少份合适？**
A: 建议分批，每批 3-5 份，覆盖不同领域（战略/组织/产品/资本/文化）。系统会告诉你哪些领域还缺素材。
