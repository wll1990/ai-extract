## 5. 本轮必须收口（优先级）

**P0 — 安全，立刻**
1. **C6 IDOR（最高优先）**：所有按 ID 访问接口补归属校验；尤其 `SkillController.getConversationMessages`/`deleteConversation` 先加上 `Authorization` 解析与 `conversation.userId == 当前用户` 校验。
2. **C5 飞书回调**：接入 `FeishuAdapter.verifySignature`（方法已存在），从签名头解析 `companyId`，移除硬编码；`SecurityConfig` 保持 `permitAll` 但逻辑内校验。
3. **C1 前端 token**：彻底移除 `localStorage` 读写，改后端 `HttpOnly; Secure; SameSite=Strict` Cookie；SSE 也只依赖 Cookie（`credentials:'include'`），删掉 `sse.ts` 里 `getToken()` 注入 `Authorization`。

**P1 — 正确性 / 稳定性**
4. **M7**：删除 `downloadReport` 的 JSON 伪装，未生成返回 409/202 + 状态；实现或删除 `regenerateFile`（别留空操作）。
5. **H1**：`backfillEmbeddings` 改为游标分页（如每次 200 条）+ 异步任务，禁止 `findAll()` 全量进内存。
6. **H5**：`loadCompositeExpertKnowledge` / `getCompositeDetail` 改用 `findByExpertIdIn(ids)` 批量。
7. **H8/H9**：其余流式路径补 `blockLast(Duration.ofSeconds(60))`；并把 AI 流式从请求线程迁 `@Async`+`SseEmitter`（释放 Tomcat 线程）。

**P2 — 加固 / 清理**
8. **H1 前端**：补 `src/middleware.ts` 在 Edge 校验会话 + `super_admin`。
9. **C4**：`spring.datasource` 的 username/password 改 `${DB_USER}/${DB_PASSWORD}`。
10. **M1 / H3 前端**：SSE 调用方传入 `timeout`，流期间 401 也 `clearAuth()`+跳转。
11. **M4 访谈页**：改用独立 `streamingText` 状态增量渲染。
12. **清理**：删 ai-service 死代码模块（`report_generator/expert_composer/expert_extractor/interview_engine`）+ 无用的 `prompt_watcher`；`ReportService.getReport` 浏览量改为异步/REQUIRES_NEW。
