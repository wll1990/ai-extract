# 提示词文件清单

> 全量 Prompt 文件的分类、用途和领域化方式。

---

## 一、分类

| 类型 | 位置 | 说明 | 新领域需做什么 |
|------|------|------|-------------|
| **通用 prompt** | `prompts/` 根目录 | 已 `{domain.xxx}` 变量化，自动适配 | **零改动** |
| **领域 prompt** | `prompts/domain/{domain_id}/` | 领域专属版本 | **新建**（从已有领域复制改角色名） |

查找链：`domain/{domain_id}/{name}`（领域专属）→ `domain/{一级}/{name}`（一级专属）→ `{name}`（通用版）

## 三、领域 prompt（需新建）

放在 `prompts/domain/{domain_id}/` 下。以下文件通常需要领域专属版本：

| 文件 | 用途 | 说明 |
|------|------|------|
| `material_context_tag.md` | L0 情境标注 | 领域专属的分类维度 |
| `material_extract_full.md` | L5 颗粒提取 | 领域专属角色+任务 |
| `material_extract_short.md` | L5 精简版 | 同上 |
| `classify_scenes.md` | L5b 场景归类 | 领域名替换 |
| `material_faq.md` | FAQ 提取 | 通常通用版够用 |
| `material_verify.md` | 对抗验证 | 通常通用版够用 |
| `material_merge.md` | 合并去重 | 通常通用版够用 |
| `material_pattern.md` | 模式发现 | 领域角色替换 |
| `material_profile.md` | 画像生成 | 领域角色替换 |
| `material_narrative.md` | 叙事重放 | 领域角色替换 |
| `interview_system.md` | 访谈系统 | 领域专属访谈策略 |
| `meta_interview_system.md` | 元访谈 | 领域专属 |
| `practice_analyzer_intent.md` | 对练意图 | 领域专属意图分类 |
| `skill_practice_angles.md` | 对练角度 | 领域专属教学角度 |
| `skill_practice_customer.md` | 对练客户 | 领域专属角色关系 |
| `skill_practice_opening.md` | 对练开场 | 领域专属开场场景 |
| `skill_practice_evaluate_response.md` | 对练逐轮评价 | 领域专属评估维度 |
| `skill_practice_full_answer.md` | 对练满分回答 | 领域专属输出格式 |

> **不是全部 18 个都需要**。先从已有领域（`sales.b2b_enterprise`）复制全量，然后按需改差异项。很多文件（verify、merge、narrative、faq）用通用版即可。
