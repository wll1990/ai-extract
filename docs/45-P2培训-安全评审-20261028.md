## 4. 编码前必须补的设计项（已写入 docs/43 D23–D29）

1. **strip 边界**：统一 attempt → 学员 DTO 的映射器，四条路径共用；单测遍历断言不含金标字段。
2. **答题写入原子性**：条件 UPDATE + rowcount 判定（仓储已满足，补并发单测）。
3. **管理侧归属链**：attempt / record / review 三张无 `company_id` 的表逐一断言，禁止裸 `findById`。
4. **review/certify 入参 → cohort 映射链**：已冻结为表格形式，四条单测（非导师 403 / 跨企业 404 / 导师改他人 403 / 自己复核自己 403）。
5. **批量分配逐人校验学员企业**：从"数据卫生"升级为安全断言。
6. **权限撤销即时生效**：跨模块，需单独立项（不只是培训）。
7. **super_admin 放行模式统一**："先 404 再放行"。
