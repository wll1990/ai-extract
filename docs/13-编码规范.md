# 13\-编码规范



**版本**：V1\.0

**日期**：2026年6月29日

**用途**：本项目所有代码必须严格遵守以下编码规范。PiAgent生成代码时以此为硬性约束。





## 一、Java编码规范（阿里巴巴Java开发手册）



本项目的所有Java代码**必须**遵循《阿里巴巴Java开发手册》泰山版。以下为关键规则的强制要求：



### 1\.1 命名规范



|对象|规范|示例|
|---|---|---|
|类名|UpperCamelCase|`InterviewService`|
|方法名|lowerCamelCase|`createSession()`|
|变量名|lowerCamelCase|`sessionId`|
|常量|UPPER\_SNAKE\_CASE|`MAX_RETRY_COUNT`|
|包名|全小写，点分隔|`com.aiextract.controller`|
|抽象类|Abstract或Base开头|`BaseController`|
|异常类|Exception结尾|`SessionNotFoundException`|
|测试类|Test结尾|`InterviewServiceTest`|
|接口|不加I前缀|`UserRepository`（不是`IUserRepository`）|
|枚举|Enum后缀|`SessionStatusEnum`|



### 1\.2 代码格式



|规则|要求|
|---|---|
|缩进|4个空格，禁止使用Tab|
|单行最大字符|120字符|
|大括号|左大括号不换行，右大括号换行|
|空行|方法之间空一行，逻辑组之间空一行|
|空格|`if (`、`for (`、`while (` 关键字后加空格|
|import|不使用通配符`*`，按字母顺序排列|
|文件编码|UTF\-8|
|文件末尾|必须有且仅有一个换行符|



### 1\.3 注释规范



|规则|要求|
|---|---|
|类注释|必须包含：作者、创建日期、功能描述|
|公共方法|必须包含Javadoc：`@param`、`@return`、`@throws`|
|复杂业务逻辑|必须添加行内注释说明|
|注释内容|不使用拼音、不出现错别字、与代码同步更新|
|TODO|标记待办事项，格式：`// TODO(作者): 描述`|



**示例**：

```Java
/**
 * 访谈服务类
 * 
 * 负责管理AI萃取访谈的完整生命周期，包括会话创建、
 * 对话管理、中断恢复和报告触发。
 *
 * @author 周铭
 * @since 2026-06-29
 */
@Service
public class InterviewService {

    /**
     * 创建新的访谈会话
     *
     * @param request 包含spaceId、topic和可选expertSkillId
     * @return 创建的会话信息
     * @throws SpaceNotFoundException 如果空间不存在
     */
    public InterviewSession createSession(CreateInterviewRequest request) {
        // 校验空间存在性
        Space space = spaceRepository.findById(request.getSpaceId())
            .orElseThrow(() -> new SpaceNotFoundException(request.getSpaceId()));
        
        // 构建会话对象
        InterviewSession session = InterviewSession.builder()
            .spaceId(space.getId())
            .topic(request.getTopic())
            .status(SessionStatus.CREATED)
            .build();
        
        return interviewRepository.save(session);
    }
}
```



### 1\.4 异常处理



|规则|要求|
|---|---|
|捕获异常|必须处理，不能空catch块|
|异常日志|捕获后必须记录日志|
|异常抛出|不在finally块中使用return|
|异常类型|使用项目中定义的自定义异常类|
|异常不用于流程控制|不要用`try-catch`替代`if-else`|



**正确的异常处理**：

```Java
try {
    // 业务逻辑
} catch (AiServiceException e) {
    log.error("AI服务调用失败, sessionId: {}", sessionId, e);
    throw new InterviewException("AI服务暂时不可用", e);
}
```



**错误的异常处理（禁止）**：

```Java
try {
    // 业务逻辑
} catch (Exception e) {
    // 空catch块，什么都不做
}
```



### 1\.5 日志规范



|规则|要求|
|---|---|
|日志框架|统一使用SLF4J|
|日志级别|DEBUG（开发）、INFO（关键节点）、WARN（异常但可恢复）、ERROR（严重错误）|
|敏感信息|不打日志（密码、Token、身份证号等）|
|日志内容|包含关键参数值，用占位符拼接|
|生产环境|不输出DEBUG级别日志|



**示例**：

```Java
@Slf4j
@Service
public class InterviewService {
    
    public void processMessage(String sessionId, String message) {
        log.info("开始处理访谈消息, sessionId: {}, messageLength: {}", sessionId, message.length());
        // 不记录完整消息内容（可能包含敏感客户信息）
    }
}
```



### 1\.6 数据库规范



|规则|要求|
|---|---|
|表名|全小写，下划线分隔|
|字段名|全小写，下划线分隔|
|主键|必须有主键，使用UUID|
|必备字段|`created_at`、`updated_at`|
|外键|禁止使用物理外键，应用层保证完整性|
|索引|高频查询字段必须建索引|
|SQL|不用`SELECT *`，明确列出字段|
|空值判断|使用`IS NULL`，不用`= NULL`|
|表注释|必须有表注释和字段注释|



### 1\.7 分层规范



|层|职责|禁止|
|---|---|---|
|**Controller**|接收请求、参数校验、调用Service、返回响应|不包含业务逻辑|
|**Service**|业务逻辑处理、事务管理|不直接操作数据库（通过Repository）|
|**Repository**|数据访问、SQL操作|不包含业务逻辑|



### 1\.8 依赖注入



|规则|要求|
|---|---|
|注入方式|使用构造器注入，不使用字段注入|
|Lombok|使用`@RequiredArgsConstructor`简化构造器|



**示例**：

```Java
@Service
@RequiredArgsConstructor
public class InterviewService {
    private final InterviewRepository interviewRepository;
    private final AiServiceClient aiServiceClient;
    // Lombok自动生成包含所有final字段的构造器
}
```

## 二、Python编码规范



### 2\.1 命名规范



|对象|规范|示例|
|---|---|---|
|模块/文件|snake\_case|`skill_loader.py`|
|类名|PascalCase|`SkillLoader`|
|函数/方法|snake\_case|`load_skill()`|
|变量|snake\_case|`skill_id`|
|常量|UPPER\_SNAKE\_CASE|`MAX_TOKENS`|



### 2\.2 代码格式



|规则|要求|
|---|---|
|缩进|4个空格|
|单行最大|100字符|
|行尾|无多余空格|
|文件末尾|有且仅有一个换行符|
|import|按标准库→第三方库→本地库顺序排列|
|字符串|统一使用双引号|



### 2\.3 文档字符串



所有公共函数/类必须包含文档字符串：



```Python
def load_skill(skill_id: str) -> Skill:
    """加载销冠分身Skill
    
    Args:
        skill_id: 分身Skill的唯一标识
        
    Returns:
        组装完成的Skill对象
        
    Raises:
        SkillNotFoundException: 如果Skill不存在
    """
```



### 2\.4 类型注解



所有函数必须使用类型注解：



```Python
from typing import List, Optional

def vector_search(
    query: str, 
    grains: List[ExperienceGrain], 
    top_k: int = 5
) -> List[ExperienceGrain]:
    pass
```

## 三、TypeScript/React编码规范



### 3\.1 命名规范



|对象|规范|示例|
|---|---|---|
|组件|PascalCase|`InterviewChatPage`|
|函数|camelCase|`fetchSpaces()`|
|变量|camelCase|`sessionId`|
|常量|UPPER\_SNAKE\_CASE|`API_BASE_URL`|
|类型/接口|PascalCase|`InterviewSession`|
|文件名|PascalCase（组件）、camelCase（工具）|`InterviewChatPage.tsx`、`api.ts`|



### 3\.2 代码格式

|单行最大|100字符|

```TypeScript

  // 组件逻辑
```
