## 二、分层架构

```
Controller（薄） → Service（厚，业务+事务） → Repository（数据访问）
                       ↕
                  AI 算力层（ChatStreamAdapter + GrainRetriever + Embedding）
```

### 核心原则（来自 CLAUDE.md）

- **Controller 薄，Service 厚** — Controller 只做参数校验+调用 Service+返回结果
- **事务不放 Controller** — @Transactional 在 Service 方法上
- **长耗时操作异步化** — AI 调用、文件解析走 Scheduler/@Async
- **每层只管自己的事** — 不跨层注入 Repository

## 五、核心设计模式

### 5.1 统一响应格式

```json
{ "code": 200, "message": "success", "data": { ... } }
```

所有 Controller 返回 `ApiResponse<T>`，全局异常处理器统一包装。前端 `apiClient` 依赖此格式。

### 5.2 SSE 流式输出

```java
@PostMapping(value = "/{skillId}/chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public void chat(@PathVariable String skillId, @RequestBody SkillChatRequest request,
                 HttpServletResponse response) {
    response.setContentType("text/event-stream");
    PrintWriter writer = response.getWriter();
    skillService.chatToWriter(skillId, request, writer, userId);
}
```

SSE 事件格式：`data:{"type":"chunk","content":"..."}\n\n`。前端 `lib/sse.ts` 统一解析，支持 `chunk`/`content`/`source`/`meta`/`done`/`error` 事件类型。

### 5.3 RBAC 权限

```
SecurityConfig:
  /auth/login, /auth/register → permitAll()
  /admin/**                    → hasRole("SUPER_ADMIN")
  其余                         → authenticated()
```

JWT 携带 `userId` + `companyId` + `role`。管理员登录后跳转 `/admin` 工作台，普通用户跳转 `/skills` 分身广场。

### 5.4 AI 双模型架构

- **Chat**: DeepSeek (spring.ai.openai 自动配置)
- **Embedding**: 通义千问 (DashScopeEmbeddingService，不走 Spring AI OpenAI 兼容模式)
- **线程池**: embeddingExecutor (2核4线)

### 5.5 Prompt 模板热加载

```
prompts/                          ← 项目根目录（14个 .md 文件）
  skill_qa_chat.md                ← 用户端问答（v7新增）
  skill_qa_system.md              ← 审核端问答
  skill_practice_customer.md      ← 客户扮演（v8增强：四段分析+溯源）
  skill_practice_evaluate.md      ← 对练评价（v8增强：sources字段）
  ...
```

`PromptLoader`: classpath 加载到内存，文件 mtime 变化自动热更新。

## 七、关键业务流程

### 7.1 素材上传 → 颗粒入库

```
选择空间（spaceId）→ 上传文件
  → SkillMaterial(uploaded)
  → MaterialCleaningScheduler 定时扫描
  → 11层清洗管道
  → 管理员审核 → 颗粒入库(active)
  → DashScopeEmbedding（异步1024维向量化）
  → pgvector HNSW索引更新
  → Skill status: generating → reviewing
```

### 7.2 分身问答（RAG链路）

```
用户提问（SSE 流式）
  → GrainRetriever.retrieve(question)  [向量化→cosine距离→top-5]
  → buildSkillSystemPrompt              [画像+颗粒→skill_qa_chat.md]
  → ChatStreamAdapter.chatStream       [LLM流式]
  → SSE source事件（reportId+reportTitle+grainTags+grainCount+avgScore）
  → 持久化 user+assistant 消息
  → SSE meta事件（conversationId）
```

### 7.3 访谈完成 → 报告生成

```
访谈四阶段完成
  → ReportGenerationService.generateReport(interviewId)
  → 查找 interview → space → skill
  → generateAsync(skillId) 异步生成报告
```

### 7.4 审核 → 发布

```
审核页四步骤:
  ① 知识显性化 — 素材解析Pipeline
  ② 经验技能化 — AI质量裁决+五维评分
  ③ 技能场景化 — 场景对比卡片
  ④ 场景产品化 — 完善画像→验证测试→发布

发布校验:
  ✅ 画像三要素必填
  ✅ 活跃颗粒 ≥ 10
  ✅ 场景覆盖 ≥ 3
```
