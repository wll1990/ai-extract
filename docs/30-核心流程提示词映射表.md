## 流程① 萃取师技能 — 3 个 Prompt

### expert_document_extraction.md
- **用途**：分析萃取师上传的材料（文件内容+人物信息）
- **变量**：`{expert_name}` `{expert_description}` `{expert_seniority}` `{expert_style}` `{expert_industry}` `{file_contents}`
- **调用位置**：`ExpertService.analyzeMaterials()` → `promptLoader.format("expert_document_extraction.md", vars)`
- **AI 产出**：七章《萃取师经验报告》JSON

### expert_structure_report.md
- **用途**：将 AI 原始输出重新格式化为标准六章 JSON
- **变量**：`{raw_content}`
- **调用位置**：`ExpertService.structureExpertReport()` → `promptLoader.format("expert_structure_report.md", vars)`
- **AI 产出**：标准化六章 JSON（chapters 数组）

### expert_grain_extraction.md
- **用途**：从七章报告中拆解为 7 类 expert_grain
- **变量**：`{report_json}`
- **调用位置**：`ExpertService.extractGrainsFromReportContent()` → `promptLoader.format("expert_grain_extraction.md", vars)`
- **AI 产出**：JSON 数组，每项含 category / knowledgeContent / applicationRule / priority

## 流程② 销冠访谈 — 5 个 Prompt

### interview_system.md
- **用途**：四阶段访谈对话的主 Prompt——定义 AI 角色、对话原则、四个阶段的行为准则
- **变量**：`{expert_knowledge}`
- **调用位置**：`InterviewService.loadInterviewSystemPrompt()` → `promptLoader.format("interview_system.md", vars)`
- **AI 产出**：四阶段自然对话

### interview_opening.md
- **用途**：访谈开始时的第一条引导消息
- **变量**：`{opening_type}`
- **调用位置**：`InterviewService.generateOpeningMessage()` → `promptLoader.format("interview_opening.md", vars)`
- **产出**：温暖自我介绍式开场文本

### interview_completion.md
- **用途**：closing 阶段完成时的致谢消息指令
- **变量**：无
- **调用位置**：`InterviewService.markPhaseCompleteToWriter()` → `promptLoader.load("interview_completion.md")`
- **AI 产出**：温暖致谢+回顾收获+告知后续步骤

### meta_interview_system.md
- **用途**：访谈萃取师本人时的主 Prompt（元萃取模式）
- **变量**：`{expert_knowledge}`
- **调用位置**：`InterviewService.loadInterviewSystemPrompt(expertSkillId, "expert")` → `promptLoader.format("meta_interview_system.md", vars)`
- **AI 产出**：以"同行交流"姿态访谈萃取师

### grain_extraction.md
- **用途**：从销冠六章报告中拆解 experience_grain
- **变量**：`{report_json}`
- **调用位置**：`ReportGenerationService.extractExperienceGrains()` → `promptLoader.format("grain_extraction.md", vars)`
- **AI 产出**：JSON 数组，每项含 sceneTag / sceneDescription / expertThought / standardScript / commonMistakes / applicableCondition

## 流程③ 分身问答 — 3 个 Prompt

### skill_qa_chat.md（用户端，v7 新增）
- **用途**：用户端 AI 分身问答的主 Prompt。在 skill_qa_system.md 基础上增加了：社交消息处理（"谢谢""好的"简短回应）、禁止称呼规则、`---` 分隔的分析段
- **变量**：`{owner_name}` `{owner_title}` `{background}` `{personality}` `{speaking_style}` `{common_phrases}` `{knowledge_domains}` `{skill_tags}` `{target_scenarios}` `{communication_preferences}` `{experience_context}` `{mode_instruction}`
- **调用位置**：`SkillService.buildSkillSystemPrompt()` → `promptLoader.format("skill_qa_chat.md", vars)`
- **AI 产出**：销冠第一人称回答 + `---` + 分析段。前端解析 `---` 分隔符，分析区独立渲染。溯源由 SSE source 事件提供（报告+锦囊标签+评分）

### skill_qa_system.md（审核端，保留）
- **用途**：审核页模拟问答时使用。原用户端 prompt，v7 后用户端改用 skill_qa_chat.md
- **变量**：同上
- **AI 产出**：销冠第一人称回答，引用真实案例和话术

### enterprise_system.md
- **用途**：企业总调度——跨空间综合多个销冠的经验回答
- **变量**：`{experience_context}`
- **调用位置**：`SkillService.buildEnterpriseSystemPrompt()` → `promptLoader.format("enterprise_system.md", vars)`
- **AI 产出**：综合多位销冠经验的回答，标注来源

## 流程④ 分身对练 — 5 个 Prompt

### skill_practice_customer.md（v8 增强）
- **用途**：对练中扮演客户的 System Prompt——定义客户身份、情绪弧线、回应规则。**v8 增强**：每轮回应后输出 `---` 分隔的四段分析（⚠️不足 → 💡销冠话术 → 📌改进 → 📎溯源）。禁止跳出角色批评用户
- **变量**：`{scene_context}` `{practice_angles}` `{round_number}` `{total_angles}` `{history}` `{last_message}`
- **调用位置**：`SkillService.buildPracticeSystemPrompt()` → `promptLoader.format("skill_practice_customer.md", vars)`
- **AI 产出**：客户的下一句回应 + `---` + 四段分析

### skill_practice_evaluate.md（v8 增强）
- **用途**：对练结束后的综合评价——销冠视角复盘。**v8 增强**：输出增加 `sources` 字段（报告ID+标题），前端展示溯源内容
- **变量**：`{owner_name}` `{conversation}` `{scene}` `{source_context}`
- **调用位置**：`SkillService.buildPracticeEvaluatePrompt()` → `promptLoader.format("skill_practice_evaluate.md", vars)`
- **AI 产出**：JSON（score / strengths / improvements / demo_script / next_advice / sources）

### skill_practice_angles.md
- **用途**：从场景颗粒中提取 3-5 个练习角度
- **变量**：`{scene_tag}` `{grain_info}`
- **调用位置**：`PracticeDemoService.getScenePracticeAngles()`
- **AI 产出**：JSON 数组 ["角度1", "角度2", "角度3"]

### skill_practice_opening.md
- **用途**：根据场景颗粒生成客户开场白
- **调用位置**：`PracticeDemoService.generateCustomerOpening()`
- **AI 产出**：自然客户开场白文本

### skill_practice_summary.md
- **用途**：对练成长总结（技法掌握+下次试试+推荐场景）
- **调用位置**：`PracticeDemoService`
- **AI 产出**：成长总结文本
