## 2. 合并后的问题与处置

| 问题 | 来源 | 处置 |
|---|---|---|
| 逾期/评分失败后进度行永久卡 in_progress，认证不可达 | T-F1 / S-F13 | AI 落 `error` 时进度行转 `pending_review`；复核接口接受 `error` 尝试；主管可看证据裁决 |
| `timeout_fail` 直接定稿 fail，不可申诉/重考 | P-F4/F5 / R-F3 / S-F13 | 改为 `in_progress → pending_review`（建议 fail），主管复核后定稿；`termination_reason=timeout_fail` |
| 逾期来源不可见（系统代交/判失败无标记） | P-F4 / U-F5 / R-F3/F4 | attempt 增 `termination_reason`（auto_submit/timeout_fail/system_error），学员/管理端均下发 |
| 扫描写已取消/已认证分配，取消与认证双写 | P-F3 / T-F3 / S-F17 | 两条扫描 SQL 过滤分配状态；`handleOverdue` 再做一次 open 校验；取消改条件 UPDATE；学员写路径校验分配可操作；复核拒绝已结束分配 |
| 扫描器被脏行饿死 | T-F2 / S-F14 / R-F11 | 任务/记录缺失、分配已结束时 `markSweepError` 移出队列；两类查询各自 try/catch |
| 陪练逾期查询无索引 | T-F4 / S-F14 | 新增 `idx_ta_deadline_open ON training_assignment(deadline) WHERE status IN (...)` 作为驱动路径，并补 `idx_tat_assignment ON training_attempt(assignment_id, attempt_no DESC)` 供 join 侧索引下探 |
| 认证人/姓名缺失，四处字段不一致 | P-F1 / U-F1/F2/F4 / R-F1/R-F8 | 统一 `CertificationView{status,confirmedBy,confirmedByName,confirmedAt,note}`；certify/我的培训/批次详情/进度共用 |
| 认证失败没有阻塞清单，按钮可用性靠猜 | P-F2 / U-F3 | 进度行下发 `canCertify/certifyBlockedReason/certificationBlockers`（缺哪门必修、当前状态） |
| `canRetry` 与「剩余次数」矛盾（failed 被当终态） | R-F2 | 只有 passed/waived 阻止重考；failed 可重考 |
| `waived` 不计必修；全选修计划永远无法认证 | S-F16 / T-F8 / R-F10 | 必修满足口径统一为 passed|waived；`requiredTotal==0` 时全部任务满足才可认证 |
| 逾期窗口内陪练动作与实际接口不一致 | R-F5 | `toView` 用 `attempt.deadline ?: assignment.deadline` 算有效截止；下发 `deadlineExceeded` |
| 学员看不到是谁认证的 / 重复点击静默丢备注 | P-F9 / R-F7 | 认证视图带 `confirmedByName`；幂等响应带 `alreadyCertified=true`，明确备注未被覆盖 |
| 锁序：先锁任意 UUID 再鉴权 | T-F6 / S-F15 | 先无锁读 + `assertCanReview`，再行锁读取并复核 |

| 认证记录缺失/未确认但分配已 certified | T-F6 | 明确 409「认证记录异常，请联系管理员」，不再误报必修未过 |

## 3. 测试与实机证据

`mvn -f backend/pom.xml clean test` → **338 用例 / 0 失败 / 2 跳过**（T6 新增 22）。

实机（真实服务 + 真实库）：

```
认证：
  certify → certified，certification 含 confirmedByName/confirmedAt/note
  幂等 → alreadyCertified=true，备注不被覆盖
  非待认证 → 409
  进度行/批次详情/我的培训 → 同一 CertificationView

截止：
  auto_submit → pending_review/pass，terminationReason=auto_submit
  timeout_fail → pending_review/fail，terminationReason=timeout_fail，learner result=null
                 → 主管复核 pass → finalized/pass，record=passed，进入 pending_certification
  已取消分配 → 扫描跳过（不再代交/判罚）
```
