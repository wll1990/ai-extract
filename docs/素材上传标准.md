# 素材上传标准

> **上传前必读。不符合标准的素材会被系统自动拒绝，或无法产出有效分身。**

---

## 一、我们接收什么样的素材

我们是一个**销售经验萃取平台**。系统从你上传的素材中提取销冠的实战技巧、话术和判断逻辑，生成可对话的 AI 分身。

好的素材 = **真实销售场景中发生的真实对话或经验分享**。

### ✅ 推荐上传

| 类型 | 示例 | 说明 |
|------|------|------|
| **销售对话记录** | 微信聊天截图、IM 导出文本、通话转写 | 客户和销售的完整对话，包含客户质疑和销售回应 |
| **经验心得** | 销冠自己写的总结、复盘笔记、战报 | 第一人称分享实际案例，包含具体场景、动作和思考 |
| **访谈实录** | 萃取师访谈销冠的文字记录 | 一问一答形式，销冠讲述自己的经历和方法 |
| **会议录音转写** | 销售例会、复盘会、培训分享的录音转文字 | 多人讨论销售案例的对话 |
| **CRM 记录** | 跟客记录、商机备注、成单总结 | 从线索到成交的完整过程记录 |

### ❌ 不接收

| 类型 | 为什么不收 |
|------|-----------|
| **销售培训教材/书籍内容** | "销售应该真诚""要挖掘客户需求"——这是通用理论，不是个人实战经验 |
| **产品白皮书/介绍文档** | 产品功能列表，不包含销售技巧 |
| **营销广告文案** | "限时优惠""立即购买""扫码领取"——这是推广内容 |
| **纯英文素材** | 当前仅支持中文销售对话分析 |
| **技术文档** | API 文档、部署手册、代码——和销售无关 |
| **财务报表/合同** | 不含销售经验，无法萃取 |
| **AI 生成的虚构对话** | 非真人经验，萃取结果无实际价值 |
| **HR 制度/行政通知** | 公司内部管理文档，非销售技能 |

## 二、支持的文件格式

| 格式 | 后缀 | 建议场景 |
|------|------|---------|
| 纯文本 | `.txt` | 导出的聊天记录、手打的对话 |
| PDF 文档 | `.pdf` | 访谈记录、复盘报告（文字型 PDF，非扫描版） |
| Word 文档 | `.docx` `.doc` | 整理后的对话或心得 |
| Excel 表格 | `.xlsx` `.xls` | CRM 跟客记录、商机备注 |
| Markdown | `.md` | 结构化笔记 |
| 图片 | `.png` `.jpg` `.jpeg` | 微信聊天截图（需清晰可读） |
| 音频 | `.mp3` `.wav` `.m4a` | 通话录音、会议录音（需中文普通话） |

### 不支持的格式

`.exe` `.dll` `.so` `.bin` `.zip` `.rar` `.7z` `.tar` `.gz` 等二进制/压缩文件。

### 文件大小限制

单个文件 ≤ **100MB**。超大文件请先压缩或拆分后上传。

## 三、内容质量要求

### 硬性要求（不满足直接拒绝）

| 要求 | 标准 | 说明 |
|------|------|------|
| **语言** | 中文占比 ≥ 70% | 当前仅支持中文，中英混杂可接受但中文必须为主 |
| **领域** | 必须是销售相关 | 需包含报价/竞品/客户/谈判/成交等关键词，系统会自动检测 |
| **来源** | 真人真实经验 | 需使用第一人称（"我做过""我遇到过"），系统会检测理论化程度 |
| **长度** | ≥ 50 个有效字符 | 太短的内容无法有效萃取 |
| **原创性** | 不与已上传素材重复 | 系统会自动检测重复，重复率 > 90% 会被拒绝 |

### 质量建议（不强制但强烈建议）

| 建议 | 为什么 |
|------|--------|
| 对话素材至少 3 轮以上 | 只有一问一答很难体现销冠的判断逻辑 |
| 包含客户的真实质疑 | "太贵了""跟竞品比有什么优势""我再考虑考虑"——这些异议是萃取出好技巧的关键 |
| 覆盖多个话题领域 | 价格谈判、竞品对比、异议处理、关系建立等，覆盖越多分身越全面 |
| 对话越完整越好 | 从初次接触到成交的完整过程，比碎片对话好得多 |
| 标注说话人 | "销售：... 客户：..." 或 "我：... 对方：..."，让系统更准确识别销售角色 |

## 四、上传后会发生什么

```
你上传素材
    │
    ├── 即时检查（秒级）
    │   系统自动判断：格式对吗？是销售内容吗？长度够吗？重复吗？
    │   ├── ✅ 通过 → 进入下一步
    │   └── ❌ 不通过 → 告诉你具体原因，请修改后重新上传
    │
    ├── 质量评分（秒级）
    │   系统给出质量预估：预计能提取多少条技巧、覆盖了哪些销售场景
    │   🟢 优秀 / 🟡 可用 / 🔴 偏低
    │
    ├── 自动萃取（几分钟到几十分钟）
    │   AI 逐层分析：识别场景 → 提取话术 → 挖掘逻辑 → 验证质量
    │
    └── 生成分身
        萃取后的经验进入分身知识库，你就能跟销冠对话了
```

## 五、常见问题

**Q: 我只有一段 100 字的销售心得，可以上传吗？**
A: 满足硬性要求（中文、销售相关、第一人称）就可以上传。但 100 字能提取的技巧有限，建议补充更多细节——具体场景、实际说的话、客户反应、为什么这么做有效。

**Q: 微信聊天截图可以吗？**
A: 可以。确保截图清晰、文字可辨。多张截图合并上传效果更好。

**Q: 通话录音需要先转成文字吗？**
A: 不需要。上传音频文件后系统会自动语音转文字。

**Q: 我可以上传多份素材吗？**
A: 可以，而且建议。同一个销冠的多份素材（对话 + 心得 + 访谈）能让分身更全面。

**Q: 上传后多久能生成分身？**
A: 取决于素材长度和复杂度。一般 5-15 分钟。你可以在管理后台查看进度。

**Q: 素材被拒绝了怎么办？**
A: 系统会告诉你具体原因。按提示修改后重新上传即可。如果觉得误判，联系管理员。
