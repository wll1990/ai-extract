## 2. 导航

三处同源改动：

- `NavConfigController`：新增「培训计划」(`/admin/training/plans`, `TRAINING_MANAGE`) 与「我的培训」(`/training`, `TRAINING_LEARN`)。
- `frontend/src/lib/permissions.ts`：补 `TRAINING_MANAGE / TRAINING_REVIEW / TRAINING_LEARN` 三个常量（此前前端缺这三个码）。
- `AppLayout`：本地 `NAV_ITEMS` 同步两条；`canAccessAdmin()` 加入 `TRAINING_MANAGE|TRAINING_REVIEW`——**导师（employee）只有 `TRAINING_REVIEW`，不加这条会被布局层踢回 `/skills`，看着像 404**；`isNavActive` 让 `/training/assignments/**`、`/admin/training/cohorts/**` 分别高亮到「我的培训」「培训计划」。

导师入口不做独立菜单，放在「我的培训」的「我带的批次」标签页（`GET /admin/training/cohorts/mine`），避免给 employee 下发管理菜单。

## 3. 后端补的两处支撑

T7 过程中发现两个前端无法自行补齐的缺口，按最小改动补上（均有单测/实测）：

1. **陪练对话恢复**：原有接口只能发消息（SSE），刷新/续接后拿不到历史。新增
   `GET /me/training/attempts/{id}/messages` → `[{id, role, roleLabel, content, createdAt}]`。
   归属走 `requireLearnerAttempt`（非本人 404），考试尝试 400，无会话返回 `[]`；
   单测 3 条（本人历史 / 考试拒绝 / 越权 404）。
2. **成绩页补考路由**：`GET /me/training/attempts/{id}/result` 的 `attempt` 增加 `assignmentId`，
   否则陪练「再试一次」无法拼出任务页路由。

## 4. 关键交互与约束

### 考试页

- 倒计时只做展示（`remainingSeconds` 由服务端下发，到 0 冻结输入），交卷/超时以服务端为准；
- 草稿：手动保存 + 15 秒自动保存（仅在有改动时发请求），离开页面前补一次保存；
- 交卷 = 保存草稿 → `POST submit` → 成绩页；重复提交由服务端幂等；
- 刷新恢复：`GET attempts/{id}` 的 `answers` 回填，`allowedActions` 决定按钮可用性；
- 非考试尝试误入该路由会被重定向到成绩页。

### 陪练页

- 开始/续接都走 `POST task-records/{id}/attempts`（服务端返回进行中的那次，不会重复建）；
- 历史消息 + 客户开场白（技能 `openingMessage`，仅展示，不入库）一起渲染；
- 发言走 `POST attempts/{id}/messages`（`connectSse`，逐字流式）；提示走 `hints`，按钮只在 `allowedActions` 含 `hint` 时出现（考试/关闭提示的任务服务端 403）；
- 提交后跳成绩页；`pending_review` 时任务页显示「等待主管复核」，并禁止再开新尝试。

### 管理侧

- 计划编辑器只在**当前版本是草稿**时可写；已发布版本只读，提供「新建版本」；
- 任务表单按类型收敛必填项（阅读要资源、陪练要分身、考试要已发布题集+时长），前置任务多选，支持阶段内 ↑↓（提交完整 ID 集）；
- 批次创建只能选已发布版本；批量分配逐人展示成功/跳过/失败原因，不只弹 toast；
- 批次详情：进度行直接给 `canCertify / certifyBlockedReason / certificationBlockers`，缺哪门必修写在行内；抽屉里按任务列尝试，点击尝试看题面+金标+学员作答+AI 明细+陪练原对话+复核历史；复核理由 ≥5 字（服务端同样校验），`error` 尝试可「重新评分」；
- **权限**：分配/取消只有 `TRAINING_MANAGE` 可见；导师只看到进度、复核、认证按钮（URL 级 `TRAINING_REVIEW`），点不到会 403 的按钮不再渲染。

### 金标

学员侧只消费 T5 已 strip 的 `questions`（`itemId/orderNo/question/context/citationRequirement/sceneTag`）与 `score`（逐题只留分数/结论）；题面金标只在管理侧抽屉展示。

## 6. 已知限制

| 事项 | 说明 |
|---|---|
| 浏览器端到端 | 当前环境无浏览器自动化；页面以 HTTP 200 + 接口契约核对代替点击回归，交互细节需人工过一遍 |
| 选择器规模 | 学员/导师/知识/案例/分身/题集选择器都只取前 100 条，>100 的企业需要搜索（P3） |
| 批次成员/进度全量加载 | 与后端一致，未分页（P3） |
| 补训/整改/撤销认证 | P3，界面未提供入口（docs/51 §2） |
| 通知 | 待复核/认证完成暂无站内信或飞书通知（P3），靠导师进批次详情看 |
| 409 子码 | 仍以中文 message 展示；`certifyBlockedReason` 已覆盖认证按钮的可用性判断 |
| 陪练开场白 | 技能 `openingMessage` 仅前端展示，不写入会话，也不参与评分转录（T4 既有口径） |
