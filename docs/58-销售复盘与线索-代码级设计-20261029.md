## 0. 已确认口径

1. 企业可配置自己的 DeepSeek Key；**没配置 / 停用 → 用平台 Key**，保证流程可用。
2. Chat 模型固定 `deepseek-chat`；Embedding/STT 平台统一，不允许企业覆盖。
3. 复盘只支持**文本**（用户自行把录音转成文本后粘贴）。
4. 教练必须选**本企业、已发布、individual** 的分身。
5. 线索首版只做最小记录；跟进任务落系统内。
6. 教练台账记录「谁/何时/客户/摘要」；完整对话默认不可见，销售可授权。
7. 可见性：销售本人 + `company_admin/super_admin` 看全公司；其他员工只看自己；跨企业 404。
8. **企业 Key 运行中报错（401/402/429）不自动回退平台**：企业 Key 有问题就暴露出来，避免悄悄消耗平台额度；仅在「未配置 / 显式停用且允许回退 / 解密失败且允许回退」时用平台 Key。
9. 报告保持细化五区块 + 每条原文引用（不裁剪为 3 条式简版）。
10. 转线索只做「人工确认」：重复候选由人决定，不自动创建、不自动合并；**本轮不做线索池/认领/公海**，创建后负责人就是发起人。
11. **主复盘是教练的 AI 分身；真人教练可以被请求补充点评**。补充与 AI 报告分表存，不改写 AI 报告，不阻塞报告生成。
12. `company_admin/super_admin` 是最大权限，可以看全公司复盘原文；普通员工只能看自己的。
13. 复盘内容按记录长期保留，不做自动清理、不设保留期。

```java
// service/TenantChatClientProxy.java
public final class TenantChatClientProxy {
    public static ChatClient of(ChatClientResolver resolver) {
        return (ChatClient) Proxy.newProxyInstance(
            ChatClient.class.getClassLoader(), new Class[]{ChatClient.class},
            (proxy, method, args) -> {
                if (method.getDeclaringClass() == Object.class) {
                    return switch (method.getName()) {
                        case "toString" -> "TenantChatClientProxy";
                        case "hashCode" -> System.identityHashCode(proxy);
                        case "equals" -> proxy == args[0];
                        default -> null;
                    };
                }
                return method.invoke(resolver.current(), args);
            });
    }
}
```

```java
// service/ChatClientResolver.java
@Slf4j @Component
public class ChatClientResolver {
    private final ChatClient platformClient;
    private final CompanyAiConfigRepository repository;
    private final PartnerCrypto crypto;
    private final CompanyChatClientFactory factory;

    // 显式构造：Lombok 不会把 @Qualifier 复制到生成构造器的参数上
    public ChatClientResolver(@Qualifier("platformChatClient") ChatClient platformClient,
                              CompanyAiConfigRepository repository,
                              PartnerCrypto crypto,
                              CompanyChatClientFactory factory) {
        this.platformClient = platformClient;
        this.repository = repository;
        this.crypto = crypto;
        this.factory = factory;
    }

    private final ConcurrentHashMap<UUID, CacheEntry> cache = new ConcurrentHashMap<>();

    public ChatClient current() {
        UUID companyId = TokenContext.getCompanyId();
        if (companyId == null) {
            return platformClient; // 异步任务未带企业上下文 → 平台兜底
        }
        CompanyAiConfig cfg = repository.findByCompanyIdAndProvider(companyId, "deepseek").orElse(null);
        if (cfg == null) {
            return platformClient; // 未配置 → 平台兜底
        }
        if (!"enabled".equals(cfg.getStatus())) {
            if (cfg.isFallbackEnabled()) return platformClient;
            throw BusinessException.conflict("AI_KEY_DISABLED", "企业 AI Key 已停用，请联系管理员");
        }
        CacheEntry entry = cache.get(companyId);
        if (entry != null && entry.updatedAt().equals(cfg.getUpdatedAt())) {
            return entry.client();
        }
        String apiKey;
        try {
            apiKey = crypto.decrypt(cfg.getApiKeyCipher());
        } catch (Exception e) {
            log.error("企业 AI Key 解密失败 companyId={}", companyId, e);
            if (cfg.isFallbackEnabled()) return platformClient;
            throw BusinessException.conflict("AI_KEY_DECRYPT_FAILED", "企业 AI Key 解密失败，请联系管理员");
        }
        ChatClient client = factory.create(companyId, cfg.getBaseUrl(), apiKey, cfg.getModelName());
        cache.put(companyId, new CacheEntry(client, cfg.getUpdatedAt()));
        return client;
    }

    public void evict(UUID companyId) { cache.remove(companyId); }

    private record CacheEntry(ChatClient client, LocalDateTime updatedAt) {}
}
```

```java
// service/CompanyChatClientFactory.java
@Slf4j @Component @RequiredArgsConstructor
public class CompanyChatClientFactory {
    private final TokenUsageService usage;
    @Value("${spring.ai.openai.chat.options.model:deepseek-chat}") private String model;
    @Value("${spring.ai.openai.chat.options.max-tokens:8192}") private int maxTokens;
    @Value("${spring.ai.openai.chat.options.temperature:0.1}") private double temperature;

    public ChatClient create(UUID companyId, String baseUrl, String apiKey, String modelName) {
        OpenAiApi api = new OpenAiApi(baseUrl, apiKey); // 注意顺序：baseUrl, apiKey
        OpenAiChatModel chatModel = new OpenAiChatModel(api, OpenAiChatOptions.builder()
            .model(modelName).maxTokens(maxTokens).temperature(temperature).build());
        return ChatClient.builder(new TokenAwareChatModel(chatModel, usage, modelName, companyId))
            .defaultOptions(OpenAiChatOptions.builder()
                .model(modelName).maxTokens(maxTokens).temperature(temperature).build())
            .build();
    }
}
```

**兜底语义（写死）**：

| 场景 | 行为 |
|---|---|
| 企业未配置 | 平台 Key |
| 企业配置但 `disabled` | `fallback_enabled=true` → 平台 Key；否则 409 `AI_KEY_DISABLED` |
| 解密失败 | `fallback_enabled=true` → 平台 Key（记 ERROR）；否则 409 `AI_KEY_DECRYPT_FAILED` |
| 运行中 401/402/429 | **不自动回退**，返回稳定子码（避免掩盖企业账单/额度问题） |
| 无企业上下文（异步任务） | 平台 Key |

> 企业 Key 隔离的覆盖范围：所有经 `ChatClient` 的调用（对话/萃取/复盘/评测/提示）都会走代理。异步任务要真正用企业 Key，必须在任务入口设置 `TokenContext`（见 2.8）。

### 2.4 配置服务

```java
@Service @RequiredArgsConstructor
public class CompanyAiConfigService {
    private final CompanyAiConfigRepository repository;
    private final PartnerCrypto crypto;
    private final ChatClientResolver resolver;
    private final SalesAuditService audit;
    private final TokenUsageLogRepository usageRepository;
    private final CompanyChatClientFactory factory;

    @Value("${spring.ai.openai.chat.options.model:deepseek-chat}")
    private String platformModelName;

    public CompanyAiConfigView get(UUID companyId) {
        CompanyAiConfig cfg = repository.findByCompanyIdAndProvider(companyId, "deepseek").orElse(null);
        Usage usage = usageRepository.sumByCompanySince(companyId, LocalDate.now().withDayOfMonth(1));
        return new CompanyAiConfigView(
            cfg != null, "deepseek", platformModelName,
            cfg != null ? cfg.getBaseUrl() : null,
            cfg != null ? cfg.getKeyLast4() : null,
            cfg != null ? cfg.getStatus() : "disabled",
            cfg == null || cfg.isFallbackEnabled(),
            true,
            usage.inputTokens(), usage.outputTokens());
    }

    @Transactional
    public CompanyAiConfigView update(UUID companyId, CompanyAiConfigRequest req) {
        validateBaseUrl(req.baseUrl());
        CompanyAiConfig cfg = repository.findByCompanyIdAndProvider(companyId, "deepseek")
            .orElseGet(() -> newConfig(companyId));
        cfg.setBaseUrl(req.baseUrl().trim());
        if (req.apiKey() != null && !req.apiKey().isBlank()) {
            String key = req.apiKey().trim();
            cfg.setApiKeyCipher(crypto.encrypt(key));
            cfg.setKeyLast4(last4(key));
        }
        cfg.setFallbackEnabled(req.fallbackEnabled());
        cfg.setStatus("enabled");
        cfg.setUpdatedBy(TokenContext.get());
        cfg.setUpdatedAt(LocalDateTime.now());
        repository.save(cfg);
        resolver.evict(companyId);
        audit.record("ai.model.config.update", "company_ai_config", cfg.getId(),
            Map.of("baseUrl", cfg.getBaseUrl(), "keyLast4", cfg.getKeyLast4(),
                   "fallbackEnabled", cfg.isFallbackEnabled()));
        return view(cfg);
    }

    public CompanyAiTestResult test(UUID companyId, String apiKey, String baseUrl) {
        // apiKey 为空 → 用已存 Key；baseUrl 为空 → 用已存/平台默认
        String plain = resolvePlainKey(companyId, apiKey);
        String url = baseUrl == null || baseUrl.isBlank() ? resolveBaseUrl(companyId) : baseUrl.trim();
        validateBaseUrl(url);
        long t0 = System.currentTimeMillis();
        try {
            ChatClient client = factory.create(companyId, url, plain, "deepseek-chat");
            client.prompt().user("ping").options(OpenAiChatOptions.builder().maxTokens(1).build())
                .call().content();
            return new CompanyAiTestResult(true, System.currentTimeMillis() - t0, null, "连接成功");
        } catch (Exception e) {
            return new CompanyAiTestResult(false, System.currentTimeMillis() - t0,
                mapErrorCode(e), mapErrorMessage(e));
        }
    }

    @Transactional
    public void rotate(UUID companyId, String newKey) {
        CompanyAiConfig cfg = require(companyId);
        String previousKeyLast4 = cfg.getKeyLast4();
        cfg.setApiKeyCipher(crypto.encrypt(newKey.trim()));
        cfg.setKeyLast4(last4(newKey.trim()));
        cfg.setUpdatedBy(TokenContext.get());
        cfg.setUpdatedAt(LocalDateTime.now());
        repository.save(cfg);
        resolver.evict(companyId);
        // 旧 Key 不再落库：审计留末 4 位与废弃标记即可
        audit.record("ai.model.rotate", "company_ai_config", cfg.getId(),
            Map.of("keyLast4", cfg.getKeyLast4(),
                   "previousKeyLast4", previousKeyLast4 == null ? "" : previousKeyLast4,
                   "previousKeyRetained", false));
    }

    @Transactional
    public void disable(UUID companyId) {
        CompanyAiConfig cfg = require(companyId);
        cfg.setStatus("disabled");
        cfg.setUpdatedAt(LocalDateTime.now());
        repository.save(cfg);
        resolver.evict(companyId);
        audit.record("ai.model.disable", "company_ai_config", cfg.getId(),
            Map.of("fallbackEnabled", cfg.isFallbackEnabled()));
    }
}
```

校验：

- `baseUrl` 必须 `https://` 开头（本地开发允许 `http://localhost`），长度 ≤300。
- `apiKey` 长度 8..300；保存时只存密文与末 4 位。
- 测试接口 10 秒超时；错误映射：401→`AI_KEY_INVALID`，402/余额→`AI_KEY_BALANCE`，429→`AI_KEY_RATE_LIMIT`，超时→`AI_KEY_TIMEOUT`，其他→`AI_KEY_UNREACHABLE`。
- 任何响应/日志不得出现明文 Key。

### 2.8 异步上下文覆盖（P0 必做清单）

| 入口 | 公司来源 | P0 是否设置 |
|---|---|---|

| 评测 Worker | `evaluation_run.company_id` | ✅ 需补 |

设置方式（不改 TokenContext 语义）：

```java
TokenContext.callWith(userId, companyId, () -> { ...调用 LLM... });
```

在 `TokenContext` 增加：

```java
public static <T> T callWith(UUID userId, UUID companyId, Supplier<T> action) {
    UUID oldUser = USER_ID.get(), oldCompany = COMPANY_ID.get();
    try {
        set(userId, companyId);
        return action.get();
    } finally {
        if (oldUser == null) USER_ID.remove(); else USER_ID.set(oldUser);
        if (oldCompany == null) COMPANY_ID.remove(); else COMPANY_ID.set(oldCompany);
    }
}
```

> 若本轮只做复盘，可先只覆盖复盘 Worker；其余三处列在实现清单，企业上线前必须补齐，否则会静默用平台 Key。

```java
public List<SegmentDraft> split(String transcript) {
    List<SegmentDraft> out = new ArrayList<>();
    for (String raw : transcript.split("\\r?\\n")) {
        String line = raw.trim();
        if (line.isEmpty()) continue;
        for (String piece : splitLongLine(line, 2000)) {
            out.add(new SegmentDraft(detectSpeaker(piece), stripPrefix(piece)));
        }
        if (out.size() >= 500) break; // 防超长
    }
    if (out.isEmpty()) out.add(new SegmentDraft("unknown", transcript.trim()));
    return out;
}
private String detectSpeaker(String line) {
    if (line.startsWith("客户") || line.startsWith("对方")) return "customer";
    if (line.startsWith("销售") || line.startsWith("我")) return "sales";
    return "unknown";
}
```

### 3.6 Worker（事务外调用 LLM）

```java
@Slf4j @Component @RequiredArgsConstructor
public class SalesReviewReportWorker {
    private final SalesReviewReportService reportService;
    private final SalesReviewReportGenerator generator; // 无事务，调 LLM

    @Value("${app.sales.review.enabled:true}") private boolean enabled;
    @Value("${app.sales.review.worker-id:}") private String workerId;
    @Value("${app.sales.review.batch-size:2}") private int batchSize;
    @Value("${app.sales.review.max-attempts:3}") private int maxAttempts;

    @Scheduled(fixedDelayString = "${app.sales.review.worker-interval-ms:5000}",
               initialDelayString = "${app.sales.review.worker-initial-delay-ms:15000}")
    public void tick() {
        if (!enabled) return;
        List<UUID> ids = reportService.claimBatch(workerId, batchSize);
        for (UUID id : ids) {
            try {
                generator.generate(id, workerId); // 内部：读数据 → RAG → LLM → 解析 → reportService.complete
            } catch (Exception e) {
                log.warn("复盘报告生成失败 reportId={}", id, e);
                reportService.fail(id, workerId, truncate(e.getMessage()));
            }
        }
    }
}
```

```java
@Transactional
public List<UUID> claimBatch(String owner, int limit) {
    List<UUID> ids = reportRepository.lockClaimableIds(limit, maxAttempts);
    LocalDateTime expires = LocalDateTime.now().plusMinutes(10);
    return ids.stream()
        .filter(id -> reportRepository.claim(id, owner, expires, maxAttempts) == 1)
        .toList();
}

@Transactional public void complete(UUID id, String owner, String summary, String payload, String model) {
    int updated = reportRepository.complete(id, owner, summary, payload, model);
    if (updated == 0) return;
    ReviewReport r = reportRepository.findById(id).orElseThrow();
    sessionRepository.findById(r.getSessionId()).ifPresent(s -> {
        if ("active".equals(s.getStatus())) {
            s.setStatus("report_ready"); s.setUpdatedAt(LocalDateTime.now()); sessionRepository.save(s);
        }
        notificationService.notifyUser(s.getReviewerId(), s.getCompanyId(),
            "sales_review_ready", "复盘报告已生成",
            "「" + (s.getCustomerName() == null ? "本次对话" : s.getCustomerName()) + "」的复盘已生成，点击查看。",
            "/sales/reviews/" + s.getId(), "review_report", r.getId(), "sales:report:" + r.getId());
    });
}
@Transactional public void fail(UUID id, String owner, String error) {
    ReviewReport r = reportRepository.findById(id).orElseThrow();
    boolean exhausted = r.getAttempts() >= maxAttempts;
    reportRepository.finishFailed(id, owner, exhausted ? "failed" : "queued", error);
}
```

```java
public ParsedReport parse(String raw, Set<UUID> segmentIds) {
    String json = stripFences(raw).trim();
    JsonNode root;
    try { root = objectMapper.readTree(json); }
    catch (Exception e) { throw new ReportParseException("模型输出不是合法 JSON", e); }
    String summary = text(root, "summary");
    if (summary == null || summary.isBlank()) throw new ReportParseException("缺少 summary");
    summary = summary.length() > 200 ? summary.substring(0, 200) : summary;

    List<Map<String,Object>> strengths = points(root, "strengths", segmentIds, 8, true);
    List<Map<String,Object>> weaknesses = points(root, "weaknesses", segmentIds, 8, true);
    List<Map<String,Object>> risks = points(root, "risks", segmentIds, 8, true);
    List<Map<String,Object>> signals = signals(root, "customerSignals", segmentIds, 8);
    List<Map<String,Object>> nextSteps = steps(root, "nextSteps", segmentIds, 3);
    Map<String,Object> leadDraft = leadDraft(root);

    Map<String,Object> payload = new LinkedHashMap<>();
    payload.put("summary", summary);
    payload.put("strengths", strengths);
    payload.put("weaknesses", weaknesses);
    payload.put("risks", risks);
    payload.put("customerSignals", signals);
    payload.put("nextSteps", nextSteps);
    payload.put("leadDraft", leadDraft);
    return new ParsedReport(summary, objectMapper.writeValueAsString(payload));
}
```

校验规则：

- `evidence[].segmentId` 必须属于本次会话；否则整份报告失败。
- `evidence[].quote` 若存在，必须出现在对应段落文本中（忽略空白差异）；否则失败（防模型编引用）。
- strengths/weaknesses/risks 每条必须有非空 evidence。
- customerSignals 的 `sourceType=unknown` 时 `value` 必须为 null；其他来源必须至少一条 evidence。
- nextSteps 每条 title 非空，最多 3 条；`dueInDays` 1..30，缺省 3。
- 条数超限直接截断，不报错。
- 任何解析失败 → `ReportParseException` → Worker 重试/失败，不落半成品。

- 限流 Lua：`INCR key`，首建 `EXPIRE 3600`；总次数 40，`INCR` 后 >40 拒绝；每分钟 10 次用第二个 key（`rate:sales-review:{sessionId}:min`，TTL 60）。Redis 异常 fail-open（与全站限流同口径）。
- 历史只取最近 10 条，避免上下文膨胀。

### 3.12.1 请真人教练补充

**定位**：AI 分身是主复盘；真人教练是「加一层人判断」，不是必填流程。补充点评追加写，不改 AI 报告，报告照常生成、照常可转线索。

流程：

1. 发起人在复盘详情点「请教练补充」，可填一句说明（≤500 字），并选择是否同时授权教练看原文。
2. 后端写 `review_coach_request(status=pending)`，给教练发站内信；若同时授权，把 `review_session.share_transcript_with_coach` 置 true 并审计。
3. 教练在「教练台账 → 待我补充」打开工作台，能看到：客户/主题、发起人、说明、AI 报告摘要与五区块；只有授权时才返回 `segments` 原文。
4. 教练可追加多条补充（≤2000 字/条）。第一条落库时请求置 `done`，给发起人发站内信。
5. 发起人在详情页看到「教练补充」区，与 AI 报告视觉分离；补充不改变报告版本。

约束：

- 一个会话只有一条 request；`done` 后可以再次请求（状态回到 `pending`，历史 note 保留）。
- 只有发起人能请求/取消；只有 `coach_owner_id == me` 的教练能看工作台和写 note。
- 教练本人就是发起人时，不创建 request，直接允许写 note（自复盘）。
- 教练工作台返回的报告只读；补充内容不参与后续 RAG/报告重生成，避免把个人意见当事实。
- 审计：`sales.coach.request`、`sales.coach.cancel`、`sales.coach.note`。
- 通知：请求 → 教练；首条补充 → 发起人；链接分别是 `/sales/coach/requests/{sessionId}` 和 `/sales/reviews/{sessionId}`。

### 5.1 `TrainingPickerService` 增加 `coach=true`

## 8. 风险与边界

- **JWT 权限缓存**：新增权限码需要重新登录才生效；上线公告写明。
- **ChatClient 代理**：所有注入 `ChatClient` 的类自动走租户解析；若有代码按具体实现类型强转会失效（当前仓库没有）。
- **异步上下文**：未设置 `TokenContext` 的后台任务会走平台 Key；这是本轮已知边界，企业上线前必须逐项确认。
- **报告质量**：LLM 可能输出不合 schema；解析失败整份重试，不落半成品；前端只展示 ready 报告。
- **长文本**：P0 上限 30000 字；更长文本请分段复盘（P1 做自动分段/摘要）。
- **线索查重**：名称规范化只能降低重复，不能完全避免；首版以提示+人工确认为准。
