---

**版本**：V1\.0

**日期**：2026年6月29日

**用途**：指导开发人员快速搭建项目骨架，完成本地开发环境初始化





## 一、项目概述



**项目名称**：AI经验萃取平台（AI Extract）

**技术栈**：Next\.js 14 \+ Spring Boot 3 \+ Python FastAPI \+ PostgreSQL \+ Redis

**部署方式**：Docker Compose（开发/测试），Kubernetes（生产/后续）



**项目结构**：

```Plain Text
ai-extract/
├── frontend/          # 前端 (Next.js 14 + TypeScript + Tailwind CSS)
├── backend/           # 后端 (Spring Boot 3 + Java 17 + Maven)
├── ai-service/        # AI服务 (Python 3.11 + FastAPI)
├── docker-compose.yml # 容器编排
├── seed.sql           # 初始数据脚本
└── README.md
```

## 三、快速启动（Docker Compose 一键启动）



### 3\.1 克隆项目



```Bash
git clone <仓库地址> ai-extract
cd ai-extract
```



### 3\.2 配置环境变量



```Bash
# 复制环境变量模板
cp ai-service/.env.example ai-service/.env

# 编辑 .env，填入DeepSeek API Key
# LLM_API_BASE=https://api.deepseek.com
# LLM_API_KEY=sk-your-deepseek-api-key
# LLM_MODEL=deepseek-chat
```



### 3\.3 一键启动



```Bash
# 构建并启动所有服务
docker-compose up -d

# 查看启动状态
docker-compose ps

# 查看日志
docker-compose logs -f
```



### 3\.4 验证服务



|服务|地址|验证方式|
|---|---|---|
|前端|http://localhost:3000|浏览器打开，看到登录页|
|后端API|http://localhost:8080/api/v1|`curl http://localhost:8080/api/v1/auth/me` 返回401|
|AI服务|http://localhost:8000|`curl http://localhost:8000/docs` 看到Swagger文档|
|PostgreSQL|localhost:5432|`psql -h localhost -U postgres -d aiextract`|
|Redis|localhost:6379|`redis-cli ping` 返回PONG|



### 3\.5 初始化数据库



```Bash
# 方式一：手动执行seed脚本
docker exec -i ai-extract-db-1 psql -U postgres -d aiextract < seed.sql

# 方式二：进入数据库容器执行
docker exec -it ai-extract-db-1 psql -U postgres -d aiextract
\i /seed.sql
```

## 四、分步启动（开发模式）



如果不想用Docker Compose一键启动，可以分别启动各个服务。



### 4\.1 启动数据库和缓存



```Bash
# 只启动数据库和Redis
docker-compose up -d db redis
```



### 4\.2 启动AI服务



```Bash
cd ai-service

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 复制环境变量
cp .env.example .env
# 编辑 .env，填入API Key

# 启动服务
uvicorn main:app --reload --port 8000
```



### 4\.3 启动后端



```Bash
cd backend

# 编译并启动
./mvnw spring-boot:run

# 或使用IDE直接运行 AiExtractApplication.java
```



### 4\.4 启动前端



```Bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```





## 五、项目初始化步骤（从头搭建）



如果是全新项目，按以下步骤初始化。



### 5\.1 创建前端项目



```Bash
npx create-next-app@latest frontend --typescript --tailwind --app --src-dir
cd frontend

# 安装组件库
npx shadcn-ui@latest init
# 选择：Default style, Slate base color, CSS variables

# 安装额外依赖
npm install zustand framer-motion
npm install @radix-ui/react-dialog @radix-ui/react-dropdown-menu
npm install @radix-ui/react-tabs @radix-ui/react-progress
```



**配置 tailwind\.config\.js**：

```JavaScript
// frontend/tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: { DEFAULT: '#1A2B4C', light: '#2D4373' },
        accent: { DEFAULT: '#C8A45C' },
        surface: { DEFAULT: '#F7F8FA', card: '#FFFFFF' },
        text: { primary: '#1A1A1A', secondary: '#6B7280' },
        success: '#059669',
        warning: '#D97706'
      }
    }
  }
}
```



### 5\.2 创建后端项目



```Bash
# 使用Spring Initializr创建项目
# 或手动创建Maven项目

# pom.xml 关键依赖：
# - spring-boot-starter-web
# - spring-boot-starter-data-jpa
# - spring-boot-starter-security
# - spring-boot-starter-webflux (用于SSE)
# - spring-cloud-starter-gateway
# - postgresql
# - flyway-core, flyway-database-postgresql
# - redis (spring-boot-starter-data-redis)
# - jjwt (io.jsonwebtoken)
```



**配置 application\.yml**：

```YAML
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/aiextract
    username: postgres
    password: password
  jpa:
    hibernate:
      ddl-auto: validate  # Flyway管理，不自动建表
  flyway:
    enabled: true
    locations: classpath:db/migration
  redis:
    host: localhost
    port: 6379

ai:
  service:
    url: http://localhost:8000

jwt:
  secret: your-secret-key-change-in-production
  expiration: 86400000

storage:
  type: local
  local:
    path: /data/files
```



### 5\.3 创建AI服务



```Bash
mkdir ai-service
cd ai-service

# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装依赖
pip install fastapi uvicorn openai python-dotenv openpyxl beautifulsoup4 python-pptx python-docx PyPDF2 watchdog httpx pydantic

# 创建requirements.txt
pip freeze > requirements.txt
```



### 5\.4 创建数据库迁移脚本



将第三章的完整DDL保存为 `backend/src/main/resources/db/migration/V1__init.sql`。



### 5\.5 创建Prompt模板文件



将以下文件放入 `prompts/`：

- `interview_system.md`（文档③ System Prompt）

- `skill_qa_chat.md`（分身基础模板）

- `meta_interview_system.md`（元萃取访谈Prompt）

- `expert_document_extraction.md`（文件材料提取Prompt）

    

### 5\.6 创建Docker Compose



将第二章的 `docker-compose.yml` 保存到项目根目录。





## 六、开发约定



### 6\.1 代码风格



|语言|规范|工具|
|---|---|---|
|Java|Google Java Style|Checkstyle|
|Python|PEP 8|Black \+ Ruff|
|TypeScript/React|Airbnb|ESLint \+ Prettier|



### 6\.2 Git规范



|分支|用途|
|---|---|
|`main`|生产分支|
|`dev`|开发分支|
|`feature/xxx`|功能分支|
|`fix/xxx`|修复分支|



**提交信息格式**：

```Plain Text
feat: 新增AI访谈引擎SSE流式接口
fix: 修复中断恢复时对话历史加载不全的问题
docs: 更新API接口文档
refactor: 重构Skill加载器
```



### 6\.3 接口规范



- 所有API接口统一 `/api/v1/` 前缀

- 请求体/响应体使用JSON格式

- SSE接口使用 `text/event-stream`

- 分页参数统一为 `page` 和 `size`

    

### 6\.4 数据库规范



- 使用Flyway管理数据库版本

- 禁止直接手动修改数据库结构

- 迁移脚本命名：`V{版本号}__{描述}.sql`

- 所有表使用UUID作为主键

## 八、常用命令速查



```Bash
# 启动所有服务
docker-compose up -d

# 停止所有服务
docker-compose down

# 查看日志
docker-compose logs -f backend
docker-compose logs -f ai-service

# 重建并启动
docker-compose up -d --build

# 进入数据库
docker exec -it ai-extract-db-1 psql -U postgres -d aiextract

# 执行seed脚本
docker exec -i ai-extract-db-1 psql -U postgres -d aiextract < seed.sql

# 前端开发
cd frontend && npm run dev

# 后端开发
cd backend && ./mvnw spring-boot:run

# AI服务开发
cd ai-service && source venv/bin/activate && uvicorn main:app --reload --port 8000
```

### PROMPTS_DIR 环境变量（v3.4）

- Docker: `PROMPTS_DIR=/app/prompts`，volumes 挂载 `./prompts:/app/prompts`
- Java: `PromptLoader` 优先读取 `PROMPTS_DIR`，其次 classpath `prompts/`
- Python: `PromptCache` 同逻辑，`PromptWatcher` 监听热重载
