    -H "Content-Type: application/json" \
    -d '{"account":"admin","password":"123456","companyCode":"DEFAULT01"}'

# 2. 跑对比
python3 scripts/grain-audit.py \
    --material-id 4015cc44-605c-4a4d-a775-2bdcfe4e8263 \

API 直接调用

curl http://localhost:8080/api/v1/admin/materials/{materialId}/audit-report \
    -H "Authorization: Bearer <token>"
返回完整的 materialInfo + pipelineTrace + chunkDetail + verifyDetail + dropLogs + finalGrains + summary。
