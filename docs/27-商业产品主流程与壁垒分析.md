### 流程①：萃取师技能（原料的原料）

```
上传材料 → 调度分析 → AI生成七章报告 → 提取7类萃取法则 → 激活 → 注入访谈
```

**商业价值**：把萃取师的经验变成 AI 可执行的追问指令，让每次访谈都有顶级萃取师的水平。

**当前状态（2026-07-01 更新）**：✅ 已修复 — 调 AI 从七章报告中拆解锦囊，AI 失败时降级为默认颗粒。

### 流程②：销冠访谈（核心原料生产）

```
创建访谈 → 四阶段对话 → 6模块采集 → 生成六章报告 → 提取锦囊 → 激活分身
```

**商业价值**：把销冠的隐性经验变成结构化的锦囊，是后续所有体验的数据基础。

**当前状态（2026-07-01 更新）**：✅ 已修复 — 调 AI 从六章报告中拆解锦囊，AI 失败时降级为基础颗粒。

### 流程③：分身问答（知识消费）

```
选择分身 → 加载锦囊 → 注入Prompt → AI用第一人称回答 → 追问引导
```

**商业价值**：员工随时随地向销冠的 AI 分身请教，获取真实案例和话术。

**当前状态（2026-07-01 更新）**：✅ 已修复 — 颗粒从 AI 报告提取后，每个分身的回答基于该销冠的真实经验和话术，不同分身回答不同。

### 流程④：分身对练（技能转化）

```
选择场景 → 客户开口 → 多轮博弈 → 客户带情绪反馈 → 结束评价
```

**商业价值**：安全环境中反复练习真实销售场景，AI 客户有性格有情绪。

**当前状态（2026-07-01 更新）**：✅ 已完成 — 场景从锦囊库加载（非硬编码），客户带情绪弧线，评价由 AI 基于真实对话生成。

## 二、壁垒分析

### 什么是真正的壁垒？

一个 AI 应用产品能建立的壁垒，不是技术本身（底层模型都是 DeepSeek），而是**企业独有的数据**+"**数据驱动的飞轮效应**"。

### 我们这个产品设计了什么壁垒？

| 壁垒 | 原理 | 护城河深度 |
|------|------|-----------|
| **萃取师经验库** | 企业自己的萃取师方法论，越用越好 | 深 — 每个企业的萃取师都是独特的 |
| **销冠锦囊库** | 每个销冠的真实案例、话术、失误 | 最深 — 不可复制，离职不可带走 |
| **AI分身人格化** | 每个分身的回答来自该销冠的真实数据 | 深 — 换一个销冠回答完全不同 |
| **数据飞轮** | 更多访谈→更多锦囊→更好分身→更多使用 | 最深 — 竞争对手无法复制 |

### 当前实现了多少？（2026-07-01 更新）

| 壁垒 | 设计 | 实现 |
|------|------|------|
| 萃取师经验库 | 7类萃取法则，每类从材料中提取 | ✅ AI 拆解 + 降级兜底 |
| 销冠锦囊库 | 从六章报告拆解场景+话术+心法 | ✅ AI 拆解 + 降级兜底 |
| AI分身人格化 | 不同分身引用不同的真实经验 | ✅ 不同锦囊库 = 不同分身 |
| 数据飞轮 | 每次访谈让系统更聪明 | ✅ 访谈→报告→锦囊→分身，链路已通 |

### 结论

**壁垒已立。** 锦囊提取从硬编码改为 AI 驱动，四个流程全部变为真实数据驱动。每次访谈产出的报告会自动拆解为颗粒，下次分身对话即可引用。飞轮已转起来。
