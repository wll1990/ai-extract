高级产品经理的判断
底部栏不是第三个菜单，它只回答两个问题：「我不会用，去哪学」和「我要找东西，怎么快」。

所以：
· 导览和帮助都属于「学」，但导览需要被看见，所以给首次卡片 + 底部复看入口；
· 帮助只有遇到问题才点，收进图标即可；
· ⌘K 是效率工具，一个图标足够，不需要文字；
· 三行文字会把辅助区做成第二菜单，这是 C 的问题。

结论

  • 采用 A：底部单行图标条（导览 / ⌘K / 帮助），34px 高，悬停出 tooltip。
  • 加首次使用卡片：只对没走完导览的用户显示，可关闭，走完不再出现——解决新用户找不到入口的问题。
  • 不做 B 的单入口：导览被藏进二级菜单，和「最多人需要的功能要在第一层」冲突。
  • 不做 C 的三行文字：辅助区不能和业务菜单同权重。
