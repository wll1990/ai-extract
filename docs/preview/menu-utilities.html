产品导览图标候选（产品经理 + 高级 UI 结论）

指南针 推荐

「带路、指引」的语义最贴导览；和系统里其它线性图标同一套语言；不会让人误以为是视频或录屏。

地图路线

强调「多条路线、章节路径」，适合导览中心页面本身；单独放侧栏时略像「场景地图」，容易和业务菜单混。

分步清单

强调「按步骤走」，但更像任务清单/待办，和「我的工作台」语义打架。

播放圆 排除

和 🎬 一样会让人以为是录屏/视频。我们的导览是真实页面上的聚光引导，不是播放录像，图标不能承诺错的东西。

结论与理由

  • 位置：侧栏最底部三行，业务菜单之上不混工具项。
  • 产品导览：指南针线性图标 + 文字，保留「产品导览」四个字，不靠图标猜。
  • 快捷入口：⌘ 图标 + ⌘K 键帽，点击打开命令面板。
  • 帮助：问号圆环 + 「帮助与 FAQ」，和顶栏不再重复放。
  • 移除：右下角悬浮坞、Token 用量常驻条、回到顶部按钮。
  • 设置/退出：留在头像菜单，工具区不放账号操作。
  • 图标规范：24×24 视框、1.6px 描边、圆角端点，与系统内线性图标一致；不混用 emoji。
  • 导览运行时：工具区正常显示，不隐藏——它本身就是导览入口。
