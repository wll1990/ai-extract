### 需要开发

#### A. 回调对接 SkillService

`FeishuAdapter` 收到消息后 → 调 `SkillService.chatToWriter()` → 将 SSE 流式输出收集为完整回复 → 通过飞书 API 发送。

```
飞书用户发消息
  → Feishu webhook 回调
  → 验签 + 解析消息
  → 查 ImChannel 获取 skillId
  → 调 SkillService.chatToWriter()
  → 收集 AI 回复全文
  → 追加溯源标注（命中/未命中）
  → buildReplyMessage() 发送到飞书
```

#### B. 溯源小字（markdown 格式）

飞书 markdown 语法：
```markdown
<font size=1 color=grey>
📋 异议处理 · 来源：销冠访谈_周铭.txt · ⭐4.5
</font>
```

五种状态的 markdown 格式：
- 📋 绿色 `<font color=green>` + 来源文件 + 评分
- 🔗 蓝色 `<font color=blue>` + "基于场景经验推断"
- 💡 黄色 `<font color=orange>` + "基于画像和心法"
- ⚠️ 红色 `<font color=red>` + "建议补充素材"
- 🚫 灰色 `<font color=grey>` + "非业务领域"

#### C. 开场白

飞书机器人首次进入对话时，主动推送欢迎消息：

```markdown
👋 你好，我是**张销冠**的AI分身

我专注金融科技销售，10年经验。擅长：
⚡ 异议处理 · ⚡ 逼单 · ⚡ 竞品博弈

> "先挖痛点再给方案，从不主动报价"

有什么想聊的？
```

数据来源：`Skill.ownerName/ownerTitle/department/seniority` + `SkillProfile.personality` + 场景标签列表。

#### D. 签名验证

飞书开放平台要求验证回调签名（SHA256），当前代码有逻辑但被注释。需要开启并测试。

#### E. 知识库配置

飞书机器人后台配置：
- 回调地址：`https://你的域名/api/v1/im/callback/feishu`
- App ID / App Secret 配置
- 权限申请：获取用户信息、发送消息、接收消息
