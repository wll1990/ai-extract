# 销售模块 · 按钮级操作手册

> 面向：一线销售、销售主管、教练、企业管理员。
> 目的：把销售导航下每个按钮「点下去会发生什么、什么时候该用、有什么前提」讲清楚。
> 依据：当前代码（2026-11-17 核对）。页面右上角「使用说明」与本文口径一致。

---

## 0. 先读这 6 条

1. **复盘、线索、跟进任务是三段，不是一件事**：复盘产出报告；转线索把客户存进线索池；生成跟进任务把报告的「下一步」变成待办。
2. **只有最新版且状态为 `ready` 的报告能转线索/建任务**；历史版本只读，切回最新版才能操作。
3. **按钮都有说明**：详情页按钮下方有「按钮说明」卡片；右上角「使用说明 → 按钮说明」逐条解释；鼠标悬停有 title。
4. **状态动作都可追溯**：线索状态、任务完成/取消、负责人变更都会写活动时间线或留档，不会物理删除。
5. **教练看到的是你的复盘**：是否展示完整原文由你勾选「允许教练看原文」决定；不勾选只看到摘要。
6. **权限决定入口**：销售用 `SALES_REVIEW` / `SALES_LEAD_MANAGE`，教练台账用 `SALES_REVIEW`，培训计划管理需要 `TRAINING_MANAGE`。

## 1. 我的销售看板 `/sales/dashboard`

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| 本周复盘 / 待跟进线索 / 待办跟进任务 / 本月转化 | 四张指标卡都是入口，跳到对应列表 | 数字只读，不改数据 |
| 团队共性问题 | 跳到团队共性问题页 | 只有企业管理员可见 |
| 最近复盘条目 | 打开复盘详情 | 可继续生成报告、转线索、建任务 |
| 使用说明 | 打开按钮说明抽屉 | 与本文一致 |

口径：本周从周一起；待跟进 = 跟进中且 7 天无活动或已到下次跟进时间；逾期 = 未完成且已过截止时间。

## 2. 销售复盘 `/sales/reviews`

### 2.1 列表页

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| ＋ 新建复盘 | 打开新建页 | 需要先有已发布分身 |
| 状态标签（全部/待生成/报告已生成/已转线索） | 只过滤列表 | 不改数据 |
| 我的 / 全公司 | 切换范围 | 全公司需要 `SALES_REVIEW_VIEW_ALL` |
| 刷新 | 重新拉列表 | — |
| 查看 / 客户名 | 打开复盘详情 | — |
| 重新生成（行内） | 仅报告失败的版本出现；新增一个报告版本 | 旧版本保留 |

列表顶部流程条：新建复盘 → 生成报告 → 转线索/建任务 → 在线索里跟进；可直接点「新建复盘」「去线索」。

### 2.2 新建复盘 `/sales/reviews/new`

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| 选择教练 | 只能选已发布个体分身 | 分身领域决定复盘视角 |
| 上传对话文件 | 解析 txt/docx/pdf 后填入文本框 | 不直接提交，可继续编辑 |
| 创建复盘 | 校验教练和文本后创建，跳到详情并异步生成报告 | 失败留在本页显示原因 |
| 取消 | 返回上一页，不保存 | — |
| 允许教练查看完整原文 | 决定教练台账看到摘要还是原文 | 之后可在详情页改 |

### 2.3 复盘详情 `/sales/reviews/[id]`

页面顶部会按状态给出「下一步」提示；按钮下方有常驻「按钮说明」。

| 按钮 | 点下去发生什么 | 前置 | 注意 |
|---|---|---|---|
| 生成报告 / 重新生成报告 | 调教练分身复盘；重新生成新增版本 | 最新版且无生成中任务 | 先弹确认；旧版本保留；会消耗模型额度 |
| 转线索 | 把客户和需求存进线索池 | 最新版 `ready` 且未转过线索 | 一份复盘只能转一次；转后状态变「已转线索」 |
| 生成跟进任务 | 把报告「下一步」复制成待办 | 最新版 `ready` | 最多选 3 条，可改标题/渠道/截止/话术；同名自动跳过；创建后到「跟进任务」完成 |
| 沉淀为案例 / 沉淀为知识 | 生成对应库草稿 | 最新版 `ready` | 先弹确认；不会直接生效，需管理员审核 |
| 允许教练看原文 | 控制教练台账能看到摘要还是完整对话 | 仅发起人可操作 | 随时可改 |
| 历史版本下拉 | 只读查看旧报告 | 版本数 > 1 | 历史版本不能转线索/建任务/沉淀 |
| 查看引用 | 展开判断对应的原文段落 | — | 报告里客户信号区分客户原话/销售转述/AI 推断 |
| 继续问教练 | 基于本次报告追问 | 报告已生成 | 只追加对话，不重新生成报告 |
| 请教练补充 | 向分身教练发起补充请求 | 发起人、非本人教练 | 可附问题；可同时授权原文；未回复前可撤回 |

报告六个区块：一句话结论、做得好的、不足、风险、客户信号、下一步。客户信号会标置信度，判断不了时显示「未提及」。

## 3. 线索 `/sales/leads`

### 3.1 列表页

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| 状态标签（全部/新线索/跟进中/已成交/无效） | 只过滤列表 | — |
| 刷新 | 重新拉列表 | — |
| 开始跟进 | 新线索 → 跟进中 | 表示已开始接触客户 |
| 标记成交 | 跟进中 → 已成交 | 不会自动创建订单 |
| 标记无效 | 退出待跟进 | 记录保留，可恢复 |
| 恢复为新线索 | 无效 → 新线索 | 重新进入待跟进 |
| 客户名 | 打开线索详情 | — |
| 来自复盘 | 打开来源复盘 | 来源复盘已删除时只显示文本 |

### 3.2 线索详情 `/sales/leads/[id]`

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| 开始跟进 / 标记成交 / 标记无效 / 恢复 | 推进状态 | 活动时间线自动记录 |
| 编辑资料 | 修改名称、需求摘要、下次跟进时间等 | 不改状态和活动记录 |
| 分配负责人 | 把线索交给本企业成员 | 只改负责人，会记录操作人 |
| ＋ 添加联系人 / 编辑 / 删除 | 维护客户关键人 | 删除不可撤销 |
| 添加备注 | 把沟通结论追加到活动时间线 | 不覆盖需求摘要 |
| 去任务页 | 查看完整跟进任务 | 详情只展示最近 50 条 |

活动时间线是只读审计记录；状态变更、负责人变更、备注都会自动追加。

## 4. 跟进任务 `/sales/tasks`

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| 状态标签（待办/已完成/已取消/全部） | 只过滤列表 | — |
| 完成 | 待办 → 已完成 | 任务留档，不会删除 |
| 取消 | 待办 → 已取消 | 放弃跟进，仍可回看 |
| 编辑 | 改标题、渠道、截止时间、跟进话术 | 不改负责人和状态 |
| 转交 | 把负责人改成同事 | 任务状态不变，原负责人收到通知 |
| 升级 | 仅逾期且未升级的任务可点 | 提醒上级介入，任务仍需完成/取消 |
| 刷新 | 重新拉列表 | — |

逾期按截止时间判断；没有截止时间的任务不会被标记逾期。

## 5. 教练台账 `/sales/coach/ledger`

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| 复盘记录 / 待我补充 | 切换列表 | 切换回第 1 页 |
| 查看原文 | 打开完整对话 | 仅发起人授权时可见；未授权只显示摘要 |
| 标记已读 | 未读 → 待处理 | 只是状态，不发送回复；可批量 |
| 回复 | 给发起人补充判断 | 批量回复会把同一内容发给选中全部 |
| 转交 | 把请求交给其他教练 | 一次一条；只换请求负责人，不改复盘归属 |
| 状态筛选 / 只看指派给我的 | 过滤请求 | 只影响列表 |

教练补充页 `/sales/coach/requests/[sessionId]`：

| 按钮 | 说明 |
|---|---|
| 提交补充 | 追加人工判断并通知发起人；不改写 AI 报告，不撤回 |
| 原文 | 发起人授权后才显示完整对话 |

## 6. 我的培训 `/training` 与培训计划 `/admin/training/plans`

| 按钮 | 点下去发生什么 | 注意 |
|---|---|---|
| 刷新 | 重新拉分配、任务、认证状态 | 不改学习记录 |
| 我的学习 / 我带的批次 | 切换视角 | 「我带的批次」需要培训复核/管理权限 |
| 展开任务 / 收起 | 按阶段展示任务 | 已结束的考试/陪练点开先看成绩 |
| 开始 / 继续 / 再试一次 | 进入阅读、陪练或考试 | 未解锁时按钮不可点，先完成前置任务 |
| 查看内容 / 查看成绩 | 回看正文或历史成绩 | 不重新发起尝试 |
| 下载认证证书 | 新窗口打开可打印证书 | 必修全部通过并确认认证后出现 |
| 绑定 IM / 解绑 | 控制飞书/企微/钉钉提醒 | 解绑只停 IM 提醒，站内信不受影响 |
| AI 生成计划 | 按训练目标生成草稿计划 | 仍需预览、调整、发布 |
| ＋ 新建计划 | 手工创建空白计划 | 创建后进入编辑页 |
| 编辑 / 批次 | 进入计划编辑页 | 可从已发布版本创建批次 |
| 查看进度 | 进入批次详情 | 看学员进度、复核、认证 |
| 结班 / 取消 / 归档 | 推进批次生命周期 | 归档后不再接收新学员，历史保留 |

## 7. 最容易踩的 8 个坑

1. 报告还是旧版就去转线索——切回最新版，且状态必须是 `ready`。
2. 把「生成跟进任务」当成转线索——任务只是待办，客户仍在复盘里，需要另外转线索。
3. 同一份复盘反复转线索——转过后不再显示转线索，后端也会拒绝。
4. 在历史版本上找按钮——历史版本只读，切回最新版。
5. 以为标记已读等于回复——已读只是状态，回复才通知发起人。
6. 任务转交后以为状态变了——转交只换负责人，任务仍需完成/取消。
7. 升级逾期任务后以为自动完成——升级只是提醒上级，任务仍需处理。
8. 教练看不到原文就以为系统坏了——是发起人没有勾选「允许教练看原文」。

## 8. 权限速查

| 能力 | employee | company_admin | super_admin |
|---|---|---|---|
| 新建/查看自己的复盘 | ✅ | ✅ | ✅ |
| 查看全公司复盘 | ❌ | ✅（`SALES_REVIEW_VIEW_ALL`） | ✅ |
| 转线索 / 生成跟进任务 / 沉淀草稿 | ✅（自己的复盘） | ✅ | ✅ |
| 线索、任务管理 | ❌（默认） | ✅（`SALES_LEAD_MANAGE`） | ✅ |
| 教练台账 | ✅（有教练分身） | ✅ | ✅ |
| 培训计划管理 | ❌ | ✅（`TRAINING_MANAGE`） | ✅ |
| 我的培训 | ✅ | ✅ | ✅ |

> 权限以后端 `RolePermissions` 与菜单下发为准；本文只列销售模块常用项。
