### 新增方法（在第 77 行 `retrieveWithScores` 方法之后追加）

```java
/**
 * 多空间语义检索 — 跨多个 space 做 pgvector ANN 检索。
 * 用于 enterprise chat 和综合分身（组织分身）。
 *
 * @param question 查询文本
 * @param spaceIds 空间 ID 列表（非空，size ≥ 1）
 * @param topK    最大返回数
 * @return 按 weightedScore 降序排列的结果
 */
public List<GrainResult> retrieveWithScores(String question, List<UUID> spaceIds, int topK) {
    long t0 = System.currentTimeMillis();
    float[] queryVector = embeddingService.embed(question);
    if (queryVector == null || queryVector.length == 0) {
        log.error("嵌入服务返回空 question={}", question.substring(0, Math.min(100, question.length())));
        return List.of();
    }
    String vectorStr = arrayToPgVector(queryVector);

    // 构建 IN 子句的占位符
    String placeholders = spaceIds.stream().map(id -> "?").collect(Collectors.joining(","));
    String sql = String.format("""
        SELECT g.*, 1.0 - (g.embedding <=> ?::vector) AS similarity
        FROM experience_grain g
        WHERE g.space_id IN (%s) AND g.status = 'active' AND g.embedding IS NOT NULL
        ORDER BY g.embedding <=> ?::vector
        LIMIT ?
        """, placeholders);

    // 参数数组：vectorStr, spaceId1, spaceId2, ..., vectorStr, topK*3
    Object[] params = new Object[spaceIds.size() + 3];
    params[0] = vectorStr;
    for (int i = 0; i < spaceIds.size(); i++) {
        params[i + 1] = spaceIds.get(i);
    }
    params[spaceIds.size() + 1] = vectorStr;
    params[spaceIds.size() + 2] = topK * 3;

    Map<UUID, Double> simMap = new LinkedHashMap<>();
    List<ExperienceGrain> candidates = jdbc.query(sql,
        (rs, rowNum) -> {
            ExperienceGrain g = mapGrainRow(rs, rowNum);
            simMap.put(g.getId(), rs.getDouble("similarity"));
            return g;
        },
        params
    );

    // Step 2: weight 重排 → 组装结果（与单 space 逻辑完全一致）
    List<GrainResult> results = candidates.stream()
        .sorted((a, b) -> Double.compare(
            simMap.getOrDefault(b.getId(), 0.0) * getWeight(b),
            simMap.getOrDefault(a.getId(), 0.0) * getWeight(a)))
        .limit(topK)
        .map(g -> new GrainResult(g, round2(simMap.getOrDefault(g.getId(), 0.0)),
            round2(simMap.getOrDefault(g.getId(), 0.0) * getWeight(g))))
        .toList();

    log.info("多空间RAG检索完成 {}ms spaceIds={} candidates={} results={}",
        System.currentTimeMillis() - t0, spaceIds.size(), candidates.size(), results.size());
    return results;
}
```

**需要追加 import**：
```java

```

> 已确认 `experience_grain` 表有索引 `idx_grain_space ON experience_grain(space_id)` 和 `idx_experience_grain_space_status ON experience_grain(space_id, status)`，`WHERE space_id IN (...)` 可走 Bitmap Index Scan，性能可接受。

## 改动 2：RagPipelineService — 多 space RAG 管道

**文件**：`backend/src/main/java/com/aiextract/service/RagPipelineService.java`

### 新增方法（在第 222 行 `retrieveGrainsWithScores` 方法之后追加）

```java
/**
 * 多空间语义检索 + 分层 — 用于 enterprise chat 和综合分身。
 * 与单 space 版本共享同一套 tier 阈值和日志记录逻辑。
 *
 * @param query    改写后查询
 * @param spaceIds 空间 ID 列表
 * @param topK     最大返回数
 * @param domain   领域标识
 * @param ragCtx   检索上下文
 */
public GrainResult retrieveGrainsWithScores(String query, List<UUID> spaceIds, int topK,
                                             String domain, RagContext ragCtx) {
    long tRag = System.currentTimeMillis();
    List<GrainRetriever.GrainResult> scored = grainRetriever.retrieveWithScores(query, spaceIds, topK);
    long ragMs = System.currentTimeMillis() - tRag;

    if (scored.isEmpty()) {
        log.info("多空间RAG无结果 spaceIds={}", spaceIds.size());
        // 多空间不写知识缺口——缺口属于具体分身
        return new GrainResult(List.of(), Map.of(), Map.of());
    }

    // tier 阈值（与单 space 版本共享同一逻辑，可提取公共方法）
    double highThreshold = 0.50;
    double refThreshold = 0.30;
    if (domain != null) {
        DomainConfig dc = domainConfigLoader.load(domain);
        if (dc != null && dc.getPrecheck() != null) {
            highThreshold = dc.getPrecheck().getRagHighThreshold();
            refThreshold = dc.getPrecheck().getRagRefThreshold();
        }
    }

    Map<UUID, String> tiers = new LinkedHashMap<>();
    Map<UUID, Double> similarities = new LinkedHashMap<>();
    int pos = 1;
    for (var r : scored) {
        similarities.put(r.grain().getId(), r.similarity());
        if (r.similarity() >= highThreshold) {
            tiers.put(r.grain().getId(), "high");
        } else if (r.similarity() >= refThreshold) {
            tiers.put(r.grain().getId(), "ref");
        }
        try {
            grainRetrieveLogRepository.save(GrainRetrieveLog.builder()
                .id(UUID.randomUUID())
                .skillId(ragCtx != null ? ragCtx.skillId() : null)
                .conversationId(ragCtx != null ? ragCtx.conversationId() : UUID.randomUUID())
                .originalQuery(ragCtx != null ? ragCtx.originalQuery() : null)
                .rewrittenQuery(query)
                .grainId(r.grain().getId())
                .sceneTag(r.grain().getSceneTag())
                .similarity(r.similarity())
                .tier(tiers.get(r.grain().getId()))
                .position(pos++)
                .createdAt(LocalDateTime.now())
                .build());
        } catch (Exception e) {
            log.debug("写检索日志失败: {}", e.getMessage());
        }
    }

    List<ExperienceGrain> grains = scored.stream()
        .map(GrainRetriever.GrainResult::grain).toList();
    log.info("多空间RAG检索完成 {}ms topK={} tags={} high={} ref={}",
        ragMs, scored.size(),
        grains.stream().map(ExperienceGrain::getSceneTag).distinct().limit(5).toList(),
        tiers.values().stream().filter("high"::equals).count(),
        tiers.values().stream().filter("ref"::equals).count());
    return new GrainResult(grains, tiers, similarities);
}
```

public Flux<ChatChunk> enterpriseChat(SkillChatRequest request, UUID companyId) {
    long t0 = System.currentTimeMillis();
    String query = request.getMessage();
    log.info("═══ 企业总调度问答开始 ═══ companyId={} msg={}",
        companyId, query.substring(0, Math.min(50, query.length())));

    // ── Phase 1: 收集公司下所有 space ──
    List<UUID> companySpaceIds = spaceRepository.findByUserIdIn(
        userRepository.findByCompanyId(companyId).stream().map(User::getId).toList()
    ).stream().map(Space::getId).toList();

    if (companySpaceIds.isEmpty()) {
        return Flux.just(ChatChunk.error("企业暂无可用分身"));
    }

    // ── Phase 2: RAG 管道（查询改写 + 多空间向量检索 + 分层） ──
    String domain = "sales.b2b_enterprise";
    String ragHistory = null; // 企业调度暂不维护对话历史
    String ragQuery = ragPipelineService.rewriteQuery(query,
        ragHistory, domain, null); // skillId=null，企业调度不关联单个分身
    UUID pseudoConvId = UUID.randomUUID();
    RagPipelineService.RagContext ragCtx = new RagPipelineService.RagContext(
        null, pseudoConvId, query);
    RagPipelineService.GrainResult grains = ragPipelineService.retrieveGrainsWithScores(
        ragQuery, companySpaceIds, 5, domain, ragCtx);

    // ── Phase 3: 组装 prompt + 流式 + 后处理（对标个人分身） ──
    final long tAiStart = System.currentTimeMillis();
    final StringBuilder aiContent = new StringBuilder();
    final AtomicBoolean hasStreamError = new AtomicBoolean(false);

    String systemPrompt = promptAssembly.buildEnterpriseSystemPromptV2(
        ragQuery, grains.grains(), grains.tiers(), companySpaceIds, domain);
    List<Map<String, String>> messages = List.of(
        Map.of("role", "system", "content", systemPrompt),
        Map.of("role", "user", "content", query)
    );

    Flux<ChatChunk> aiStream = chatStreamAdapter.chatStream(messages, Map.of("mode", "enterprise"))
        .map(event -> {
            ChatChunk chunk = ChatChunk.fromEventMap(event);
            if ("content".equals(chunk.getType()) && chunk.getContent() != null) {
                aiContent.append(chunk.getContent());
            }
            return chunk;
        })
        .timeout(Duration.ofSeconds(chatTimeoutSeconds))
        .doOnError(e -> {
            hasStreamError.set(true);
            log.error("企业调度SSE流异常", e);
        })
        .onErrorResume(err -> Flux.just(ChatChunk.error(ErrorMessages.AI_SERVICE_UNAVAILABLE)));

    // Post-stream：溯源 + meta
    Flux<ChatChunk> postStream = Flux.defer(() -> {
        long totalMs = System.currentTimeMillis() - t0;
        log.info("✅ 企业调度完成 total={}ms grains={}", totalMs, grains.grains().size());
        return Flux.concat(
            Flux.just(ChatChunk.meta(pseudoConvId.toString())),
            buildEnterpriseSourceChunkFlux(grains.grains(), grains.similarities())
        );
    });

    return Flux.concat(aiStream, postStream)
        .doFinally(s -> {
            try {
                double avgSim = grains.similarities().isEmpty() ? 0
                    : grains.similarities().values().stream()
                        .mapToDouble(Double::doubleValue).average().orElse(0);
                String errorType = hasStreamError.get() ? "stream_error" : null;
                conversationStatsRepository.save(ConversationStats.builder()
                    .id(UUID.randomUUID())
                    .conversationId(pseudoConvId)
                    .mode("enterprise")
                    .ragHighCount((int) grains.tiers().values().stream()
                        .filter("high"::equals).count())
                    .ragRefCount((int) grains.tiers().values().stream()
                        .filter("ref"::equals).count())
                    .ragNoneCount(grains.grains().isEmpty() ? 1 : 0)
                    .ragAvgSimilarity(avgSim)
                    .errorType(errorType)
                    .isTest(false)
                    .llmDurationMs((int) (System.currentTimeMillis() - tAiStart))
                    .totalDurationMs((int) (System.currentTimeMillis() - t0))
                    .createdAt(LocalDateTime.now())
                    .build());
            } catch (Exception e) {
                log.warn("写入enterprise stats失败: {}", e.getMessage());
            }
        });
}

```java
/**
 * 构建企业总调度 System Prompt V2 — 带 tier 标记 + 销冠姓名。
 * 替代旧版 buildEnterpriseSystemPrompt（仅按 space 分组，无姓名，无 tier）。
 */
public String buildEnterpriseSystemPromptV2(String question, List<ExperienceGrain> grains,
        Map<UUID, String> grainTiers, List<UUID> companySpaceIds, String domain) {
    // 预加载 space→ownerName 映射，避免逐个查
    Map<UUID, String> spaceOwnerMap = new HashMap<>();
    if (!grains.isEmpty()) {
        List<UUID> distinctSpaceIds = grains.stream()
            .map(ExperienceGrain::getSpaceId).distinct().toList();
        List<Space> spaces = spaceRepository.findAllById(distinctSpaceIds);
        List<UUID> userIds = spaces.stream().map(Space::getUserId).distinct().toList();
        Map<UUID, String> userNames = userRepository.findAllById(userIds).stream()
            .collect(Collectors.toMap(User::getId, User::getName, (a, b) -> a));
        for (Space sp : spaces) {
            spaceOwnerMap.put(sp.getId(),
                userNames.getOrDefault(sp.getUserId(), "销冠"));
        }
    }

    StringBuilder expCtx = new StringBuilder();
    if (!grains.isEmpty()) {
        Map<UUID, List<ExperienceGrain>> bySpace = new LinkedHashMap<>();
        for (ExperienceGrain g : grains) {
            bySpace.computeIfAbsent(g.getSpaceId(), k -> new ArrayList<>()).add(g);
        }
        for (Map.Entry<UUID, List<ExperienceGrain>> entry : bySpace.entrySet()) {
            String ownerName = spaceOwnerMap.getOrDefault(entry.getKey(), "销冠");
            expCtx.append("## ").append(ownerName);
            // tier 标记
            String tier = grainTiers.getOrDefault(
                entry.getValue().get(0).getId(), null);
            if ("high".equals(tier)) {
                expCtx.append(" 【核心经验 · 高度匹配】");
            } else if ("ref".equals(tier)) {
                expCtx.append(" 【参考经验】");
            }
            expCtx.append("\n");
            for (ExperienceGrain g : entry.getValue()) {
                if (g.getSceneTag() != null)
                    expCtx.append("- 场景：").append(g.getSceneTag()).append("\n");
                if (g.getExpertThought() != null)
                    expCtx.append("  思考：").append(truncate(g.getExpertThought(), 200)).append("\n");
                if (g.getStandardScript() != null)
                    expCtx.append("  话术：\"").append(truncate(g.getStandardScript(), 300)).append("\"\n");
                if (g.getCommonMistakes() != null)
                    expCtx.append("  避坑：").append(truncate(g.getCommonMistakes(), 150)).append("\n");
            }
            expCtx.append("\n");
        }
    } else {
        expCtx.append("（暂无经验数据，基于通用销售逻辑回答）\n");
    }

    return promptLoader.format("enterprise_system.md", Map.of(
        "experience_context", expCtx.toString()
    ), domain);
}
```

## 改动 6：ChatStreamService — buildEnterpriseSourceChunkFlux

```java
/**
 * 企业调度溯源 SSE — 从跨空间检索结果构建 source chunk。
 * 与个人分身的 buildSourceChunkFlux 类似，但 grainId 可能来自不同 space。
 */
private Flux<ChatChunk> buildEnterpriseSourceChunkFlux(
        List<ExperienceGrain> grains, Map<UUID, Double> similarities) {
    if (grains.isEmpty()) return Flux.empty();

    // 预加载 space→ownerName
    List<UUID> spaceIds = grains.stream().map(ExperienceGrain::getSpaceId).distinct().toList();
    Map<UUID, String> ownerNames = new HashMap<>();
    try {
        List<Space> spaces = spaceRepository.findAllById(spaceIds);
        List<UUID> userIds = spaces.stream().map(Space::getUserId).distinct().toList();
        Map<UUID, String> userNames = userRepository.findAllById(userIds).stream()
            .collect(Collectors.toMap(User::getId, User::getName, (a, b) -> a));
        for (Space sp : spaces) {
            ownerNames.put(sp.getId(), userNames.getOrDefault(sp.getUserId(), "销冠"));
        }
    } catch (Exception e) {
        log.warn("加载溯源销冠名失败: {}", e.getMessage());
    }

    String grainIds = grains.stream()
        .map(g -> g.getId().toString())
        .collect(Collectors.joining(","));
    String grainTags = grains.stream()
        .map(g -> {
            String name = ownerNames.getOrDefault(g.getSpaceId(), "");
            String tag = g.getSceneTag() != null ? g.getSceneTag() : "";
            return name.isEmpty() ? tag : name + "·" + tag;
        })
        .collect(Collectors.joining(","));
    double avgScore = similarities.values().stream()
        .mapToDouble(Double::doubleValue).average().orElse(0);
    double avgSim = avgScore; // 保留原始语义

    return Flux.just(ChatChunk.source(grainIds, grainTags,
        Math.min(grains.size(), 5), Math.round(avgScore * 100) / 100.0, avgSim));
}
```
