## 1\. 产品定位



基于顶尖萃取师方法论（BEI、认知任务分析、隐喻诱引），通过AI深度访谈，将销冠的隐性经验转化为“道、术、坑”三维一体的专业成果。以“人”为单位建立经验空间，生成AI分身Skill，并通过企业级调度系统实现经验的精准匹配与即时调用。



**核心壁垒**：元萃取系统——将真实萃取师的实践智慧转化为AI可执行的隐性知识指令，持续提升AI访谈质量。



---



## 2\. 用户角色与权限



系统面向两类用户角色，UI 层呈现为管理员/用户。后端数据库中保留 `super_admin`（管理员）、`employee`（有空间的用户）、`employee`（普通用户）三种角色值以实现权限细分：

| UI 角色 | DB 角色值 | 权限 |
|---------|-----------|------|
| **管理员** | `super_admin` | 管理所有空间、查看所有数据、配置模型与IM渠道、查看场景覆盖地图、发起萃取邀请、管理分身（公开/停用）、**管理萃取师经验库（上传材料/分析/审核法则/激活Skill）** |
| **用户（有空间）** | `employee` | 管理自己的空间、创建访谈、查看/编辑报告、编辑档案（含一句话介绍）、查看调用数据、使用分身问答/对练 |
| **用户** | `employee` | 浏览分身广场、使用分身问答/对练、浏览授权空间、下载资料、提交反馈评分、为报告打分 |

侧边栏菜单根据角色动态展示：
- 所有人可见：工作台、分身广场
- 有空间用户追加：我的空间、创建访谈
- 管理员追加：分身管理、萃取师经验库、场景地图、IM管理

## 4\. AI访谈引擎



|序号|能力项|说明|
|---|---|---|
|4\.1|结构化引导|按四阶段推进：开场定调→故事深描→模型提炼→收网确认|

## 5\. 输出：个人空间（以人为单位）



### 5\.1 个人档案

- 姓名、岗位、年限、标签

- 一句话介绍：AI从访谈金句中自动提炼，销冠可编辑修改

    

### 5\.2 经验报告墙

- 该销冠所有萃取报告列表

- 每个报告支持：Web版预览、Word下载、PPT下载

- 报告结构（六章）：案例故事、方法论（术）、心法（道）、避坑指南（坑）、行动检查清单、情景练习

- 最新报告卡片显示“新”标签

- 初始评分4\.5，员工阅读后可打分，平均分实时更新

    

### 5\.3 AI分身Skill

- 基于该销冠全部已发布报告的锦囊训练

- 管理员可配置“仅使用指定报告”

- 功能模式：问答模式、对练模式

- 问答模式维护会话上下文（最近5轮），支持连续提问

- 对练模式预设场景从该销冠报告案例中自动提取，同时支持员工自定义场景

- 调用渠道：飞书机器人、企微应用、微信小程序、网页端

    

### 5\.4 资料库

- 金句海报：AI自动生成

- 话术卡片：AI自动生成

- 行动检查清单：从报告提取

- 情景模拟剧本：从报告练习提取

- 讲师手册：MVP阶段标记“敬请期待”

- 评估表：MVP阶段标记“敬请期待”

    

### 5\.5 数据面板

- 空间浏览/调用次数、分身问答次数、热门内容排行

    

### 5\.6 萃取师经验库（新增）

- 系统支持将真实萃取师的实践智慧转化为AI可执行的隐性知识指令

- 来源渠道：真人访谈、文件材料上传（案例报告/课件/文章）、两者混合

- 产出：《萃取师经验报告》→ 锦囊 → 萃取师Skill

- 应用：创建访谈时可选使用哪位萃取师的经验，或使用综合多位萃取师的综合Skill

- 向下兼容：不选时使用基础版AI萃取引擎

## 8\. 用户交互流程



### 8\.1 销冠路径：创建访谈 → 完成萃取



```Plain Text
登录 → 我的空间 → 创建新访谈
    → 选择萃取主题 + 选择萃取风格（综合/指定萃取师/基础版）
    → 开始AI访谈（四阶段对话）
    → 访谈中断 → 恢复弹窗“继续/重新开始”
    → 访谈完成 → 报告生成完成页
    → 预览报告 → 下载Word/PPT → 编辑报告
    → 查看我的AI分身 → 分享空间
```



### 8\.2 员工路径：学习经验 → 使用分身



```Plain Text
登录 → 经验广场（浏览所有空间）
    → 进入销冠空间 → 查看报告
    → 使用AI分身（问答/对练）
    → 下载资料（海报/卡片/清单）
    → 打分反馈
    → 在飞书/企微中 @销冠分身 提问
```



### 8\.3 管理员路径：配置系统 → 管理经验库



```Plain Text
登录 → 企业管理后台
    → 空间管理（查看/编辑所有空间）
    → 场景覆盖地图（查看覆盖状态，邀请萃取）
    → IM渠道配置（飞书/企微）
    → 模型配置（选择大模型/API Key）
    → 萃取师经验库（上传材料/审核法则/激活Skill）
```



### 8\.4 访谈交互细节

- 访谈前：暖开场——AI 温暖自我介绍，建立信任，锁定具体成功案例
- 访谈中：四阶段进度条 + 右侧采集面板（6 模块实时标记：案例故事、核心步骤、关键决策、专家心法、适用边界、行动清单）；阶段引导卡片提示当前阶段目标；AI 主动发出【建议推进】高亮提示
- 访谈中断：暂停按钮（会话列表 ⋮ 菜单）+ 恢复弹窗（继续上次/重新开始），AI 自动衔接上下文
- 访谈后：完成致谢卡片（展示成果摘要），不自动跳转报告页——用户手动查看报告

    

### 8\.5 对练交互细节

- 对练场景选择：从锦囊库按 scene_tag 自动生成场景（含标题、背景设定、客户开场白），同时支持员工自定义场景
- 对练中：角色气泡区分（AI 客户灰气泡左对齐 vs 用户品牌色气泡右对齐）；AI 扮演难缠客户，带情绪弧线（怀疑→试探→被打动）；不中途评判，完全模拟真实对话
- 对练结束：综合评价卡片——AI 以销冠视角复盘，给出优点（引用对话原句）、改进点、销冠示范话术、下次建议。无固定分数（不虚构 85 分）

## 13\. 元萃取系统（新增）



### 13\.1 元萃取概述



元萃取是产品的核心壁垒。当前AI萃取专家的能力基于BEI等显性理论，但顶尖萃取师身上有理论不教的**实践智慧**——判断直觉、心智框架、失败经验。



**元萃取**：用AI访谈萃取师/分析萃取师文件材料，获取其实践智慧，转化为AI可执行的隐性知识指令。



### 13\.2 两种输入渠道



|渠道|优势|局限|适用场景|
|---|---|---|---|
|**真人访谈**|可追问细节、情绪、直觉|萃取师时间难约|有渠道接触到的萃取师|
|**文件材料**|不受时间限制，可批量处理|无法追问，材料质量参差|拿不到真人但拿得到案例|
|**两者结合**|先用文件做初步提取，再针对性访谈|—|最优方案|



### 13\.3 处理流程



```
收集材料/邀请萃取师
    ↓
上传文件 或 开始元萃取访谈
    ↓
调度器扫描（30s 轮询 + 乐观锁）→ status=analyzing
    ↓
AI分析 → 生成《萃取师经验报告》
    ├── 自动解析：txt/md/csv/html/docx/pdf/pptx/xlsx
    └── 人工处理：图片/音频 → 返回提示词模板 → status=pending_manual
    ↓
status=extracting（待提取法则）
    ↓
管理员手动点击"提取法则" → AI 从全部历史报告全量重提（删除旧法则后重新提取）
    ↓
法则审核（under_review）→ 编辑/删除/调整优先级
    ↓
确认入库 → 激活萃取师Skill → status=active
    ↓
更新综合Skill（regenerateCompositeAsync — 当前为空壳，待实现）
    ↓
创建访谈时可选择萃取风格
```

**注意**：法则提取（extractGrains）为手动触发操作，非自动执行。追加文件后需重置 status=pending 才会被调度器重新处理。综合 Skill 生成当前为空实现。



### 13\.4 多萃取师经验协同



|情况|处理方式|
|---|---|
|多个萃取师提到同一判断直觉|合并为“共识”，优先级提升|
|不同萃取师对同一场景有不同建议|保留双方观点，标注来源|
|某位萃取师有独特经验|保留为“独家经验”|
|两位萃取师建议直接矛盾|标记为“注意项”，AI动态判断|



### 13\.5 在访谈中的应用



创建访谈时可选萃取风格：

- **综合（默认）**：使用所有已激活萃取师的综合经验

- **指定萃取师**：使用某位特定萃取师的经验风格

- **基础版**：不使用萃取师经验

    

选择后在B4报告完成页显示本次使用的萃取师来源。访谈流程不变（四阶段对话流、追问规则、禁忌全部保留），仅Prompt中`{expert_tacit_knowledge}`占位符替换内容不同。
