# 领域配置参考

> `domain/*.yml` 完整字段说明。该系统所有领域相关行为的唯一配置源。

---

## 一、文件结构

```
domain/
├── _tree.json               ← 领域树，GET /api/domains 直接返回
├── sales.yml                ← 销售一级（通用配置，可被继承）
├── sales/
│   └── b2b_enterprise.yml   ← 销售·B2B大客户（extends: sales）
├── finance.yml              ← 金融一级
├── finance/
│   └── secondary_market.yml ← 金融·二级市场研究（extends: finance）
```

- `_tree.json`：前端领域选择器的数据源
- 一级 YAML：领域通用配置，可被二级继承
- 二级 YAML：`extends: {一级ID}`，只写差异项

---

## 二、顶层结构

```yaml
extends: sales          # 可选，继承的父领域 ID（一级域名）
domain:   {...}         # 领域基本信息
acceptance: {...}       # Gate 1 准入标准
precheck: {...}         # Gate 2 质量预检
pipeline: {...}         # 萃取流水线参数
chat:     {...}         # Chat 三种模式配置
```

## 三、domain — 领域基本信息

| 字段 | 类型 | 必填 | 说明 | 销售示例 | 金融示例 |
|------|------|------|------|---------|---------|
| `id` | string | ✅ | 唯一标识，点号分隔层级 | `sales` | `finance.secondary_market` |
| `name` | string | ✅ | 对外展示名 | `B2B 大客户销售` | `二级市场研究` |
| `role_label` | string | ✅ | 专家称呼 | `销冠` | `研究员` |
| `counterparty_label` | string | ✅ | 对话另一方称呼 | `客户` | `市场` |
| `skill_label` | string | ✅ | 技能称谓 | `销售技巧` | `投资研究能力` |
| `knowledge_unit` | string | ✅ | 知识单元名（单数） | `锦囊` | `投资洞察` |
| `knowledge_unit_plural` | string | ✅ | 知识单元名（复数） | `条销冠锦囊` | `条投资洞察` |

## 四、acceptance — 准入标准（Gate 1）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `min_text_length` | int | 50 | 最少字符数，低于拒收 |
| `chinese_ratio_min` | double | 0.70 | 中文占比下限 |
| `sales_keyword_density_min` | double | 0.005 | 关键词密度下限 |
| `first_person_ratio_min` | double | 0.01 | 第一人称占比下限（反教科书） |
| `theoretical_ratio_max` | double | 0.30 | 理论句式占比上限 |
| `marketing_ratio_max` | double | 0.15 | 营销信号词上限 |
| `duplicate_similarity_max` | double | 0.90 | 重复拒收阈值 |
| `sales_keywords` | list[string] | — | 关键词全集 |
| `business_whitelist` | list[string] | — | **业务白名单**，含这些词的行不被 BusinessNoiseFilter 删除 |
| `marketing_signals` | list[string] | — | 营销广告信号词 |
| `ai_signals` | list[string] | — | AI 生成信号词（标记不拒收） |

## 五、precheck — 质量预检（Gate 2）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `min_dialogue_turns` | int | 3 | 最少对话轮次 |
| `min_customer_ratio` | double | 0.20 | 对方发言占比建议下限 |
| `business_density_threshold` | double | 0.02 | 业务关键词密度建议阈值 |
| `noise_ratio_max` | double | 0.50 | 噪音占比上限 |
| `chinese_ratio_warn` | double | 0.80 | 中文占比警告阈值 |
| `duplicate_similarity_warn` | double | 0.70 | 重复警告阈值 |
| `keyword_groups` | list | — | 关键词分组（带权重），用于密度计算和话题多样性 |
| `objection_patterns` | list | — | 异议信号正则 |
| `noise_patterns` | object | — | 噪音词库（greeting/chitchat/echo/closing/filler） |
| `scene_mapping` | list | — | 关键词→场景标签映射 |
| `labels` | object | — | **预检反馈文案措辞**（见下表） |

### labels — 反馈文案

```yaml
precheck:
  labels:
    counterparty_role: 客户方          # 替代硬编码"客户方"
    dialogue_structure: 客户-销售对话   # 替代"客户-销售对话"
    objection_term: 客户异议信号       # 替代"客户异议信号"
    business_content: 实质销售内容     # 替代"实质销售内容"
    domain_scenario: 销售场景          # 替代"销售场景"
```

金融版：
```yaml
precheck:
  labels:
    counterparty_role: 市场方
    dialogue_structure: 对话结构
    objection_term: 关键信号
    business_content: 实质投资研究内容
    domain_scenario: 投资研究场景
```

### keyword_groups

```yaml
keyword_groups:
  - name: 价格谈判        # 分组名
    weight: 3             # 权重 1-3
    keywords:             # 关键词列表
      - 报价, 底价, 折扣, 砍价, 贵了, 便宜, 预算不够
```

### objection_patterns

```yaml
objection_patterns:
  - pattern: "(太贵|贵了|超预算|预算有限)"   # Java 正则
    signal: price_objection                    # 信号代码
    label: 价格异议                             # 展示标签
```

> 金融等非对话领域可设为 `[]`。

### scene_mapping

```yaml
scene_mapping:
  - scene: 价格谈判
    keywords: [报价, 底价, 折扣, 砍价, 贵了, 便宜, 预算, 费用]
```

## 六、pipeline — 萃取流水线

| 字段 | 类型 | 说明 |
|------|------|------|
| `context_dimensions` | list | L0 情境标注维度 |
| `scene_taxonomy` | list[string] | 场景分类体系 |
| `extraction_role` | string | **颗粒提取 AI 角色**，注入 extract prompt |
| `extraction_task` | string | **颗粒提取任务描述**，注入 extract prompt |
| `extraction_output_fields` | list | 颗粒输出字段定义 |
| `material_type_labels` | map | 素材类型标签（dialogue/monologue/interview） |

### context_dimensions

```yaml
context_dimensions:
  - key: stage
    label: 购买阶段
    values:
      - value: awareness
        label: 问题认知
      - value: consideration
        label: 方案评估
```

### extraction_output_fields

```yaml
extraction_output_fields:
  - key: scene_description
    label: 场景描述
    max_chars: 50
  - key: expert_thought
    label: {domain.role_label}的思考逻辑   ← 可用领域变量
    max_chars: 150
```

### material_type_labels

```yaml
material_type_labels:
  dialogue: 销售对话        # 金融: 投资交流
  monologue: 经验分享        # 金融: 研究报告
  interview: 专家访谈
```

## 七、chat — 对话模式

```yaml
chat:
  modes:
    qa:
      label: 请教销冠                    # 前端按钮文字
      description: AI教你怎么说          # 按钮副标题
      placeholder: 问我任何销售问题...    # 输入框提示
      icon: 💬
    talk:
      label: 自由对话
      description: 茶水间碰到销冠
      icon: ☕
    practice:
      label: 场景对练
      description: AI扮演客户
      icon: 🎯
      role_swap: 我扮演客户，你来扮演销售   # 对练角色互换说明
      opening_context: 客户微信消息        # 对练开场场景描述
  practice_intents:
    - key: icebreak
      label: 破冰寒暄
    - key: discovery
      label: 需求探询
    - key: presentation
      label: 方案呈现
    - key: objection
      label: 异议处理
    - key: closing
      label: 逼单促成
    - key: avoidance
      label: 回避转移
```

## 八、extends — 继承机制

```yaml
# domain/finance/secondary_market.yml
extends: finance           # 继承一级全部配置

domain:
  id: finance.secondary_market
  name: 二级市场研究
  role_label: 研究员       # 覆盖父级的"分析师"

# precheck、acceptance、pipeline、chat 未写的字段全部从 finance.yml 继承
```

合并规则：子配置的非 null 字段覆盖父配置，Map/List 级别深度合并。
