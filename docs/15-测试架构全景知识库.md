## 清单3：核心业务状态机

### InterviewSession 六状态
- `created` → `in_progress` (首次发消息，InterviewService:176)
- `created` → `abandoned` (重新开始，:308)
- `in_progress` → `paused` (暂停，:328)
- `in_progress` → `completed` (四阶段全完成+6项采集全true，:495)
- `in_progress` → `abandoned` (重新开始，:308)
- `paused` → `in_progress` (恢复，:810 resumeSessionToWriter)
- `paused` → `abandoned`
- **非法拦截**：非created/in_progress状态不能发消息 → BusinessException(400) → InterviewService:169

### ExpertSkill 五状态
- `pending` → `analyzing` (上传材料后，:119)
- `analyzing` → `extracting` (AI分析完成，:132) 或 `analyzing` → `failed` (异常，:140)
- `extracting` → `active` (审核激活，:199)
- `active` → `extracting` (追加文件，:216)
- 状态判断分散在 ExpertService 各方法 → 无集中状态机

### Report file_status 二状态
- `synced` ⇄ `pending_regenerate` (编辑报告时:114-123)
- 下载时 `pending_regenerate` → 触发生成 → `synced` (:156-167)
